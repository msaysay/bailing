# 第十三期 · IP 工作台 · 分镜规划

横屏 1920×1080，事为主（人不出镜），Fish Audio 配音。画面主体是用户的工作台操作录屏（3 分 16 秒，1528×1080，60 帧），原声不用。

## 录屏怎么处理

- **只裁工作台本身**：裁掉浏览器标签栏、地址栏和桌面任务栏，保留左侧导航和正文（原片 x 40–1180、y 180–968），放进录屏外框里，配合推近和局部放大。
- **名字**：按用户要求用录屏里的「ClipSignal 短视频工作台」，不盖。
- **评论页打码**：网友昵称全部打码，用打码后的截图做推近，不直接用录屏。
- 录屏里的数字都是用户账号的真实数据，按原样使用。

## 逐段画面

| 段 | 口播要点 | 画面 |
|---|---|---|
| 开场（约 0–12 秒） | 一个人做 IP，最累的是拍完以后 | 三张卡快切：三个平台的数据、下一条拍什么、评论区，每张一推一停；落在「交给一个工作台」时，录屏外框从中间展开到看板 |
| 闭环（约 12–18 秒） | 定位 → 计划 → 创作 → 发布 → 采集 → 复盘 | 六个节点围成一圈依次点亮，每亮一个，旁边闪一下那一页录屏的小窗。**15 秒内全貌出完** |
| 漏斗（约 18–38 秒） | 五段漏斗，第一个偏弱的就是这周唯一要改的事 | 看板录屏推近到漏斗表；再用组件重画一遍五段漏斗，S1→S5 依次点亮，视频号那一行停在 S4 关系，打红框，旁边标 0.46% |
| 计划（约 38–48 秒） | 复盘 → 下周计划，目标拿来验收 | 复盘录屏快速滚过，切到计划表，局部放大「目标指标」那一列 |
| 创作（约 48–58 秒） | 两条路：AI 全自动、录口播 AI 剪 | 创作看板录屏，左右两块各标一个签；「不露脸的视频」处插第 6 期成片的一两秒 |
| 发布和评论（约 58–70 秒） | 三平台一起发，评论按规则起草回复 | 发布页勾三个平台；评论页（昵称打码）推近到自动回复规则 |
| 观点（约 70–78 秒） | 拼的是每周都知道下一条该怎么改 | 强调字幕，背后闭环图再转一圈 |
| 收口（约 78–88 秒） | 我是宁少；先关注，评论区打「工作台」 | 关注卡；评论弹出「工作台」；复盘表的缩略图 |
