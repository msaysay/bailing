# 每天拆一个大 V · 第 1 期：小 Lin

约 400 字，按 350 字/分算 70 秒左右。两个平台只有最后一段不一样。
【】里的要你填。交给助手时把「口播稿」那一段存成 `script.txt`（句读决定字幕在哪断行，已按一行不超过 14 个字断好）。

## 口播稿（抖音版）

```
## 开头
小Lin一条视频，
她对着镜头说话的时间，
只有三分之一。
剩下一半时间，
她缩成右上角一个小圆，
把画面让给证据。
这是我一帧一帧量出来的。
而且我把她这套剪法，
做成了一条工作流，
AI照着就能剪。
你现在看的这条，
就是它剪的。

## 三个数
我量了她三条片子，
一共18分钟，
就说三个数。
第一，版式。
人全屏只占三分之一，
素材加小圆头像占一半，
五到七秒就换一次。
第二，素材。
差不多两秒换一个画面，
而且全是硬切。
第三，字幕。
永远在同一个位置，
纯白，不变色。
重点不靠字幕，
靠画面上的卡片和大字。

## 我是谁
我是【名字】，
【一句话身份】。
我做了一套AI剪口播的工具。
你给一条原片，
AI照着它剪口误、排版式、
配素材、出成片，
我只用确认三四次。
小Lin是我拆的第一个。
接下来我每天拆一个头部博主，
把他的内容是怎么做出来的，
一比一还原给你看。
拆的是做法，不是搬内容。

## 结尾
想要这套工作流的，
进我粉丝群，
我放在群里。
明天拆谁，
评论区你们定。
```

## 给剪辑助手的画面提示（财经解读风，技能 xiaolin-talk）

| 段 | 版式 | 放什么 |
|---|---|---|
| 开头前 3 秒 | 人全屏，胸口压一张图 | 小 Lin 成片的截图（素材带 + 小圆那种） |
| 「只有三分之一…让给证据」 | 素材带 | 对标片的联系表、版式占比的条形图，两秒一换 |
| 「你现在看的这条，就是它剪的」 | 人全屏，推近 | 什么都不压 |
| 「就说三个数」 | 人全屏 + 进度牌 | 三张牌：版式 / 素材 / 字幕，全片靠它串 |
| 第一、第二、第三 | 素材带 + 大数字，进度牌亮到对应那张 | 「1/3」「2 秒」；第三个放字幕位置的示意 |

| 「每天拆一个」 | 关键词大字 | 「每天拆一个大 V」 |

## 稿子里每个数的出处

都来自 `docs/对标拆解-小Lin口播.md`：三条片子 6:18 + 4:12 + 7:42 = 18 分 12 秒；人全屏 32% 到 51%（两条新样片是 32% 和 36%）；小圆头像 47% 到 53%（两条新样片）；平均 5.4 到 6.6 秒换一次版式。
「差不多两秒换一个画面」是从两秒一格的联系表里看出来的，不是逐帧数的，所以稿子里说的是「差不多」。
