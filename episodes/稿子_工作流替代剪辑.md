# 口播稿：大 V 的剪法，普通人也能用了

约 400 字，按 350 字/分算 70 秒左右。【】里的要你填。
交给助手时把「口播稿」那一段存成 `script.txt`（句读决定字幕在哪断行，已按一行不超过 14 个字断好）。

## 结构（为什么这么排）

| 段 | 时长 | 干什么 | 用的是哪条规律 |
|---|---|---|---|
| 钩子 | 前 3 秒，两句 | 把结果直接亮出来：这条就是 AI 照着大 V 的剪法剪的 | 结果前置；第一句单拿出来也成立；画面当场就是证据 |
| 证明 | 8 秒 | 点三个名字，说一句怎么做到的 | 钩子许下的事马上兑现，不让人等 |
| 观点 | 6 秒 | 我已经不找剪辑师了 | 反常识的结论 |
| 怎么用 | 40 秒 | 两种用法，各三个短句 | 「问题 + 分步拆解」，每步一个画面 |
| 升级 | 6 秒 | 六种风格 | 临近结尾再给一个新信息，防止提前划走 |
| 引导 | 5 秒 | 进群或留言 | 行动只给一个 |

和上一版的差别：上一版先铺了五句背景（大 V 有团队、我拆了、我量了…）才说到结果，现在结果放第一句，背景压成一句放到后面当证明。

## 口播稿

```
## 钩子
这条视频，
是AI照着小Lin的剪法剪的。
我没碰过剪辑软件。

## 证明
小Lin、蛋解创业、子祺见微，
这几位头部博主的片子，
我一帧一帧拆过。
多久换画面，字幕放哪，
人什么时候出镜，
全做成了一套工作流。

## 观点
所以我的口播视频，
已经不找剪辑师了。
原片丢进去，
说一句要谁的风格，
就这两步。

## 一键
它有两种用法。
第一种，什么都不想管。
说一句不用问我，
它一路做到底。
说错重来的，剪掉。
嗯啊这些口头语，去掉。
字幕、版式、配乐，配好。
你回来，成片已经在那儿了。

## 想对
第二种，想把把关。
它每做完一步，
停下来问你一句。
先对文字，错字改掉。
再对结构，不要的删掉。
最后对素材，
这句话配这个画面行不行。
一共点三四次头。
以前这些是跟剪辑师对的，
现在跟AI对。

## 升级
而且不止小Lin一种。
财经、科普、老板口播、
访谈、横屏长视频，
现在有六种风格可以选。

## 结尾
想要这套工作流的，
【进我粉丝群 / 评论区留一个剪字】，
我发给你。
```

## 钩子的三个备选（第一句换着试）

| 类型 | 第一句 | 什么时候用 |
|---|---|---|
| 结果型（稿子里用的） | 这条视频，是 AI 照着小 Lin 的剪法剪的。 | 这条成片确实是财经解读风剪的；画面本身就是证据，最稳 |
| 反常识型 | 小 Lin 那套剪法，我让 AI 学会了。 | 想突出「拆大 V」这个系列 |
| 利益型 | 不会剪辑，也能剪出大 V 那种视频。 | 想打不会剪辑的普通人；不点名，最安全 |

三个都能接后面的「证明」段，不用改别的。可以同一条片子换第一句发两个平台，看哪个留人。

## 给剪辑助手的画面提示

| 段 | 放什么 |
|---|---|
| 钩子第一句 | **第一帧就要有信息**：人全屏，胸口压一张「小 Lin 成片 / 这条视频」的左右对比图，静音也看得懂 |
| 「我没碰过剪辑软件」 | 人全屏推近 |
| 三个名字 | 素材带：三位博主的成片截图，说到谁切到谁，一秒一个 |
| 「多久换画面…全做成了工作流」 | 素材带：对标片联系表、版式占比图；压大数字「1/3」「2 秒」 |
| 观点 | 人全屏 + 两张卡：「丢原片」「说风格」 |
| 「它有两种用法」 | 进度牌：「一键出片」/「逐步确认」，全片靠它串 |
| 第一种 | 素材带：飞书录屏里它自己跑的那几步；「剪掉」「去掉」「配好」各一个画面 |
| 第二种 | 素材带：录屏里它停下来问你的界面；「对文字」「对结构」「对素材」三张卡逐张亮 |
| 「一共点三四次头」 | 人全屏推近 + 大数字「3～4 次」 |
| 升级 | 六种风格的成片截图快切，每个一秒；进度牌换成六格 |
| 结尾 | 人全屏，胸口一张卡写引导语 |

## 写的时候拿不准的四处

1. **「不找剪辑师」的分寸**。你给的核心观点是「已经实现了对专业剪辑的替代」。我写成了「我的口播视频，已经不找剪辑师了」：说的是你自己的做法，站得住；「替代专业剪辑」是对整个行业下结论，这套工作流目前只做口播类，而且声音听感、剪口顺不顺还要人看一遍，容易被懂行的人在评论区挑。想用原话也可以，把第一句换成「这套工作流，已经能替代专业剪辑了」。
2. **钩子那两句**。「是 AI 照着小 Lin 的剪法剪的」前提是这条成片用的是财经解读风；「我没碰过剪辑软件」前提是全程用工作流出片、你没有手动调过。哪条不成立就换备选钩子。
3. **「不用问我，它就一路做到底」**。技能里默认每个确认点都会停下来问；你明确说不用问，它才会一路做完。录屏时请按这个说法演示，别让画面和口播对不上。
4. **开头点名三位博主**。这三位的片子确实是这套工作流的对标样本，拆解文档里有数。我没写「一键复刻」和「内容生产进入普通人时代」这两句原话：工作流复刻的是剪法（版式、节奏、字幕），不是他们的选题、稿子和出镜表现，说「复刻了内容生产流程」范围大了；而且点了真名，说得越满越容易被当事人或粉丝较真。稿子里用的是「大V的剪法，现在普通人也能用了」。约读书房和天图通逊是给客户做的，不算头部大 V，没有点名。不想点名的话，第一句换成「那些头部博主的视频」。

## 爆款结构的依据

查到的都是运营博客和工具厂商的经验总结，没有抖音官方数据，里面「前 3 秒流失 60% 以上」这类数字没有可核实的出处，我没有用。几篇文章一致的只有三条，稿子是按这三条排的：
1. 前 3 秒决定划不划走，所以把结果放第一句（「时间 + 结果」「结果型钩子」）。
2. 第一帧静音也要看得懂主题，所以画面提示里第一帧就压对比图。
3. 开头抛结果或反常识，中段分步展开，结尾只给一个行动。
