## 口播稿

```
## 钩子
小Lin、蛋解创业、子祺见微，
这些头部博主的视频，
背后都有一个专业的剪辑团队。
我把他们的片子，
一帧一帧拆了一遍。
多久换一次画面，
字幕放在哪，
人什么时候出镜，
全都量了出来。
然后做成了一套工作流，
AI照着就能剪。
大V的剪法，
现在普通人也能用了。

## 观点
所以我的口播视频，
现在已经不找剪辑师了。
你现在看的这一条，
从剪口误到上字幕、配画面，
没有一个人动过剪辑软件。
我只做了两件事。
把拍好的原片丢进去，
再说一句我要谁的风格。

## 一键
它有两种用法。
第一种，你什么都不想管。
跟它说一句不用问我，
它就一路做到底。
说错重来的那几遍，
它自己剪掉。
嗯啊这种口头语，
它自己去掉。
字幕、版式、配乐，
它自己配好。
你回来的时候，
成片已经在那儿了。

## 想对
第二种，你想把把关。
那它每做完一步，
就停下来问你一句。
先对文字，
哪个字识别错了，改掉。
再对结构，
哪一段不要了，删掉。
最后对素材，
这句话配这个画面行不行。
一共就点三四次头。
以前这些来回，
是我跟剪辑师在微信里对的。
现在是我跟AI对。

## 结尾
风格现在有六种。
财经解读、知识科普、
老板口播、访谈，
还有横屏的长视频。
想要这套工作流的，
【进我粉丝群 / 评论区留一个剪字】，
我发给你。
```

## 写的时候拿不准的四处

1. **开头那句的分寸**。你给的核心观点是「已经实现了对专业剪辑的替代」。我写成了「我的口播视频，已经不找剪辑师了」：说的是你自己的做法，站得住；「替代专业剪辑」是对整个行业下结论，这套工作流目前只做口播类，而且声音听感、剪口顺不顺还要人看一遍，容易被懂行的人在评论区挑。想用原话也可以，把第一句换成「这套工作流，已经能替代专业剪辑了」。
2. **「没有一个人动过剪辑软件」**。前提是这条视频确实全程用工作流出片。如果你后面手动调过，这句删掉。
3. **「不用问我，它就一路做到底」**。技能里默认每个确认点都会停下来问；你明确说不用问，它才会一路做完。录屏时请按这个说法演示，别让画面和口播对不上。
4. **开头点名三位博主**。这三位的片子确实是这套工作流的对标样本，拆解文档里有数。我没写「一键复刻」和「内容生产进入普通人时代」这两句原话：工作流复刻的是剪法（版式、节奏、字幕），不是他们的选题、稿子和出镜表现，说「复刻了内容生产流程」范围大了；而且点了真名，说得越满越容易被当事人或粉丝较真。稿子里用的是「大V的剪法，现在普通人也能用了」。约读书房和天图通逊是给客户做的，不算头部大 V，没有点名。不想点名的话，第一句换成「那些头部博主的视频」。
