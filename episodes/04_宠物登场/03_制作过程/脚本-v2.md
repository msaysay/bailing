# 一个 IP，怎么让 AI 把它养活（EP00 · 脚本 v2）

**这条片子是给谁看的**：手上有 IP、或者想做 IP，又想用 AI 的人。
**这条片子要证明什么**：我能用 AI 把一个静态的形象，变成一个**会动、会长、会跟观众互动**的 IP，而且整套东西我已经做出来了。海豹是证据，不是主角。
**和前面两套工具的关系**：这是第三件事——「IP 的 AI 化」。新闻稿自动化、口播自动化是另外两套工具；这条片子本身会**叠加**用到它们（口播的剪辑、字幕、组件），但片子讲的只是 IP 这件事。

**片名备选**：《我让 AI 养了一个 IP，它长成什么样由评论区决定》／《IP 最贵的不是形象，是它会长大》
**画幅**：横屏 1920×1080，你坐在桌前，中景。宠物全系列固定在**画面右下角**。
**时长**：约 2 分 20 秒。口播约 520 字，加动作停顿。
**结构**：照对标片「要求 → AI 交初版 → 打回 → 想明白 → 成品」的循环来讲做 IP 的过程，三轮打回都是真的，画面就用我们这几天真实做出来的四版图。

## 一、开拍前

1. **画面右下角留空**，那里是它常住的位置。
2. **桌上贴两个美纹纸小标记**：A 点（你右手前方 20 厘米），B 点（画面右下角对应的桌面边缘）。后期擦掉。
3. **先空拍 3 秒空桌面**。
4. **托它的手势**：手心朝上、五指微弯，像托一个乒乓球；托住后停 1 秒再动，动作慢、走直线，眼睛看手心。

### 4 · 第二、三版：学大师，再打回（0:40–1:05）
| | |
|---|---|
| **口播** | 它去拆了宝可梦伊布为什么能进化成八种样子、泡泡玛特 Labubu 为什么要露牙、婴儿脸为什么让人想照顾，做出第二版。我说还是丑。它又去看了成年人在网上真正喜欢的 IP——卡皮巴拉、吉伊卡哇、Loopy，结论是：成年人要的是情绪稳定、毛绒、能做成表情包。第三版就成了这样。 |
| **你的动作** | 说三个参考时**右手掰手指数三下**；说「卡皮巴拉、吉伊卡哇、Loopy」时**左手往左边一划**，像在翻资料卡。 |
| **它** | 冰蛋的眼睛（隔着冰）跟着你的手转。 |

### 5 · 40% 转折：人只出手一次（1:05–1:20）
| | |
|---|---|
| **口播** | 第三版能看了，但我手上正好有一个更好的底模——就是这只海豹。我把模型丢给它，说：在这上面改。这是我唯一一次亲自出手。 |
| **你的动作** | 「就是这只海豹」时**从 A 点把它重新捧起来**，捧到胸前。「唯一一次」时竖一根手指。 |

## 四、成长规则（置顶评论版）

1. **你们的互动让它长大**：点赞、评论、转发、收藏、关注都会变成经验值，经验满了升级。冰蛋 → 破冰 → 幼崽 → 成体。
2. **长成什么，看你们聊什么**：每期 AI 读一遍评论区，按大家更偏技术、赚钱、情绪还是故事，给机芯、金羽、焰心、星语四条路线加分，进化那期分数最高的胜出。还有一条隐藏路线。
3. **全公开**：每期涨了多少经验、AI 凭哪几条评论给哪条路线加分，都贴出来。
4. **名字由你们起**：点赞最多的名字当选。

**说法提醒**：只说「你们的互动会让它长大」，不说「点赞过万它就……」「不点赞它就……」。
