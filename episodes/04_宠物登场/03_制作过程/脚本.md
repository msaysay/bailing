# 宠物登场 · 拍摄脚本（EP00）

**片名备选**：《我的频道开始养一只海豹，它长成什么样由你们决定》／《这只海豹，靠你们养大》
**画幅**：横屏 1920×1080，机位和对标片一样：你坐在桌前，中景，上半身加桌面。
**时长**：约 1 分 30 秒。口播约 320 字（按每秒 4.5 个字约 72 秒），加上放蛋、「嘘」、「咔」这些动作的停顿。
**结构**（照对标片的做法）：前 5 秒交代清楚「谁、要干嘛、赌什么」；40% 处放隐藏路线的悬念；80% 处是「咔」把它送进角落；结尾留「哪一期破冰」的悬念。

---

## 一、开拍前：三件事

1. **画面右下角留空。** 那里是它以后常住的位置。桌面右下这一块别放杯子、书、线。
2. **桌上贴两个小标记**（米白色美纹纸撕一小块，后期会擦掉）：
   - **A 点**：你右手前方 20 厘米的桌面，它放在桌上时待的位置。
   - **B 点**：镜头右下角对应的桌面边缘，「咔」的时候你手指指向这里。
3. **先空拍 3 秒**：你还没坐下时，空桌面拍 3 秒。后期要用它擦掉标记，也方便我把海豹贴得更干净。

**托它的手势（全片通用）**：手心朝上，五指微微并拢、略弯，像托着一个乒乓球。手停在胸口高度、身体右前方，**手托住后至少停 1 秒不动**，动的时候慢、走直线。手里是空的，眼睛看着手心，像那里真有东西。

## 二、分镜

> 「组件」一栏的编号对应组件包里的编号（`组件说明.md`）。「它」指海豹。

### 1 · 冷开场（0:00–0:04）
| | |
|---|---|
| **口播** | 我的频道，今天开始养一只宠物。它长成什么样，不由我说了算，由你们说了算。 |
| **你的动作** | 开机就是**双手捧在胸前**，像捧着一颗蛋，低头看它。说到「由你们」时抬头看镜头。 |

### 2 · 它是谁（0:04–0:14）
| | |
|---|---|
| **口播** | 现在它还是一颗冰蛋。里面睡着一只小海豹。你凑近看——它还在打呼。 |
| **你的动作** | 「凑近看」时**把双手往镜头方向送 10 厘米**，自己也微微前倾。说完收回。 |

### 3 · 规则一：互动让它长大（0:14–0:31）
| | |
|---|---|
| **口播** | 它怎么长大？靠你们。每一个点赞、评论、转发、收藏，都会变成它的经验值。经验攒满了，它就升一级。攒够几级，就会破冰出来。 |
| **你的动作** | 「靠你们」时**把蛋放到桌上的 A 点**：手慢慢落到桌面，停 1 秒，手抽走。然后右手食指**指向镜头**（指观众），说到「点赞、评论、转发、收藏」时，左手掰手指数四下。 |
| **它在干嘛** | 冰蛋留在桌上 A 点，开始轻轻晃。每数一下，就有一个小图标（❤ 💬 ↗ ⭐）从画面上方飞进蛋里，蛋亮一下、裂纹多一点。 |
| **画面加什么** | 蛋旁边出现一根经验条，从 0 开始往上涨一小截（L07 目标计数器的样式）。「升一级」时数字 Lv0 跳成 Lv1 后又退回 Lv0，配字「（示意）」。 |
| **音效** | 每个图标进蛋一声「叮」，音高一次比一次高。 |

### 4 · 规则二：AI 决定它长成什么（0:31–0:45）
| | |
|---|---|
| **口播** | 它长成什么样？也看你们。每期结束，我让 AI 把评论区读一遍——大家聊的是技术，是赚钱，是情绪，还是自己的故事——给四条路线加分。到了进化那一期，分数最高的胜出。 |
| **你的动作** | 「技术、赚钱、情绪、故事」**每说一个，手在胸前比一个方向**：左上、右上、左下、右下，像在桌面上方摆四张牌。 |
| **它在干嘛** | 冰蛋待在 A 点，眼睛（隔着冰）跟着你的手转。 |
| **画面加什么** | 你比到哪，哪个位置就弹出一张剪影卡：四种成体形态的**黑色剪影**加「？」（L10 卡片扇的样式摆成四宫格），先不揭晓长什么样，只露每条路线的名字和颜色：机芯（蓝）、金羽（金）、焰心（橙）、星语（紫）。 |
| **音效** | 每张卡弹出一声「翻牌」。 |

## 三、手势速查（拍的时候放手机上看）

| 时刻 | 手势 | 要点 |
|---|---|---|
| 开场 | 双手捧在胸前 | 手心朝上，停稳再开口 |
| 「凑近看」 | 双手往镜头送 10 厘米再收回 | 慢 |
| 「靠你们」 | 放到 A 点，停 1 秒，手抽走 | 手抽走时别擦过 A 点上方 |
| 数四种互动 | 左手掰手指 | 别挡住 A 点 |
| 技术、赚钱、情绪、故事 | 左上、右上、左下、右下各比一下 | 位置要分得开，后期在那四处弹卡片 |
| 隐藏路线 | 食指竖嘴前「嘘」 | |
| 「一个字不改」 | 手掌往下一压 | |
| 取名 | 从 A 点重新捧起 | 手落到 A 点停 1 秒再托起 |
| 「咔」 | 右手托着往右下送，左手食指划向 B 点，「咔」时定住 0.5 秒，眼睛看右下 | 这是全片最重要的一个动作，多拍几条 |
| 结尾 | 侧头瞄右下角 | |

**拍几条**：整段一条拍完；第 8 段「咔」单独再补拍 3 条，后期挑最干脆的一条。

## 四、成长规则（给观众的简版，可以贴置顶评论）

1. **你们的互动让它长大。** 点赞、评论、转发、收藏、关注都会变成它的经验值，经验满了就升级。
2. **它长成什么样，看你们聊什么。** 每期结束，AI 读一遍评论区，按大家更偏技术、赚钱、情绪还是故事，给机芯、金羽、焰心、星语四条路线加分。进化那一期，分数最高的胜出。还有一条隐藏路线。
3. **全公开。** 每期涨了多少经验、AI 给哪条路线加了分、凭的是哪几条评论，都贴在置顶评论里。
4. **名字由你们起。** 点赞最多的名字当选。

成长阶段：冰蛋 → 破冰 → 幼崽 → 成体（四选一）。完整规则和内部怎么算见 `docs/宠物成长规则.md`。

**说法上的提醒**：平台限制用利益或威胁诱导互动。片中只说「你们的互动会让它长大」，不要说「点赞过万它就……」「不点赞它就……」。
