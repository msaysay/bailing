# 口播线 第 1 步 · 定稿与拍摄要求

## 先判断走哪条线
- **事为主**（横屏，人不出镜，实拍和图表讲事）：走 `video-01` 到 `video-08`。
- **人为主**（竖屏，真人出镜，人和画面交替）：走这条线。判断标准：这条内容靠「谁在说」立住，还是靠「发生了什么」立住。

## 稿子
写法同 `video-01-script`，多三条：
1. **一句一个意思，句子短。** 口播要一口气念完一句，超过 25 个字就拆。
2. **每 20 到 30 秒安排一句「人话」**：提问、转折、表态、玩笑（「那你可能会好奇」「我跟你说哈」）。这些句子在成片里是全屏人脸，用来换气。
3. **需要给证据的地方在稿子里标出来**（「你看」「比如」后面跟的东西），第 3 步会给它们配素材。
4. 全片如果在讲「几个并列的东西各自怎么样」，想一张**贯穿全片的表**：开头亮出空表，讲完一项填一行，结尾整张做总结。

## 拍摄要求（发给出镜人）
| 项 | 要求 | 原因 |
|---|---|---|
| 画幅 | 竖屏 9:16，1080×1920 以上 | 成片只用上面的 2:3，底部留给平台按钮 |
| 人的大小 | **脸宽占画面宽 20% 到 25%**，眼睛在画面上三分之一处 | 脸太大，下巴以下放不下组件 |
| 头顶 | 头顶到画面上沿留一个头的高度 | 要放小圆头像和标题 |
| 水印 | 关掉相机水印、时间戳 | 去水印会损画质 |
| 背景 | 干净、不动；人和背景有亮度差 | 人缩成小圆时还能看清 |
| 录法 | 一条到底，不停机 | 剪口越少越好 |
| 口误 | 说错了停一秒，**整句重说**，不要只补半句 | 整句才能干净地剪掉 |
| 声音 | 领夹或指向麦，离嘴一拳到一臂 | 字幕时间从声音里取 |

## 输出
`episodes/<期>/03_制作过程/script.txt`（出镜人念之前的稿）、`episodes/<期>/01_输入素材/口播原片.mp4`。

## 放行条件
稿子经人确认；原片拿到手。原片不符合拍摄要求时，告诉用户差在哪、成片会受什么影响，由他决定重拍还是将就。
