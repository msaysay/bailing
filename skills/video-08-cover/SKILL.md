# 第 8 步 · 封面与发布包

## 封面

封面是一个 Remotion 静帧组件，同一套设计按尺寸自适应。范例：`studio/src/episodes/ep02/cover.tsx`。

```bash
cd studio
npx remotion still src/index.tsx <期>-COVER-DOUYIN out/cover/<期>-封面-抖音-1080x1440.png
npx remotion still src/index.tsx <期>-COVER-SHIPINHAO out/cover/<期>-封面-视频号-1080x1260.png
```

| 平台 | 尺寸 | 说明 |
|---|---|---|
| 抖音 | 1080×1440（3:4） | 个人主页网格的显示比例 |
| 视频号 | 1080×1260（6:7） | 信息流的显示比例 |

平台规格会变，出图前向用户确认当前要求。

设计要点：

- **一张主图**：最好是人物近景，表情和选题情绪一致。从素材里截一帧时，注意原片角落的字幕要遮掉。
- **标题不超过 10 个字**，分两行，上白下暖色；疑问句或反差句比陈述句好。不照抄视频标题。
- **一个时效标签**放左上角（例如「辞职第二天」）。
- **最多三个数字**做成小卡，只用核对过有出处的数字。
- 底部放账号名和定位句。
- 关键内容离边缘至少 60 像素，避开平台叠加的标题和按钮。
- **人脸不能被标题盖住**：脸放上半部，标题从下巴以下开始。

## 发布包

交给用户一份清单：

1. 成片文件、两张封面。
2. 标题备选 3 个；一段简介（讲清这期说了什么）；话题标签。
3. **署名**：背景音乐等需要署名的素材，写进简介。
4. **提醒**：片中和封面使用的新闻画面没有取得授权，是否发布由用户决定；口播里没有查到出处的说法逐条列出。
5. 是否标注「AI 生成」，按平台要求和用户意愿。
6. **片尾的制作说明要如实**：配音是真人录的还是合成的、用了哪家的合成服务，先问用户，不要自己猜。

助手不代替用户发布。
