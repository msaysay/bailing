# 第 5 步 · 逐段规划

## 输入
`script.txt`、`timing.json`、镜头表、`faces.json`、`事实核对.md`、组件目录（`studio/src/gallery/catalog*.tsx` 或组件包里的 `组件说明.md`，共 232 个：结构、时间、数字、市场、对比、组织与人、流程与政策、内容与引用，以及网页与文档、录屏与设备、视频与图片、数据图表、文字与强调、关系与流程、口播叠加、炫技动效、画面效果、运动手感、广播风三组（每章换色、常驻外框、双语字幕、粒子数据、人物件、图解件，做法见 `docs/对标拆解-AfterJensen.md`）；运动函数在 `studio/src/kit/motion.ts`）。

## 输出
`episodes/<期>/03_制作过程/规划.md`：一张逐段的表，写清每段的时间、口播、镜头、组件、来源标注、字幕处理、人脸处理。

## 对每一段，按顺序回答五个问题

1. **这句话的对象和变化是什么？** 例如「100 个人里裁掉 60 个」，对象是人，变化是减少。先有这个答案，再去选组件。
2. **目录里有没有现成的组件？** 按「适用」一栏找，看「不适用」一栏排除。没有合适的，写明缺口并新做一个；一期新做的不超过四成。
3. **画面上放什么字？** 只放口播里没有的信息：数字、名称、标签、来源、结构。口播的原句不上大字。
4. **这句要不要强调字幕？** 只有设问、金句、论点用；全片每分钟不超过两句。用了就把这一行加进隐藏底部字幕的名单。
5. **这个镜头里有没有人脸？** 有的话三选一：
   - 组件只占一侧 → 给镜头写 `faceTo`，把脸挪到另一侧；
   - 脸在上方 → 组件排到下半部；脸在中间 → 组件分到左右；
   - 组件要铺满 → 换一个没有人脸的镜头。

## 整体节奏

- 每 4–6 秒画面要变一次：换镜头、换组件，或主体有明确变化。
- 长视频分章节：每个大部分开头一张章节页，章节条全程显示进度。
- 留呼吸：情绪重的句子（现场、悼念、转折）可以不放组件，只留画面和字幕，加一个新闻角标。
- 同一种组件全片不连用三次；系列视频里可以有意复用一两个组件做呼应。
- 一个时刻只有一个主角；新元素在语义段落边界进场。

## 来源标注

- 核对一致的数字：组件上加 `Src`，写「机构 · 日期」。
- 没查到的：不加来源标签。
- 没有真实数据就不画像数据的图。例如没有分时行情，就用跌幅尺表示幅度，并写明「幅度示意」。
- 内容示意（帖子正文、文件正文）用灰条，标「内容示意，非原文」，不编造文字。

## 放行条件
用户认可方向。**先只做第一段给用户看**，确认风格后再铺全片。
