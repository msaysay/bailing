# 相框口播线 第 2 步 · 标题与剪辑决定表

这一步不写代码，只写一个 JSON。模板 `studio/src/yuedu/` 读它出片。
完整的例子：`episodes/14_约读书房_样片/03_制作过程/edl.json`（四分半，71 段画面），先读它。

## 输入
`timing.json`、`script.txt`、`cuts.json`、`meta.json`、素材库 `library.json`（可能没有）、`brands/yuedu/rules.md`。

## 一、标题：出三组，用户选

标题是相框顶上那三行，第二行在黄条里。写 `03_制作过程/标题候选.md` 并贴给用户，格式照样片目录里那份。

- 三行各有分工：第一行抛出反差或场景，**第二行（黄条）放品牌名加动作，不超过 9 个字**，第三行落到一个具体的问题或结果。第一、三行各不超过 14 个字。
- 三组走三个方向，不要三组换词不换意思：一组提问，一组讲结果或数字，一组讲反差。
- 标题里的数字和说法必须是口播里有的。
- 每组后面写一句「适合谁看」。

用户选定后写进 `edl.json` 的 `title`。用户没回复时先用你最推荐的那组往下做，交付时说明。

## 二、画面窗里的八种处理

| do | 处理 | 人 | 什么时候用 |
|---|---|---|---|
| `P` | 人铺满，可带景别 `zoom` | 铺满 | 默认。提问、过渡、表态 |
| `K` | 关键词贴纸（橙刷字，贴在脸旁边） | 铺满 | 一个概念词全片第一次出现。不超过 8 个字 |
| `L` | 并列清单（两到四条橙刷字依次出现） | 铺满 | 口播连说几个并列的词 |
| `S` | 聚光对比（压黑，只留人，左侧大字） | 铺满 | 「不是 A，而是 B」「从 A 到 B」。每行不超过 10 个字 |
| `R` | 素材铺满画面窗 | 不在 | 提到具体场景，看一眼就够（4.5 秒内） |
| `C` | 画中画：人缩成右上角小圆，窗里放素材或卡片 | 小圆 | 要对着一个东西讲 3 秒以上 |
| `G` | 生成卡片铺满画面窗 | 不在（可设 `"person": "bubble"`） | 讲流程、对比、数字、趋势，没有合适的素材 |
| `E` | 收束金句（人推近，底部超大字） | 铺满 | 全片最后一句 |

`P S E R C G` 是「底」：一个接一个，每个持续到下一个开始。`K L` 是叠在人身上的，只能出现在 `P` 里。

## 三、画面从哪来（按顺序试）

1. **客户给的素材**：在 `library.json` 里按 `desc` 找。同一条全片只用一次，时长要够。
2. **搜**：`python3 scripts/tikhub.py search "约读书房 读书会" --landscape`，下载用 `get <作品ID> --out <目录> --name <别名>`，然后对那个目录跑一遍 `scripts/library_index.py` 入库。搜来的东西是别人的：**只用约读书房官方账号发的**，其余的不用；用了哪条，在版式表备注里写出处，交付时告诉用户「这几条是搜来的，请确认能用」。
3. **生成卡片**：前两条都没有，就用卡片把这句话画出来。十三张卡的用途和参数见同目录的 `卡片目录.md`。**没有素材从来不是让人消失或者干放人脸的理由**，卡片就是为这个准备的。

卡片的三条规矩：
- **卡片上的字必须是口播里有的或能直接推出来的**。口播说「三个阶段」，卡片可以写三个阶段的名字；口播没说的数字，一个都不能写。
- `Report`、`Dashboard`、`Curve` 画的是示意图，右上角自带「示意」角标，不许去掉。有真实的报告截图或后台录屏时，优先用 `Magnify` 把真东西放大。
- 同一张卡全片最多用两次，两次的内容不能一样。

## 四、edl.json 的写法

```jsonc
{
  "title": ["从“碎片化”到“系统化”", "约读书房如何解决", "“阅读指导”的标准化难题？"],
  "hot": ["规模化", "标准化", "可度量"],          // 字幕里放大变黄的词，8 到 15 个；必须和字幕里的写法一字不差
  "beats": [
    { "at": 0, "do": "P", "zoom": 1.0 },
    { "at": ["开场", "作为约读"], "do": "P", "zoom": 1.14 },
    { "at": ["开场", "要实现规模化"], "do": "K", "text": "实现规模化", "side": "left", "hold": 2.4 },
    { "at": ["开场", "必须将"], "do": "R", "clip": "b01-01" },
    { "at": ["双师", "导致教师"], "do": "C", "card": "Compare", "props": { … }, "cues": [["双师", "导致教师"], ["双师", "那双师模式呢"]] },
    { "at": ["培训", "全方位理解"], "do": "G", "card": "Checklist", "props": { … }, "cues": [["培训", "阅读心理学"], ["培训", "产品逻辑"], ["培训", "运营标准"]] },
    { "at": ["测评", "变成了可追溯"], "do": "L", "side": "left", "items": [{ "at": ["测评", "可追溯"], "text": "可追溯" }, { "at": ["测评", "可优化"], "text": "可优化" }] },
    { "at": ["结尾", "我们没有把"], "do": "S", "lines": [{ "at": ["结尾", "我们没有把"], "text": "不把教育做成苦力活" }, { "at": ["结尾", "而是做成了"], "text": "而是标准化工业产品", "tone": "accent", "size": "l" }] },
    { "at": ["结尾", "可复制的"], "do": "E", "lines": [{ "at": ["结尾", "可复制的"], "text": "可复制的", "tone": "hot" }, { "at": ["结尾", "阅读教育商业"], "text": "阅读教育商业解决方案" }] }
  ]
}
```

- **`at` 写 `[段名, 词]`**，意思是「这一段里念到这个词的那一刻」。词要照 `script.txt` 的原字写，取够长（四个字以上）避免撞到前面相同的词。可以带第三项做微调：`["开场", "必须将", -0.3]` 是提前 0.3 秒。**不要自己估秒数**；只有盖剪口时直接写 `cuts.json` 里的数。
- `cues` 是卡片里每一项亮起来的时刻，顺序和卡片的项一一对应；不写就自动均匀排开。
- `zoom`：默认 1.0；强调句、反问句用 1.12 到 1.25。景别只硬切，相邻两次至少差 0.08。
- `side`：贴纸和清单放脸的哪一边。看 `meta.json` 的 `face.x`：小于 720 放 `right`，否则放 `left`。
- `clip` 可带 `"from": 秒` 从素材中间开始放；竖版和截图会自动用模糊垫底。
- `G` 加 `"person": "bubble"` 就是人以小圆留在角上；超过 6 秒的卡片都应该这样。
- `S` 的 `tone`：`white`（默认）、`accent`（橙）、`hot`（黄）；`size`：`m`、`l`、`xl`。
- 换出镜人只改这一期：加 `"speaker": { "name": "…", "titles": ["…", "…"] }`。

## 五、怎么排

先通读全文，标出三样东西：**结构句**（第一点、第二点……每段一个）、**证据句**（提到具体的人、地方、系统、数据）、**对比句**（不是…而是…）。然后：

- 每段的结构句：`P` 换景别，或一张 `G` 卡把这一段的要点亮出来。
- 证据句：有素材用 `R`（短）或 `C`（长），没有就 `G`。
- 对比句：挑全片最重的一两处用 `S`，其余用 `Compare` 卡。
- 剩下的都是 `P`。每个 `P` 超过 6 秒就在中间换一次景别，或加一个 `K`。
- 最后一句用 `E`。
- 每个剪口：让它落在 `R`、`C`、`G` 里；做不到就在那一刻加一条 `{"at": 剪口秒数, "do": "P", "zoom": 和前面差 0.1 以上}`。

节奏：平均 4 到 6 秒有一次变化；素材、卡片、人交替着来，不要连着三张卡，也不要连着三段素材。

## 六、检查

```bash
python3 scripts/frame_plan.py "episodes/<期>"
```
它把 `at` 换成秒数，逐条查硬指标，生成 `props.json`（渲染用）和 `版式表.md`（给人看）。

硬指标（「不通过」的必须改 `edl.json`，**不许改脚本里的阈值**）：
- 人在画面里不低于 70%，人铺满不低于 45%；人连续不在画面不超过 8 秒。
- 素材时长够；同一条素材只用一次；每段至少 0.7 秒。
- 贴纸不超过 8 处；聚光不超过 4 处；贴纸和清单只能落在 `P` 里。
- 相邻景别至少差 0.08，推近不超过 1.5。
- 每个剪口都被盖住。
- 标题第二行不超过 9 个字。

「提醒」不拦，但每一条都要看：能改就改，不改要有理由，交付时说明。

## 七、给用户看

把 `版式表.md` 的统计部分和整张表贴给用户，连同选定的标题。用户点头再进第 3 步；用户说了「不用问我，直接出」就直接进。

## 输出
`标题候选.md`、`edl.json`、`props.json`、`版式表.md`。

## 放行条件
`frame_plan.py` 没有「不通过」；每条「提醒」都处理过或有说明；用户选了标题、看过版式表（或明确授权不看）。
