# 生成卡片目录

十三张卡，都是纸白底、品牌绿加强调橙，占满画面窗。在 `edl.json` 里写 `"card": "名字", "props": {…}, "cues": […]`。
每张卡都可以带 `kicker`（左上角小标，写这是第几点或哪个话题）和 `title`（标题，不超过 14 个字）。
看效果：`cd studio && npx remotion render src/yuedu/index.tsx YueduCards out/cards.mp4`（每张 5 秒），示例参数在 `studio/src/yuedu/samples.ts`。

| 卡 | 口播在说什么的时候用 | props | cues 对应 |
|---|---|---|---|
| `Formula` | 「A 加 B 加 C」组成一套东西 | `parts`: 2 到 4 个词；`result`: 结果 | 每个 part 一个，最后一个给 result |
| `BigNumber` | 一个撑得起画面的数字 | `value`: 数；`suffix`: 「+」等；`unit`: 单位；`label`: 一句说明；`hub`: 中心写什么（默认「总部」） | 一个：数字开始滚的时刻 |
| `Compare` | 旧做法和新做法对着讲 | `left`/`right`: `{name, items[]}`，每边 1 到 3 条，每条不超过 10 个字 | 两个：左边出现、右边出现（同时左边被划掉） |
| `Split` | 两个角色各管什么 | `left`/`right`: `{role, items[]}`；`link`: 中间连线上的字 | 两个：左、右 |
| `Steps` | 第一步、第二步、第三步 | `steps`: 3 到 4 个 `{t, s}`（t 标题不超过 5 个字，s 一行说明） | 每步一个 |
| `Ladder` | 一级比一级高的进阶 | `steps`: 3 到 4 个 `{t, s}` | 每级一个 |
| `Checklist` | 并列的几条，一条条确认 | `items`: 2 到 4 条，字符串或 `{t, s}` | 每条一个 |
| `Loop` | 几个环节首尾相接 | `nodes`: 3 到 5 个词（每个不超过 4 个字）；`center`: 圈中间的词 | 每个环节一个 |
| `Quote` | 一句结论当画面 | `text`: 一句话（30 个字以内）；`mark`: 其中要被划重点的词；`by`: 出处 | 一个：划重点的时刻 |
| `Curve` | 增长、趋势，没有真实数值 | `series`: 1 到 3 条线的名字；`xLabels`: 横轴四个刻度 | 每条线一个 |
| `Report` | 测评、能力维度 | `dims`: 3 到 6 个 `{name, score}`；`badge`: 橙色小标 | 每个维度一个（念到时变橙） |
| `Dashboard` | 后台、监控、看板，没有录屏 | `tiles`: 3 个 `{k, v}`；`rows`: 3 到 4 个 `{name, v(0到1), tag?}` | 每个 tile 一个（念到时变绿） |
| `Magnify` | 有录屏或截图但字太小 | `src`: 文件（相对 studio/public）；`kind`: `image` 或 `video`；`focus`: `[x, y, w, h]`（0 到 1，橙框框住哪一块）；`rows`: `[[名, 值], …]` | 每行一个 |

## 写内容的规矩
- 字从口播里来。`Report` 的分数、`Dashboard` 的百分比、`Curve` 的走势是示意，卡片右上角自带「示意」或「示意数据」角标；这三张卡里**维度和指标的名字必须是口播说过的**，口播只说了三个维度就只画三个。
- `Magnify` 的 `rows` 只能写录屏里真有的东西或口播原话，读不清的不写。
- `BigNumber` 的数字必须是口播里的数字。
- 一张卡上的字越少越好：标题一行，每项一个短语。写不下说明这句话该拆成两张卡。

## 加一张新卡
现有的卡都不合适时，可以加。在 `studio/src/yuedu/cards.tsx` 里照现有的写法加一个组件（用 `Shell` 外壳、`K` 里的颜色、`cueAt` 取时刻），登记进文件末尾的 `CARDS`，在 `samples.ts` 加一条示例，在这张表里加一行。不要另起一套颜色和字体，不要用深色底。加完出一张静帧自己看过再用。
