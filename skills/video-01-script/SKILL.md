# 第 1 步 · 定稿

## 输入
想法、初稿，或用户已经写好的全文。

## 输出
`episodes/<期>/03_制作过程/script.txt`，格式：

```
## 段名
这一段的正文。数字、英文按用户的写法保留。
## 下一段名
……
```

段名自己起，短而唯一（例如「开场」「一·内网」「市场」），后面所有步骤都用段名定位。

## 步骤

1. **只校不改意思**。用户给了全文时，只修错别字、标点、明显口误；改动措辞前先问。稿子是文字权威，后面的字幕以它为准。
2. **分段**。一段讲一件事，10–25 秒为宜。开场、每个大部分、论点、结尾各自成段，方便后面逐段配画面。
3. **算时长**。中文口播约每分钟 250–280 字；报出总字数和预计时长。
4. **检查开头**。第一句要有具体对象和具体事件，18–32 个字；不合适时给 3 个备选让用户挑，不擅自换。
5. **检查结尾**。有署名和关注引导；需要时加「本视频由 AI 自动生成」的说明。
6. **标出要核对的事实**：所有数字、日期、人名、机构名、引语，列成清单交给第 2 步。

## 放行条件
用户确认稿子。之后改稿要回到这一步，并重做第 3 步的对齐。

## 不要做
- 不为了「更抓人」加没有出处的数字或夸张说法。
- 不把用户的口语改成书面语。
