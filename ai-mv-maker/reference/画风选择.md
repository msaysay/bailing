# 三种画风

| | 剪影插画 silhouette | 霓虹城市 neon | AI 生图动起来 image-layers |
|---|---|---|---|
| 样子 | 渐变天空、太阳月亮、山、树、人物剪影，像绘本 | 雨夜霓虹街道、复古条纹落日公路、雨窗光斑 | 你生成的图，加推拉运镜、视差、粒子、漏光 |
| 适合 | 温暖、回忆、成长、亲情、民谣、抒情 | 都市、失眠、思念、电子、说唱、快歌 | 想要最精致；有具体场景（古风、校园、海边、雪山） |
| 要准备 | 无 | 无 | 每场一张竖图（9:16） |
| 优点 | 风格统一、永远不会「穿帮」 | 酷、节奏感强 | 画面质感最好 |
| 缺点 | 人物比较简单 | 场景种类少，需要你写新的 | 要花时间生图，图之间风格要统一 |

## 混用建议（效果最好）

- **主歌剪影 + 副歌 AI 生图**：副歌换成精致大图，冲击力最强。
- **全片剪影 + 桥段霓虹**：情绪转折时换画风。
- **全片 AI 生图 + 片头片尾剪影**：开头结尾风格统一、中间精致。

## 各画风的代码在哪

- 剪影：`styles/silhouette/scenes.js`（《早早晚晚》19 个场景，时间写死，当参考改写）
- 霓虹：`styles/neon/scenes.js`（`neonStreet`、`synthRoad`、`rainWindow` 三个工厂，传参数直接用）
- AI 生图：`engine/fx.js` 里的 `imageScene`、`layerScene`，说明见 `styles/image-layers/README.md`
