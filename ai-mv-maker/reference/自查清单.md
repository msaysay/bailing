# 测试图自查清单（给用户看之前逐条过）

**歌词**
- [ ] 每一场的歌词都没有压在人物、太阳、月亮、窗户、招牌上
- [ ] 歌词没有低于 1550 像素（会被平台底部按钮挡住）
- [ ] 亮画面（白天、云海、雪）上白字看得清；看不清就换 `minimal`、压暗天空，或设 `dark: true` 用深色字
- [ ] 副歌标题句用了大号毛笔字（config 的 bigLine 填对了）

**画面**
- [ ] 主角在竖屏里至少 150 像素高，一眼能看到
- [ ] 树、房子、山没有被画面边缘切掉一半
- [ ] 同一场的两张测试图里，人物和镜头有在动（不是两张一样的图）
- [ ] 相邻两场的颜色没有跳得太突兀（除非是故意的白闪/换画风）
- [ ] AI 生图：图片铺满画面，没有露黑边；人物没有崩脸、怪手

**节奏**
- [ ] 第一场从第一句歌词前 1–2 秒开始，片名出现时没有歌词
- [ ] 副歌进来的那一场有大场面、有转场
- [ ] 片尾卡出现时歌已经唱完
