# 画画函数速查（engine/lib.js、engine/fx.js）

画面是 1080×1920，坐标 (0,0) 在左上角。场景函数签名：`function sXxx(ctx, T, A, t, u)`
- `T` 原曲秒数（让东西随时间动：`Math.sin(T)`）　`t` 场景内秒数　`u` 场景进度 0→1
- `A.kick` 鼓点（0–1，打鼓的那一下变大）　`A.env` 整体响度（副歌高）
- 时间小工具：`sst(a, b, x)` 平滑从 0 到 1；`lerp(a, b, t)` 插值；`easeOut / easeIO` 缓动；`clamp`；`hash(n)` 固定随机数

## 天空和光
| 函数 | 作用 |
|---|---|
| `sky(ctx, [颜色…], y0, y1, [位置…])` | 渐变天空，颜色从上到下 |
| `sun(ctx, x, y, r, 核心色, 光晕色, 强度)` | 太阳（带三层光晕） |
| `moon(ctx, x, y, r, 透明度)` | 月亮（带环形山） |
| `stars(ctx, T, 数量, 透明度, 只画到y, 种子)` | 闪烁的星星 |
| `shootingStar(ctx, 进度0–1, x0, y0)` | 流星 |
| `glow(ctx, x, y, 半径, 颜色, 强度)` | 一团光（叠加模式） |
| `rays(ctx, x, y, 条数, 长度, 颜色, 强度, T)` | 光束 / 耶稣光 |
| `cloudBand(ctx, T, 朵数, y0, y1, 最小, 最大, 颜色, 透明度, 种子, 速度, 底色)` | 一层会飘的云 |

## 地形和城市
| 函数 | 作用 |
|---|---|
| `ridge(ctx, 基线y, 起伏, 频率, 种子, 横移, 填充)` | 一层山脊（多层叠出远近） |
| `ridgeY(x, …同上)` | 山脊在 x 处的高度（让人站在山上） |
| `vgrad(ctx, y0, y1, 上色, 下色)` | 竖向渐变填充 |
| `skyline(ctx, 基线y, 种子, 横移, {minH, maxH, body, lit, win, winA, t})` | 城市天际线（窗灯会闪） |
| `water(ctx, T, y0, y1, 上色, 下色, 太阳x, 太阳色)` | 水面 + 波光 |
| `wetReflection(ctx, 地平线y, 强度)` | 湿地面倒影（neon 包） |

## 植物和人物
| 函数 | 作用 |
|---|---|
| `tree(ctx, 种子, x, y, 高, 颜色, T)` | 一棵剪影大树（会轻轻摇） |
| `pine(ctx, x, y, 高, 颜色)` | 松树 |
| `grass(ctx, T, 0, 根数, 最矮, 最高, 颜色, 种子, 摆幅, x=>地面y)` | 随风摆的草 |
| `figure(ctx, {x, y, h, dir, ph, pose, col, rim, pack, coat, hair, skirt, child, hat, staff, armL, armR, headTilt, lean, stride})` | 人物剪影。`pose`: walk/stand/sit；`ph` 步伐相位（`t*4.4`）；`rim` 轮廓光颜色；`pack` 背包；`child` 小孩；`armR: [肩角, 肘角]` 抬手 |
| `bird / flock(ctx, t, 只数, x0, y0, vx, vy, 颜色)` | 鸟群 |
| `umbrella(ctx, x, y, r, 颜色)` | 伞（neon 包） |

## 粒子和天气
`petals` 花瓣 · `snow` 雪 · `rain` 雨 · `motes` 萤火/光点 · `bokeh` 光斑虚化 · `embers` 火星 · `dust` 浮尘 · `rainGlass` 窗上的雨

## 特效和调色（fx.js）
| 函数 | 作用 |
|---|---|
| `lightLeak(ctx, T, 强度)` | 漏光（也可以在场景表里写 `leak: .4`） |
| `grade(ctx, 颜色, 强度, 模式)` | 调色（场景表 `grade: ['#ffb070', .15]`） |
| `letterbox(ctx, 1, 高度)` | 上下黑边（config 里 `letterbox: 140`） |
| `neonText / neonRect` | 霓虹字、霓虹框 |
| `shake(T, A.kick, 幅度)` | 鼓点抖动（场景表 `shake: 8`） |

## AI 生图动起来
```js
imageScene('assets/01.jpg', 'push', 'petals', { leak: .3, glowAt: [540, 800], rays: true })
layerScene({ layers: [{ src: 'assets/02.jpg' }, { src: 'assets/02_前景.png', depth: 1 }], move: 'left', particles: 'fireflies', grade: ['#ffb070', .12] })
```
`move`: push 推近 / pull 拉远 / left、right 横移 / up、down 升降 / still　`particles`: petals snow rain fireflies embers dust stars bokeh

## 场景表字段
`{ a 开始秒, f 场景函数, ly 歌词高度, x 转场秒数, fx 转场, lyric 歌词样式, lx 竖排歌词x, dark 深色字, leak 漏光, grade 调色, camera 运镜, shake 抖动, bigY 大字高度 }`
