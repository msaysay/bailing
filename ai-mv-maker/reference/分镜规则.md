# 分镜规则

## 怎么分场

- 一场 6–15 秒，覆盖一到四句歌词；3 分半的歌 15–20 场。太碎（一句一场）会晃眼，太长（20 秒以上一场）会闷。
- 从 `分场建议.txt` 开始改：它已经按歌词停顿并好了句、吸到了拍子上，还标了每段能量。
- **能量高的段（副歌）给大场面**，能量低的段（主歌、桥段）给安静、近一点的画面。
- 前奏只留 1–2 秒放片名；间奏超过 6 秒，给一个「空镜」（风景、天空变化、流星），不要黑屏。

## 画面怎么想

1. **讲故事，不翻译歌词**。歌词是情绪，画面是事件。
   - 「戒指戴上了手」→ 金色戒指绕着月亮画一圈
   - 「深夜把叹息关在门后」→ 门缝里的光慢慢合上，人坐在门边地上
   - 「三十六岁路还没走完」→ 公路边的年龄路牌从 18 一路掠过到 36
2. **一个主角贯穿全片**：同一个剪影特征（背包、长发、外套、伞），观众靠它认人。AI 生图时每条提示词都写同样的主角描述。
3. **一条线索串起来**：《早早晚晚》用「少年时的自己」：开头离家 → 中段回头看见他 → 结尾牵着他走向日出。找一个能「出现—消失—回来」的东西（一个人、一只纸飞机、一盏灯、一首歌）。
4. **颜色跟情绪**：主歌偏冷（夜、蓝、紫），副歌转暖（黄昏、日出、金色）；最后一次副歌最亮。
5. **画风只换一次**：在桥段或情绪转折处换一次（剪影 → 水墨、剪影 → 霓虹、代码画面 → AI 生图），制造惊喜。换太多次会乱。
6. **两次副歌用同一个构图**：第一次冷、散、下雨；第二次暖、聚、日出。观众认出来会被打动。
7. **结尾回到开头**：开头的地点、人物或物件再出现一次，给一个往前走的背影。

## 转场怎么选

| 转场 | 什么时候用 |
|---|---|
| `dissolve` 溶解（默认） | 同一段情绪里换场 |
| `white` 白闪 | 进副歌、情绪爆发、回忆闪回 |
| `black` 黑闪 | 情绪沉下去、深夜、结束一个段落 |
| `burn` 胶片烧 | 回忆、过去和现在切换 |
| `zoom` 冲进去 | 快歌、鼓点重的段落、从远景冲到近景 |
| `wipe` 擦除 | 时间流逝（白天到夜晚、季节变化） |

转场时长 `x`：慢歌 0.8–1.2 秒，快歌 0.3–0.6 秒。场景开头会自动吸到鼓点上（`snapToBeat`）。

## 歌词放哪、用什么样式

- 歌词高度 `ly`（画面 1080×1920，0 在最上面）：天空空的放 400–600；画面上半部分有东西放 1350–1500。**不要压在人物、太阳、窗户上。**
- 平台底部 300 像素会被标题和按钮挡住，歌词不要低于 1550。
- 样式：`glow` 逐字发光（默认）/ `karaoke` 卡拉OK 填色（快歌、说唱）/ `vertical` 竖排毛笔（古风、水墨、安静段）/ `minimal` 小字（画面本身很满，比如 AI 生图）。
