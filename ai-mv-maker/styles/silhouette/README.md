# 剪影插画

《早早晚晚》用的 19 个场景函数。它们按《早早晚晚》的时间写死（用歌曲绝对秒数 T），**做新歌时当参考改写**：
复制一个最接近你想要的场景函数到项目的 scenes.js，改名，把里面的 `T - 某个数` 换成第 4 个参数 `t`（场景内秒数）。

几个好用的：`sCampus` 黄昏大树下两人、`sTrain` 地铁车窗、`sChorus1` 山脊长镜头一天、`sField` 麦田回头、`sStreet` 雪夜街道、`sApartment` 公寓楼窗灯、`sRoad` 公路年龄路牌、`sDepart` 大落日奔跑、`sInk` 水墨、`sRoof` 天台、`sSummit` 云海山顶、`sLake` 湖边篝火、`sFinale` 日出公路。
