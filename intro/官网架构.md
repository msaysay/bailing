# 官网整体架构

两个站，一套视觉（墨黑底、荧光黄绿、DIN 数字），互相导流。公司站讲「我们能为你的团队做什么」，个人站讲「宁少是谁、卖什么」。

```

├── /                    首页                dist/company.html（本次交付）
│   ├── #believe         使命、愿景、四条价值观
│   ├── #who             三类客户：MCN、企业、超级个体
│   ├── #method          八道工序
│   ├── #products        四件工具

│   ├── #work            三种合作方式和交付流程
│   ├── #about           创始人
│   └── #contact         联系
├── /solutions/mcn       MCN 方案页          二期：李洋洋、蛋解创业两个案例展开
├── /solutions/enterprise 企业方案页         二期：八道工序展开，约读书房、词元引擎
├── /cases/…             单个案例页          二期：每个案例一页，放成片对比视频
```

## 导流关系

- 短视频、直播 → 个人站（人设承接）→ ¥0 免费包 → ¥980 星球 → ¥6,980 线下。
- MCN 和企业客户 → 个人站「专业 MCN 机构」卡片、或培训现场 → 公司站 → 项目制合作。
- 公司站「超级个体」一栏 → 个人站产品区，公司站不重复讲定价细节。

## 文件

| 文件 | 用途 |
|---|---|
| `dist/company.html`、`dist/personal.html` | 两张官网首页，单文件，直接上传服务器即可 |
| `dist/*.pptx`、`dist/*.pdf` | 公司介绍 12 页、个人介绍 11 页 |
| `assets/logo-*` | 标识：图形标和横版组合，深浅两版 |
| `src/build_html.py`、`src/build_deck.py` | 改文案改这两个脚本，重新生成 |
