# video-studio · 从创意到成片的视频生产线

目标：给一个想法，由 Agent（Claude Code / Codex）带着一组 Skill 和脚本，产出选题、口播稿、配音、分镜、素材、Remotion 成片、封面和发布文案，并把发布后的数据回流到下一期。

当前状态：**规划阶段**。还没有可运行的生产线，只有规划和拿进来学习的开源代码。
