# 约读书房 · 品牌包

| 文件 | 内容 | 能不能改 |
|---|---|---|
| `plate.png` | 纸纹底图（1080×1920） | 不改 |
| `logo.png` | 约读书房标志 | 不改 |
| `speaker.json` | 署名条上的名字和两行头衔 | **每期唯一可以改的品牌信息** |
| `glossary.txt` | 专名表，识别结果按它纠错 | 持续补充 |
| `rules.md` | 用户提过的、以后都适用的意见 | 持续补充 |
| `brand.json` | 颜色、字体、锁定项的对照表 | 只读 |

`plate.png` 和 `logo.png` 取自用户给的参考成片（纸纹底是多帧取中值后去掉文字修补的，标志是原尺寸裁出的）。用户有原始设计文件时，直接替换这两个文件即可，尺寸保持一致。

换出镜人：改 `speaker.json`。只想改某一期，在那一期 `edl.json` 里加 `"speaker": {"name": "…", "titles": ["…", "…"]}`。
名字 2 到 5 个字，头衔每行不超过 12 个字，最多两行。
