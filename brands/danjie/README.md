# 蛋解创业（抖音商业财经口播）

- 成片：竖屏 1080×1920，真人口播为底，口播全屏和素材版式交替。走「人为主」那条线（`talk-01` 到 `talk-04`）。
- 规则：`rules.md`——三条参考成片的节奏、版式坐标、字体、颜色、动效，逐项量出来的。
- 粗剪两件事要注意：出镜人一句话会录很多遍（`scripts/retakes.py`）；原片光不稳定（`scripts/grade.py`，脸不瘦）。
- 版式和花字的原型在 `cutflow/`（HTML 舞台 + ffmpeg 合成，能直接出片，29 秒样片验证过）。
  **还没有并进 `studio/` 的 Remotion 工程**：五种版式（口播全屏、通栏素材加圆头像、上卡下人、上人下卡、数据面板）
  和六种花字（关键词、清单、素材红字标注、章节角标、结尾金句、取景框）要按 `kit/talk.tsx` 的方式重写成一套读决定表的模板，
  做法参照 `studio/src/yuedu/`。并进去之前，蛋解的片子先用 `cutflow/` 出。
