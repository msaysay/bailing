# 蛋解创业 · 成片规则（对标拆解与设计规范）

样本：3 条成片（01 Roadster 3:25、02 中期选举 6:27、03 英伟达 4:57），均为 720×1280@25 的压缩上传版。
以下坐标已换算到 1080×1920 设计稿。

## 1. 节奏结构（三条共性）

| 项 | 观察 |
|---|---|
| 开场 | 0–3 秒口播全屏直接抛钩子（03 是人像抠出叠在新闻截图上），第 3 秒必切素材 |
| 版式轮换 | 口播全屏 ↔ 素材版式 交替，口播段单次 5–20 秒，素材段 5–15 秒；口播约占 45–55% |
| 素材切换 | 素材版式内每 1.5–3 秒换一个画面，基本一句话一个画面 |
| 景别 | 口播段内每 1–2 句做一次跳切放大/复位（约 1.0 ↔ 1.12） |
| 字幕 | 一行 ≤13 字，硬切、无动画；一句话 1–2.5 秒 |
| 花字 | 每 20–40 秒一个重点词；分点内容用清单；每个大段落有章节角标（02） |
| 结尾 | 口播全屏 + 黄色书法体金句 + 火焰/暖光特效 |

## 2. 版式（量自成片）

| 版式 | 素材区 | 主讲人 | 字幕基线 y |
|---|---|---|---|
| talk | — | 全屏 | 1215 |
| band（01） | 通栏 0,478 → 1080×964，上下白色光条 | 圆 r196，圆心 (540,372)，压在素材上沿 | 1532 |
| band 右头像（02） | 同上 | 圆 r150，圆心 (884,330)；左上章节角标 | 1532 |
| cardTop（02） | 圆角卡 34,248 → 1012×724，r28 | 矩形 206,1122 → 668×486，左上/右下取景角标 | 1040 |

背景：01 是深紫底 + 波纹线，02/03 是近黑藏青 + 中心微亮。本模板统一用后者（更新、更“财经”），
加了缓慢漂移的冷光和点阵，避免死黑。

## 3. 字体

| 用途 | 成片观感 | 本模板用字（可商用） |
|---|---|---|
| 口播全屏字幕 | 宽扁、方正的黑体，正体，白字深色描边 | 站酷庆科黄油体 |
| 卡片版式字幕 / 花字 | 粗斜体标题黑 | 优设标题黑 |
| 数字 | 粗几何数字 | 阿里妈妈数黑体 |
| 结尾金句 | 黄色毛笔行楷 | 马善政毛笔楷书 |

字号：口播字幕 72，卡片字幕 62，关键词 96，清单 66；超宽自动缩。描边统一 9–10px 深藏青 `#0a0d18`，外加一层柔和下投影。

## 4. 颜色

`金 #ffd84a`（重点词、关键词、数字单位）· `红 #ff3b30`（风险/对立面、素材标注）· `紫 #6d3fe0→#9a6bff`（章节）·
`底 #04060d / #0a1020 / #131f3d`。一屏内强调色不超过两种。

## 5. 动效（成片 → 本模板的升级）

成片的文字基本是硬切，只有关键词有 2 帧的模糊放大入场。升级原则：**快进、慢停、不抢话**——
入场 ≤ 0.35 秒，全部用 ease-out，停住后不再动，出场 0.16 秒淡出。

| 元素 | 成片 | 本模板 |
|---|---|---|
| 字幕行 | 硬切 | 0.14s 上浮 16px + 去模糊，几乎无感但不“跳” |
| 关键词 | 模糊放大 2 帧 | 逐字 35ms 错峰砸入（1.7→1 倍 + 去模糊）→ 下划线生长 → 一道逐字扫光 |
| 清单 | 逐条硬出 | 逐条左滑入 + 序号；新条出现时旧条压到 50% |
| 素材卡 | 硬切 | 遮罩 0.3s 揭开 + 卡片 0.9→1 缩放；同版式内换素材只做 0.16s 快闪 |
| 主讲人小窗 | 硬切 | 圆/矩形开窗 0.8→1 展开，取景角标画线生长 |
| 通栏光条 | 静态 | 从中心向两侧扫开 |
| 章节角标 | 静态贴片 | 横幅斜切擦入 + 序号回弹 |
| 数据 | AE 定制 | 面板上浮，数字 ease-out 滚动，对比条生长，因果链逐级点亮 |
| 结尾金句 | 火焰素材叠加 | 2.1→1 倍砸入 + 暖色闪光 + 0.3s 衰减余震 |
| 素材画面 | 静止或原速 | 统一带 3%（视频）/7%（图片）缓推，画面不“死” |

所有动效都是时间 t 的纯函数（`stage.js`），同一份 timeline 任何时候渲染结果逐帧一致。
