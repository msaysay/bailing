## 二、为什么做（v3 · 算法同质化 + 知识库叙事）

> v3 变更：不再提「一行代码都不懂」（加深不安全感），叙事重心改为——算法端大家都差不多，差距在知识库。

我是一个知识库的重度用户。这几年沉淀的笔记，客户、产品、行业、思考，全在里面——那是我的词汇表，我的上下文，我的第二大脑。

用过很多语音输入法之后，我发现一件事：**它们的算法端其实都差不多**——识别准确率早就不相上下。真正的问题是：**它不认识我**。我写的人名、产品名、行业黑话，它次次写错；我改了一百遍，它第一百零一遍还是错。要让它懂我，就得手动维护一大堆词库，操作量太大，没人坚持得下来。

但答案明明就躺在我的知识库里。所以我做了百灵，把它对接知识库，设计了一套方法体系：让输入法自己去读我的笔记，自己学会我的词，自己记住我的每一次修改。

**识别算法大家都买得到，但「懂你」这件事，只有接上你的第二大脑才能做到。**

## 三、技术逻辑（「它怎么做到越来越懂你」· 科普向，不堆术语）

标题：**它怎么做到「越说越懂你」**

一句话版：**它不靠你手动教，它自己从你的知识库和你的修改里学。**

四层逻辑，一层比一层像你：

1. **冷启动：你的笔记就是它的词表**
   装上后选你的 Obsidian 库（或任何装 .md 的文件夹），它在本地把笔记建成索引——一个字都不上传。你的行业、你的术语、你的上下文，它先通读一遍。

2. **说话时：先查笔记，再下笔**
   你每说一段话，它先在你的笔记里检索相关内容，让 AI 带着背景去理解——所以你行业里的黑话、语境，它听得懂。

3. **写对专名：知识库自动建词库 + 拼音纠错**
   它从你的笔记里自动挑出你的人名、公司名、产品名，建成专属词库。同音听错的，按拼音自动纠回正字——沈庭→沈婷、云衫→云杉、星尘→星宸。

4. **每次你改，它永久记住**
   出字后点一下「改错」，告诉它「听成了什么→应该是什么」。这条记住以后，下次、下下次，永远都对。**别的输入法你改一百遍还错，百灵改一遍就够。**

## 四、算力账（「用它要花多少钱」· 透明定价）

标题：**说满两个小时，识别费一块钱**

**百灵不收订阅费，作者也不经手一分钱。** 识别和润色的 API 费由用户自己付给**自己选择的**云服务商——用谁家的、花多少，都是用户自己的账号说了算。

- **语音识别（ASR）**：¥0.5 / 小时（按实际说话时长计，精确到秒，[MiMo 官方定价](https://mimo.mi.com/docs/zh-CN/price/pay-as-you-go)）
- **润色模型**：输入 ¥3 / 百万 tokens，输出 ¥6 / 百万 tokens

算一笔重度使用的账——假设**每天实打实说满 2 个小时**（绝大多数人远达不到）：

| 项目 | 用量 | 费用 |
|---|---|---|
| 语音识别 | 2 小时 | ¥1.00 |
| 润色（含知识库检索注入） | 约 150 次口述 | 约 ¥0.3 ~ 0.5 |
| **一天合计** | | **约 ¥1.3 ~ 1.5** |

**一个月重度使用 ≈ 40 块上下，一杯手冲咖啡的钱。**

推荐配置：
- **小米 MiMo（默认）**：mimo.mi.com 申请 key，一个 key 同时搞定识别和润色，配置最简单。
- **DeepSeek**：platform.deepseek.com，润色便宜快，OpenAI 兼容端点可换。
- **本地 Whisper**：不想用云的离线免费兜底。

配置方法：设置页粘贴 key → 测试连接 → 保存，两分钟，key 只存本机。

### 板块 4 · 四个不一样（特性卡片）

1. **改一次，以后都对**
   出字后点「改错」，教它「听成了→应该是」，永久记住。**这是它和所有输入法最不同的地方。**

2. **如实转译，还是梳理逻辑，你说了算**
   想逐字记录，它忠实转写；脑子比嘴乱的时候，打开「智能梳理」，它把颠三倒四的口述归并成分点、编号的清楚结构。开关在你手里。

3. **你的 key，你的数据，跟我没关系**
   识别和润色用你自己配置的服务商密钥（BYOK），录音、历史、词库、知识库索引全在本机。我不经手你一个字。

4. **在哪儿说，就像哪儿的话**
   它看你在哪个窗口说话：微信里口语一点，文档里书面一点，代码编辑器里保留英文和原样。场景自动切换。

## 六、建站与部署方案

- **形态**：纯静态单页（一个 HTML + 内联 CSS + 少量图片），零依赖、零构建。
- **设计**：跟产品同一套「宣纸墨朱 × 苹果极简」——宣纸底、墨色正文、朱砂点缀、白描鸟。
- **域名**：`49.gx.cn`（用户确认是 49.gx.cn，不是 49gx）。**首选路径式 `49.gx.cn/bailing/`**——与知更（`49.gx.cn/zhigeng/`）同一台机器同一套路，不用动 DNS 和证书，零风险不碰现有站点；子域名 `bailing.49.gx.cn` 需要另配 DNS + 证书，留作以后升级。
