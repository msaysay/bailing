# 对标拆解 · 「我要让 AI 取代我公司所有的岗位」第 1 集（内容岗）

横屏 1920×1080，6 分 21 秒，真人口播 + 三维桌面动画交替。用途：学它的**系列化结构**和**叙事生成逻辑**，补组件库。
方法：每秒一帧看完全片，放大看 36 个关键帧，口播转写。没有逐帧看动画。

## 一、它是怎么「生成」出来的（最值得学）

这条片子本身就是在讲 AI 怎么做出这条片子，所以生成逻辑是摆在台面上的。拆出来是四层：

### 1. 系列外壳：每集都一样的规则
| 元素 | 这一集的值 | 作用 |
|---|---|---|
| 主题 | AI 取代我公司的一个岗位 | 一句话说清系列 |
| 本集岗位 | 内容岗（写稿、剪辑、运营、编导） | 每集换一个，评论区投票选下一个 |
| 及格线 | 首周点赞破 1 万 | 让观众有理由看到下一集揭晓 |
| 惩罚 | 做不到就对着电脑鞠躬认错、念检讨 | 观众想看「翻车」 |
| 干预上限 | 老板出手不超过 3 次 | 每次出手都是一个小事件，画面上有计数 |
| 奖励 | 评论区抽神秘大礼包；片尾公开全部工具 | 互动和收藏 |
| 揭晓 | 开头说「你看到的视频是不是它做的，等会儿揭晓」 | 片尾回收 |

### 2. 每一件事都走同一个循环
片子分四件事（写稿、做开头动画、剪开头、整期按手册走一遍），每件都是：

**要求 → AI 交初版 → 老板打回（说清哪里不行）→ AI 想明白了（灯泡）→ 讲方法 → 成品 → 沉淀成规则**

例：写稿。要求「开头几秒讲完谁、要干嘛、赌什么、接下来怎样」→ 初版 25 秒废话 → 打回 → 它想通了，还多加了「主角、目标、背景、矛盾」→ 去拆头部博主的节奏 → 写了 3000 多行做法：前 5 秒必须有钩子，全片 40% 和 80% 处各放一个留人点 → 成稿。

这个循环就是一个可以复用的**分镜模板**，每一环有固定的画面：任务卡出场、初版画面、红色「打回」、灯泡、方法卡片、成品、规则写进手册。

### 3. 两个世界交替
- **真人世界**：老板坐在桌前讲，承担「定目标、打回、揭晓」。
- **桌面世界**：三维的木桌、一个吉祥物员工、小道具，承担「AI 在干活」。
- 两个世界用**画中画**互相串门：真人讲话时，左上角小窗放桌面世界；桌面世界里的电脑屏幕上放真人。
- 吉祥物在真人画面里也常驻右下角，按剧情做表情和小反应（火苗、感叹号、汗）。

### 4. 常驻信息层
- 左上角「岗位说明书」卡片，随剧情一行行加内容（岗位 → 职责 → 本期及格线 → 数据）。
- 每件事一张编号任务卡（01 写稿），带要打勾的小清单。
- 「出手 ≤ 3 次」三个圆点，用掉一次涂黑一个。
- 点赞计数器从 0 开始跳，结尾停在「?」留悬念。

## 二、它在制作上的做法（片中自己讲的）
| 做法 | 我们能不能用 |
|---|---|
| 按每秒约 4.7 个字的语速，开拍前算出全片时长；先排 55 个分镜，每个配什么画面、几秒 | 能，已加进稿子那一步 |
| 前 5 秒必须有钩子；全片 40% 和 80% 处各放一个留人点 | 能，已加进稿子那一步 |
| 先把全片画成一条情绪曲线（哪里得意、哪里被打回、哪里该笑），再按曲线挑音乐 | 能，做成了组件；选曲仍要人来 |
| 人一开口音乐自动压低 | 能，交付时用 ffmpeg 侧链压缩实现（待做） |
| 三维用 three.js 在网页里搭，再逐帧录成视频；金币用真实材质、摄影棚光照、物理引擎、每帧叠 40 次做动态模糊 | 三维这部分我们做不了同等质感，只做了二维的近似（金币雨、拖影） |
| 三维组件按最终尺寸画，不要小图放大 | 适用于我们所有组件，记入规则 |
| 别人家的标志不能重画，会侵权，所以打码或换成自己的东西 | 与我们「不用他人台标」的做法一致 |
| 4K 渲染一秒画面要算 80 多秒，租显卡 | 参考 |
