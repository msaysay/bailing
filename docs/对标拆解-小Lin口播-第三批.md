## 新量到的规矩

1. **一条片子有一块「主面板」贯穿全片。** 样本四是融资树图，样本五是对照表和三张税卡，样本六是那条指数折线。它每隔一两分钟回来一次，每次多填一点，最后填满当总结。排版式表时先定这一块。
2. **面板里的东西跟着口播一步一步出**，不是一次全摆上。一块面板停 10 到 40 秒，但每 2 到 4 秒就有一格在变。
3. **先「？」后揭开。** 树图、去向清单、对照表、选择题都是先摆出空位或问号，讲到再翻。
4. **小圆头像会挪位置。** 默认右上；面板占满上半屏时挪到左上（样本四树图）或者图的正下方（样本七）。
5. **开头三秒有三种开法**：虚字（样本五）、选择题（样本七）、直接上图表（样本六）。都不是先自我介绍。
6. **结尾右上角标「AI 制作」**（样本四最后一帧）。
7. **每期一个主题色，面板全跟它走。** DeepSeek 那期是蓝，韩股是红，迪士尼是黑加暗红，免税是紫和绿，旧手机是黑黄。人全屏的部分不变（白字幕、米色角标），变的只是面板。所以组件都留了 `color` 参数，排版式表时先定这一期的主题色。
8. **面板的「容器」会贴题材。** 讲手机那期，图表全装在一个白色手机壳里；讲电那期，牌子带电光描边。容器只换一种，全片统一。
9. **开头还有两种开法**：打字机标题压在黑白人物上（样本八「算力的尽头是电力」）、对决海报（样本九）。

## 横屏那条（样本十一）是另一套东西

「财富自由」是 16:9 横屏、12 分钟。它不用上面这些面板，用的是一套「推演板」：紫色底的定义板（关键词手绘划线、画圈）、「重要假设」板（空位先打问号、逐个填数）、一步步列式子的算式板（12X / 2.5% = 480X）、两张利率卡对比、「跳跃点 4 分 37 秒」这种章节戳。
这更像一个单独的骨架（横屏推演讲解），和现在竖屏的财经解读风不是一回事。**这次没有做**，要做得再下两三条同类的横屏片子一起拆。

## 怎么用

```tsx
import { Starfield, KeywordOrb, Treemap, QuoteCard3, PeopleFlow, Bubbles, MatrixBoard, StackBars, QuizBoard, GhostWord, ChestNumber, LineBoard, StepList, ChainCards, Waffle } from '../../kit/talk3';
```
每个组件上面有一行说明和参数。满屏面板要先垫 `Starfield`，同时把人切成小圆（版式表里那一段写 `bubble`）。`Bubbles`、`GhostWord`、`ChestNumber` 压在人全屏上，位置别盖脸。
看全部样子：`cd studio && npx remotion render src/index.tsx TALK3-DEMO out/talk3-demo.mp4`（45 秒，里面的字和数是示例）。

## 没做到的

- 这批组件只在演示里渲过，**还没有用进任何一条真实成片**。
- 尺寸是对着 540 宽的截图估的，没有逐像素量；动效时长（0.3 到 0.9 秒）是看联系表前后帧推的，没有逐帧数。
- 样本八到十一只看了前两分半，后半段可能还有没记到的版式；出现次数是在看过的范围里数的。
- 走势图面板演示里的数是编的示例。真用的时候要有数据来源；工作流现在**没有自动取行情数据的工具**，得用户给数，或者从他给的截图里读。
