# 频道宠物 · 成长规则（v0.1 草案）

每条视频左下角都有它。它从一颗蛋开始，**观众的互动让它长大，观众聊什么决定它长成什么样**。
这份文档分两部分：对观众公开的规则，和我们内部怎么算。

## 一、对观众公开的规则（可以直接念、直接贴置顶评论）

1. **它靠你们的互动长大。** 每条视频的点赞、评论、转发、收藏、新关注，都会变成它的经验值。经验满了就升级。
2. **它长成什么样，看你们聊什么。** 每期结束后，AI 读一遍评论区，判断大家的话更偏哪种气质，给四条成长路线加分。到了进化那一期，分数最高的路线胜出。
3. **每期都公开成长日志。** 这期涨了多少经验、AI 给哪条路线加了分、凭的是哪几条评论，全部贴出来。
4. **它还没有名字。** 第一期请评论区起名，点赞最多的名字当选。

## 二、成长阶段

| 阶段 | 等级 | 样子 | 画面上发生什么 |
|---|---|---|---|
| 蛋 | Lv 0–4 | 一颗带斑点的蛋，偶尔晃两下 | 每升一级裂纹多一点、光透出来更亮（三档：`egg1` `egg2` `egg3`） |
| 破壳 | Lv 5–9 | 一只顶着半个蛋壳的小团子 | Lv 5 那一期做一个破壳时刻 |
| 幼体 | Lv 10–19 | 长出小翅膀和两根冠羽 | |
| 成体 | Lv 20 起 | 按路线进化成四种之一 | Lv 20 那一期做「进化揭晓」，整期最大的事件 |
| 觉醒 | Lv 40 起 | （以后再设计） | |

## 三、四条路线

AI 读评论时判断每条有效评论更贴近哪一种，给对应路线加分。

| 路线 | 样子 | 评论区什么样会给它加分 |
|---|---|---|
| 机芯 | 蓝色，戴发光耳机，头顶天线 | 讲道理、看数据、聊技术和方法 |
| 金羽 | 金色，胸前一枚金币，大尾羽 | 聊生意、赚钱、机会、投资 |
| 焰心 | 红色，头顶和尾巴是火 | 情绪浓、观点冲突、吵起来了 |
| 星语 | 紫色，头顶一颗星，两颗小星绕着转 | 讲自己的故事、共鸣、温暖 |

**还有一条隐藏路线**：如果到进化那一期四条路线的分数都很接近（最高和最低差不到 10%），它会走一条谁也没见过的路。（形象等触发时再设计，先不公开细节，留悬念。）

## 四、内部怎么算

### 经验值
| 来源 | 每个算多少 |
|---|---|
| 点赞 | 1 |
| 收藏 | 3 |
| 评论（同一人同一期只算一次） | 5 |
| 转发 | 8 |
| 新增关注 | 10 |
| 喂食：评论里带上它的名字加一个🍓（同一人同一期只算一次） | 额外 +5 |

**升级**：从 Lv n 升到 Lv n+1 需要 `100 × (n+1)^1.5` 经验，越往后越难。这样小号的头几期也能看到它动起来，大号也不会一期就满级。可以在 `pet/config.json` 里改权重和曲线。

### 路线分
- 每期取评论区前 200 条有效评论（去掉纯表情、广告、重复）。
- **AI 判断**：助手逐条读，给每条打一个最贴近的路线（也可以判「都不像」不加分），并摘出最能代表每条路线的两三条评论当证据，写进 `pet/episodes/<期>.json`。
- **直接投票**：评论里写 `#机芯` `#金羽` `#焰心` `#星语` 的，每人每期算 1 票，但投票分**最多占这一期路线分的 30%**，免得被刷，AI 的判断始终是大头。
- 路线分只在进化之前累计；进化之后继续记录，留给以后的「觉醒」。

### 每期的固定动作
1. 片头：左下角宠物出现，弹一条「上期 +1,260 经验」。
2. 片中：它在左下角待机（呼吸、眨眼），讲到高能处可以给它一个小反应。
3. 片尾：经验条涨一截；升级的话放升级特效；接近进化时显示四条路线的分数条，吊胃口。
4. 发布后：把成长日志贴进置顶评论。

## 五、形象设计（定稿方向：浮石海豹，2026-11-16）

用用户提供的 `QuietCompanions.blend` 里的「03 浮石海豹」做基础（文件放在 `pet/assets/`，不进 git），由 `pet/seal.py` 在它上面优化：
- 透明底只留影子，镜头放低转正，左下角小尺寸也看得清脸。
- 身体换成奶白毛绒（每条路线微微染色），眼睛放大并加清漆高光，加腮红，头顶加一株小芽（成长线的记号）。
- 待机动画：呼吸、眨眼、拍鳍、甩尾，2 秒一循环。
- 阶段：**冰蛋**（小海豹缩成一团睡在冰蛋里，裂纹随等级变多变亮）→ **破冰**（坐在半个冰壳里）→ **幼崽** → **成体**四条路线：机芯（雾蓝 + 耳机 + 天线）、金羽（奶黄 + 抱金币 + 金叶）、焰心（蜜桃 + 头顶火苗）、星语（薰衣草 + 星星和两颗绕飞的小星）。
- 表情：平静（默认）、开心、吃惊。

渲染：`bash pet/render_seal.sh` 输出 11 个形态到 `studio/public/pet/<形态>/`；视频里用 `components/pet.tsx` 的 `PetHud` 放在左下角，演示见合成 `PET-DEMO`。

## 六、要留意的事

- **平台对「诱导互动」有规定。** 抖音、视频号都限制用利益或强制话术诱导点赞评论（比如「点赞过万就……」）。宠物是「互动会让它长大」的游戏设定，片中话术建议说「你们的互动会让它长大」，不要说「快点赞不然它就……」。具体尺度以平台最新规则为准，发之前你最好自己看一眼。
- **AI 判断要真做、要公开。** 说了「由 AI 判断」，每期就真的让 AI 读评论并贴出证据，不能事后手动改结果，否则一旦被发现，这个玩法的信任就没了。
- **数据从哪来**：点赞、评论数等从创作者后台抄（或截图给助手读）；评论原文可以从后台导出，也可以用 TikHub 拉（抖音有接口）。
- **形象是我们自己设计的**，可以随便改；名字留给观众起。
