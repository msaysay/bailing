# 对标拆解 · Yin's Broadcast「After Jensen 黄仁勋之后」

横屏 1280×720，6 分 09 秒，英文配音、中英双语字幕，人不出镜（事为主）。用途：补组件库。
方法：每秒一帧看完全片，再放大看 48 个关键帧；没有逐帧看动画过程，动效细节是按相邻帧推断的。

## 整体做法（比单个组件更值得学）

1. **12 个章节，每章换一套底色**：黑、米白（带半调网点）、红、荧光绿、蓝、墨绿。换章就换色，观众不看字也知道进了新话题。
2. **常驻外框**：四角角标；左上节目名加本期名；顶部中间一条带刻度的进度线；右上「NVDA · T+00:35.5」计时；左边缘竖排「02 / 12 · THE MARKET」。
3. **双语字幕条**：底部居中一个深色条，左侧一根强调色竖线；英文在上，念到的词变亮、没念到的发灰；中文在下，用强调色。
4. **每个画面左上有一行等宽小字**交代「这是什么数据、口径、来源」，右下或下方有来源脚注。
5. **粒子是统一的质感**：柱子、环、容器、K 线都由发光颗粒堆成，不是实心色块。
6. **数字用很瘦很高的字**（−14.3%、$820B），标题用很粗很紧的字，两种字对比强。
7. **章节页**：整屏底色 + 右侧巨大的描边序号 + 上下两行滚动的半透明标题。
