# 署名规则：三样东西，什么时候出现

署名不是一行字，是三样东西；内容都由用户填（`python3 scripts/sign.py set`，存在 `brands/<品牌>/fingerprint.json` 的 `sign` 里）。

| 哪样 | 是什么 | 放哪 | 字数 |
|---|---|---|---|
| 角标 | 频道的小牌子，像「小 Lin 说」 | 底部正中，字幕下面 | 2 到 6 个字 |
| 个人介绍 | 称呼 + 一行身份 | 上方靠左 | 称呼 2 到 6 个字，身份不超过 14 个字 |
| 简介 | 你是谁、讲什么 | 底部，压一条暗带 | 最多两行，每行不超过 18 个字 |

## 什么时候出现

都不是全程挂着。

| 哪样 | 出现 | 消失 | 依据 |
|---|---|---|---|
| 角标 | 人全屏的时候 | 切到素材、卡片、大字时收起来；开头钩子那几秒不出 | 小 Lin 的成片：角标压在人物画面底边，只在人全屏时有，切到素材带就没了（`docs/对标拆解-小Lin口播.md` 第 18 行，`docs/reference/xiaolin/样本三-原尺寸四帧.jpg`） |
| 个人介绍 | 开头钩子说完后，第一次人全屏时出一次，停 4 秒 | 4 秒后走；长视频每隔两分钟以上、新一章开头可以再出一次 | 子祺见微的成片：名字和身份只在「名片」那种版式里出现，不常驻（`docs/对标拆解-子祺见微.md` 第 40 行）。「钩子之后、停 4 秒」是电视和长视频里人名条的通行做法，对标片里没有量到确切秒数，这个数是我们定的 |
| 简介 | 最后 3 到 5 秒（片长的 8%），和称呼一起当片尾 | 片子结束 | 对标片的正片里都没有简介；放结尾是我们定的，理由是正片里它和字幕抢位置 |

时间由 `studio/src/kit/sign.tsx` 里的 `signPlan` 自动排；想先看一眼：`python3 scripts/sign.py plan --total 60 --full 0-8,14-30 --hook 3`。

## 例外：骨架自己的东西

- **横屏深度解读风**底下那条频道标志条是画框的一部分，全程都在。它算骨架，不算角标（对标片就是这样，见 `docs/reference/ziqi/对标-原尺寸四帧-1.jpg`）。
- **相框老板风**的署名条是相框的一部分，全程都在。

## 各骨架怎么配

| 骨架 | 角标 | 个人介绍 | 简介 |
|---|---|---|---|
| 财经解读风 xiaolin | 骨架自带的 `ChannelTag`（已经是人全屏才出） | `<Sign parts={['intro']}>` | `<Sign parts={['bio']}>` |
| 商业快节奏风 danjie | 在 timeline 里按同样的规矩排 | 同左 | 结尾毛笔金句之后 |
| 知识科普风 zhanpeng | `<Sign>` 三件都用，字体跟骨架用楷体（传 `font`） | | |
| 相框老板风 frame | 不另加，相框上有署名条 | 填进相框的署名条 | 片尾 |
| 访谈纪实风 interview | 不加（这个骨架左上角只放标志） | 被采访的人第一次出镜时出人名条，停 4 秒 | 品牌片尾 |
| 横屏深度解读风 ziqi | 底下的频道标志条（骨架） | 骨架自带的 `NameCard`（名片版式时出） | `<Sign parts={['bio']}>` |
| 电影分屏大字 split | `<Sign>` 三件都用 | | |
| 横屏新闻解读 news（不出镜） | 没有人全屏：角标只在开头 3 秒和结尾出（`full={[[0, 3]]}`，`hookEnd={0}`） | 不出 | 结尾 |

## 用法

```tsx
import { Sign } from '../../kit/sign';
// full：人全屏的时间段（秒），从版式表里取；不给就当全片都是人全屏
<Sign sign={{ badge: '宁少说', name: '宁少', title: '一行身份', bio: '一两行简介' }} total={时长秒} full={[[0, 8], [14, 30]]} hookEnd={3} hot="#D6FF3D" />
```
`hot` 用骨架的强调色（骨架允许换色时用个人指纹的主色）。粗剪后跑 `python3 scripts/sign.py demo --video <期的人物视频> [--wide]` 出三张图给用户确认。

## 不要做的

- 不替用户编身份和简介。他留空的那样就不出。
- 不把三样同时全程挂在画面上。
- 个人介绍不压脸：横屏在左上，竖屏在上方 12% 处；人头顶到那儿就往上挪（传 `introTop`）。
