# 流程总览（简化版，2026-11-18）

## 用法：一句话

把文件夹交给 Claude Code 或 Codex，说「**我想做一条视频**」。之后助手会一步步问你，每次只要一样东西。中途停了，下次说「**继续**」。

## 背后只有四个技能

| 技能 | 干什么 | 步骤 |
|---|---|---|
| `video-start` | 入口：问你出不出镜、查环境、建这一期 | — |
| `make-news` | 横屏解读片（人不出镜） | 稿子 → 声音 → 素材 → 做片 → 封面 |
| `make-talk` | 竖屏口播（人出镜） | 稿子与拍摄 → 粗剪 → 排版出片 → 封面 |
| `pet` | 右下角的频道宠物（可选，叠在成片上） | 结算成长 → 叠进成片 |

你要点头的地方：稿子、小样、成片、封面。其余助手自己做。

## 只有两样东西要你自己准备

1. **声音**：最好自己念（手机录就行）。不想念，就去 Fish Audio 把稿子贴进去生成，下载发给助手。
2. **TikHub 钥匙**（可选）：想让助手自动去网上找新闻画面，就去 tikhub.io 注册拿一串 API Token，存进文件夹最外层的「钥匙.txt」。没有的话，你自己发视频链接给它也行。

## 几个一条命令就跑完的工具（助手用，你不用记）

| 命令 | 做什么 |
|---|---|
| `scripts/doctor.py --fix` | 查环境，能装的自动装 |
| `scripts/episode.py new / status / done` | 建一期、看进度、记完成 |
| `scripts/voice.py <期> --tts` 或 `--audio 文件` | AI 配音或用你的录音 → 识别 → 对齐字幕 |
| `scripts/talk_prep.py <期> transcribe / cut` | 口播转写、剪口误、去水印、对齐 |
| `scripts/qc.py`、`scripts/talk_check.py` | 出片自查 |

建一期时会自动生成代码骨架（字幕、配音、外框、音乐都接好了）并注册好，助手只需要往里加画面。
