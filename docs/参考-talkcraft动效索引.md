## 怎么看、怎么用

- 预览片：`cd studio && npx remotion render src/index.tsx TALKCRAFT out/talkcraft.mp4 --muted`（约 10 分钟，每张卡下方有编号和文件名）。也可以在线看：https://vincentwei1021.github.io/video-talkcraft/
- 源码：`studio/src/talkcraft/cards/<文件名>.tsx`，由 `scripts/sync_talkcraft.py` 从 `vendor/video-talkcraft/template/cards/` 原样复制。每张卡只依赖 react 和 remotion，默认导出一个组件，画面 960×540、30 帧。
- 取用：把那张卡复制到自己这一期的目录，改文件顶部的 `CONFIG`（文字、颜色、时长），套一层 `transform: scale()` 放进画面。它内部用帧号计时，放在 `<Sequence from={帧号}>` 里，从我们的 `say()` 时刻起播。
- 每张卡的调参依据和坑：`vendor/video-talkcraft/references/cards/<文件名>.md`。
- 「我们库里相近的」一栏有内容时，优先用我们自己的组件（风格统一、时间用秒、可商用）；空着的是我们没有的，直接用这张卡。

我们库里没有相近组件的有 44 张，表里加粗。
