# 制作规则（审美手册）

每条规则都要能被检查。来源标在括号里；你提的意见判断为可复用的，追加到对应小节。

## 1. 画面要真

1. **一半以上的时长有真实画面**：新闻现场、发布会、建筑、产品实拍。真实画面可以垫在组件后面。（Fred《400万播放的财经视频，全是AI剪的》）
2. **同一个镜头全片只用一次。**（同上）
3. 每个素材登记来源、作者、许可、日期，记在本期 `sources.json`；没有许可信息的不用。
4. 图片当背景时必须有缓慢的镜头运动，不放死图。
5. 表现真实页面、公告、报表，用原件截图加聚焦，不手画假界面。（video-shotcraft）

## 2. 数据要真

1. **每个数字、每张图都标来源和日期**，标在画面里，不是只写在文档里。（Fred）
2. **查不到就写「未取得」**，不估算、不留空、不画示意曲线冒充数据。（Fred）
3. 图表用代码画，数字从数据文件读，不手敲进组件。
4. 来源之间数字不一致时取保守说法，并在事实核对表里写明。

## 3. 组件

1. 先看库里有没有，再决定新做；每期新做的不超过四成。（Fred：每期新做四成）
2. 一个组件只做一件事：人物关系、资金流向、地点推进、排名、时间线、对比、单数字。
3. 组件是中性的，颜色字体由 kit 决定；组件里不出现手写的颜色值和字号近似值。
4. 组件接四件套：口播锚点、素材原件、关注区域、参数。

## 4. 审美

1. **颜色**：底色 + 文字色 + 一个强调色 + 一个警示色，全片不加第五种。当前取值见本期 `kit.tsx`。
2. **不用廉价特效**：砸下、震屏、闪白、群发光、弹跳。（Fred）
3. **画面每 4–6 秒必须变一次**：换镜头、换组件、或主体发生明确变化。超过 6 秒没有变化算缺陷。（Fred）
4. 一个时刻只有一个主角；新元素只在语义段落边界进场。（video-talkcraft）
5. 时间只取自录音的逐字时间，不手写秒数。
6. 字幕不带句读，不带语气词，一行不超过 20 个字。
7. 入场比出场用力；关键信息落定后至少停 1 秒。（video-shotcraft）

## 4.5 画面字和字幕不重复

底部字幕已经把口播逐字给了观众，画面上再放一遍同样的句子是浪费，还显得像念 PPT。（2026-11-13 你的意见）

1. **画面字只放口播里没有的信息**：数字、名称、标签、来源、结构（第几件事）。口播的原句不上大字。
2. **能画就不写**：裁员用人形点阵熄灭，现金用格子划掉，占比用点亮的点，评论用上涨的气泡。先问「这句话的对象和变化是什么」，再决定画什么。
3. **关键句让字幕自己当主角**：全片最重的几句（设问、金句、论点）改用强调字幕——整句放大居中、逐词到点出现、重点词变色，同时隐藏底部字幕。同一时刻屏幕上只有一份这句话。
4. **强调字幕要克制**：每分钟不超过两句；用多了就不重了。
5. **底部字幕里的关键词变色**（年份、数字、专名），让字幕也在帮忙划重点。
6. 字幕字号比组件里的主信息小一档，位置固定，不抢画面。

## 4.6 组件不压人脸

实拍里有人脸时，面板、大字、图表都不能盖在脸上。脸是画面里最抢眼的东西，被盖住既难看，也显得不尊重画面里的人。（2026-11-13 你的意见）

1. **每个镜头先测人脸**：`scripts/faces.py` 给出每个片段里主要人脸的位置，存成本期的 `faces.json`。
2. **三种处理，按顺序选**：
   - **挪脸**：组件只占一侧时，在 `shots.json` 里给这个镜头写 `faceTo`（脸要去的位置），实拍层会放大并平移画面把脸挪过去。放大不超过 1.5 倍。
   - **挪组件**：脸在画面上方时，把组件排到下半部；脸在中间时，组件分到左右两边。
   - **换镜头**：组件要铺满全屏的段落（多栏对比、宽图表、居中大字），直接选没有人脸的镜头。
3. **人脸特写留给不需要组件的时刻**：只有字幕的呼吸段、强调字幕段，配特写最合适。
4. **路人的脸同样要避开**，并且尽量不选路人正脸很大的镜头。
5. **自查**：`scripts/facecheck.py` 按同样的算法重建「没有组件时的画面」，和成片里人脸框内的画面比，差异超过 15% 判为压脸。字幕条在底部，选镜头时就要保证脸不在画面最下面四分之一。

## 5. 出片前自查

每次整片渲染后跑 `scripts/qc.py <成片>`，全部通过才给人看。（Fred：出片前自己检查闪帧、黑场、文字重叠，每一秒截一张图看完才交）

| 检查 | 标准 |
|---|---|
| 黑场 | 没有 ≥0.2 秒的全黑 |
| 闪帧 | 没有只出现 1–2 帧就消失的画面突变 |
| 亮度突变 | 相邻帧平均亮度差不超过阈值 |
| 画面停滞 | 没有超过 6 秒的无变化段 |
| 每秒联系表 | 每秒一张，逐张看：文字重叠、出框、错字、空画面 |
| 响度 | 整片 −16 LUFS 左右，峰值不过 −1 dBTP |
| 压脸 | `scripts/facecheck.py` 无压脸镜头 |

机器通过、助手逐张看过、你认可，三件事分开记。

## 6. 迭代

1. 换风格前先拆头部同类视频：节奏、配乐、画面怎么安排，再拿自己的片一条条比。（Fred）
2. 意见指到秒；只改受影响的段。
3. 推翻旧规则是正常的，推翻时写明原因和日期。
