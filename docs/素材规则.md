# 素材规则：TikHub 是什么、和剪辑流程什么关系、怎么保证没风险

## TikHub 和这套工作流的关系

| | |
|---|---|
| 它是什么 | 一个第三方的数据服务（tikhub.io）：按关键词搜公开视频，取到没有平台水印的播放地址 |
| 和我们的关系 | **没有关系**。不是这套剪辑工作流的一部分，不是我们的服务，我们不从中收钱 |
| 收不收费 | **收费**。先充值，按调用次数扣，一条片子找素材大概几毛到几块。钱付给 TikHub，价格以它官网为准 |
| 不接行不行 | 行。不接照样能剪：用自己的素材、用组件画、用免费素材库，或者把视频链接直接发给 AI |
| 钥匙放哪 | 文件夹最外层的「钥匙.txt」，一行，只写那串字符。不要发在聊天里 |

## 它在剪辑流程里的位置

```
收原片 → 粗剪（去重录去口吃）→ 排版式（决定哪句话配什么画面）
                                      │
                                      ▼
                         备素材 ← 只有这一步可能用到 TikHub
                         第 1 档 自己的 ──┐
                         第 2 档 自己做的 ─┤ 不用问用户，直接用
                         第 3 档 明确授权的 ┘
                         第 4 档 新闻机构和官方账号 ┐ 要接 TikHub
                         第 5 档 抖音上别人的作品 ──┘ 要用户点头
                                      │
                         查（水印、台标、字幕）→ 裁（进这种风格的素材框）→ 记（来源）
                                      │
                                      ▼
搭画面 → 成片 → 发布包（提醒里写清哪些画面没有授权）
```

## 五档来源

| 档 | 来源 | 风险 | 怎么用 | 工具 |
|---|---|---|---|---|
| 1 | 自己的：自己拍的、自己的截图和录屏 | 没有 | 直接用 | 用户给文件 |
| 2 | 自己做的：组件画的图表、流程、文字卡 | 没有 | 直接用 | 组件包 |
| 3 | 明确授权的：维基共享资源（要署名）、Pexels（免费可商用） | 很低 | 按许可署名 | `footage.py find`；Pexels 要一个**免费**的钥匙 |
| 4 | 新闻机构和官方账号发在 X 上的原片 | 有 | 只截几秒当引用，裁台标，画面上标来源 | 要 TikHub；`footage.py find --level 4` |
| 5 | 抖音上别人的作品 | 最高 | 别处都没有才用，每条都要用户点头 | 要 TikHub；`footage.py find --level 5` |

## 「水印」这件事

说「有风险」，常见的是三种东西，处理办法不一样：

| 是什么 | 长什么样 | 怎么来的 | 怎么办 |
|---|---|---|---|
| 平台的跳动水印 | 抖音标加账号，在左上和右下之间跳，结尾还有一屏 | 在抖音 App 里点「保存到相册」 | **不用这种文件**。让用户发链接，或者走 TikHub：它取的是没有平台水印的原画 |
| 台标、角标、账号名 | 一直在某个角上不动 | 发布的人自己加的 | `footage.py check` 能查到；`fit` 会裁掉。裁不掉就换一条 |
| 烧在画面里的字幕、新闻横条、贴纸 | 在画面下半部分，内容一直在变 | 原视频自带 | 能裁就裁；占了三分之一以上就换一条 |

**没有水印不等于有授权。** TikHub 取的原画没有平台水印，但它仍然是别人的作品。所以第 4、5 档排在最后，用之前要用户点头，画面上要标来源，交片时要告诉用户。

## 各风格的素材放在哪、多大

| 风格 | 素材出现在 | 槽位 | 尺寸 |
|---|---|---|---|
| 财经解读风 | 素材带（人缩成右上小圆时） | `xiaolin-band` | 1080×842 |
| 横屏深度解读风 | 右侧素材窗 | `ziqi-window` | 1204×910 |
| 不出镜解读片 | 铺满垫底 | `news-full` | 1920×1080 |
| 相框老板风 | 相框中间的画面窗 | `frame-window` | 1440×1080 |
| 访谈纪实风 | 满屏空镜 | `tall-full` | 1080×1920 |
| 红顶双标题口播风 | 手机壳里的截图 | `redtop-phone` | 不裁 |
| 商业快节奏风、知识科普风 | 各自的流程里有自己的放法 | 写 宽x高 | 见各自的说明 |

## 检查做了什么、没做什么

`python3 scripts/footage.py check` 抽二十几帧，逐像素看「边缘在多少帧里都在同一个位置」：画面内容会变，叠上去的标不会变。只看四条边附近。

- 查得到：固定的台标角标、新闻横条、烧进去的字幕。
- 查不准：固定机位的画面（整个画面都不动，分不出哪些是叠上去的）；半透明的暗水印；只出现一两秒的标。
- 查不了：画面里是谁的脸、是不是别人的创作、有没有授权。

所以检查图一定要 AI 自己用看图工具看一遍。

## 交片时怎么告诉用户

`python3 scripts/footage.py ledger <素材目录>` 会按档位列出全部素材，并给出要转告的话：哪些要署名、哪些没有取得授权。这段话原样写进发布包的「发布前请看」。
