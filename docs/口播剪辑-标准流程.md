# 口播剪辑 · 标准流程（六种风格共用）

2026-11 把四条给不同人做的剪辑线（访谈、头部商业财经、健身科普、企业老板）和原来的小 Lin 式口播并成了一套。
五种风格的画面完全不同，但做法是同一套。这份文件写的是共用的那部分；每种风格自己的版式和数值在各自的技能里。

## 一、五种风格

| 风格 | 对标 | 适合谁 | 原片 | 剪辑决定写在 | 技能 |
|---|---|---|---|---|---|
| 财经解读风 `xiaolin` | 小 Lin | 财经、商业分析，要图表数据动效 | 竖屏 | 版式表 + 每期一份画面代码 | `xiaolin-talk` |
| 商业快节奏风 `danjie` | 蛋解创业 | 商业财经，信息密、素材多 | 竖屏或横屏 | `subs.txt` + `timeline.json` | `danjie-cut` |
| 知识科普风 `zhanpeng` | 张展鹏 | 健身、健康、科普 | 竖屏 | `分镜.json` | `zhanpeng-talk` |
| 相框老板风 `frame` | 约读书房 | 老板、创始人，要品牌相框 | 横屏 | `edl.json` | `frame-talk` |
| 访谈纪实风 `interview` | 天图通逊 | 访谈、采访、企业宣传 | 横竖都行，可多机位 | `script.txt` + `plan.json` | `tiantu-interview-cut` |

| 横屏深度解读风 `ziqi` | 子祺见微 | 国际局势、宏观经济，横屏长视频、分章 | 横屏 | 版式表 + 每期一份画面代码 | `ziqi-wide` |

登记表：`styles/talk-styles.json`（给程序读，产品里要给用户出选项就读它）。命令：`python3 scripts/talk.py styles`。

## 二、同一套六个阶段

```
收原片 → 清理 → 对齐 → 排画面 → 出片自查 → 声音和封面
          ↑可选：去重录、去口吃、调光      ↑可选：降噪、配乐、音效、字体
```

| 阶段 | 做什么 | 谁做 | 要用户确认 |
|---|---|---|---|
| 1 收原片 | 建期；出原片联系表，看机位、背景、水印、脸的大小；不合适当场说 | 脚本 + 助手看图 | |
| 2 清理 | 本机转写 → 机器找重录、结巴、语气词、长停顿 → 助手通读补漏 → （调光）→ 粗剪 | 脚本找，助手逐条复核 | ✔ 剪掉了哪些话 |
| 3 对齐 | 字幕断句（一行十二三个字以内、按语义断、不留标点），文字对到声音上 | 助手断句，脚本对时间 | ✔ 字幕文字（没有稿子的风格必须确认） |
| 4 排画面 | 逐句决定：人全屏、切素材、上卡片、出花字。写成一份**决定表**，脚本检查 | 助手写表，脚本校验 | ✔ 分镜或版式表、素材清单 |
| 5 出片 | 关键帧联系表 → 助手看图返修两轮 → 小样 → 成片 → 机器自查 | 脚本渲染，助手看图 | ✔ 成片 |
| 6 声音和封面 | 降噪、配乐、音效；封面 | 脚本 | 配乐和封面 |

四条线各自摸索出来、最后都一样的做法，就是这套流程的骨架：

1. **风格锁在模板里，每期只变一份决定表。** 助手不写渲染代码、不调字号颜色（财经解读风例外，它每期写画面代码）。
2. **时间只有一个来源：声音。** 决定表里写「第几行、哪个词」，秒数由脚本从对齐结果里换算。
3. **机器先找，助手复核，人最后点头。** 重录检测、口误建议、调光对比图、关键帧联系表都是给助手看的，看过才往下走。
4. **剪口一定要盖住。** 换景别、换版式或盖素材；各线的检查脚本都会拦。
5. **素材三个来源按顺序用**：用户给的 → 搜来的（TikHub，来源要登记）→ 生成的（卡片、插画、占位图）。缺素材不挡流程。
6. **先关键帧、后整片。** 关键帧一分钟出，整片要几分钟到二十几分钟。
7. **交付时说清三件事**：剪掉了什么；哪些素材是别人的或 AI 生成的；机器查不了的（口型、节奏、降噪和配乐的听感）请用户看一遍。

## 三、可选功能

`python3 scripts/talk.py options` 看总表，`--style <风格>` 看这种风格里每一项怎么开。

| 功能 | 默认 | 财经解读 | 商业快节奏 | 知识科普 | 相框老板 | 访谈纪实 |
|---|---|---|---|---|---|---|
| 去重录（留最后一遍） | 开 | `--auto-drop` | 自带 | 自带 | 自带 | 自带 |
| 去口吃和语气词 | 开 | `--auto-drop` | 结巴自带，语气词保留 | 自带 | 自带 | 自带（声学加文字两层） |
| 收紧长停顿 | 开 | 自带 | 自带 | 自带 | 自带 | 自带 |
| 人声降噪 | 关 | `--denoise` | `polish.py` | `polish.py` | 自带 | 自带 |
| 自动调光 | 关 | `--grade` | 自带（默认开） | `polish.py` | `grade.py` | `polish.py` |
| 轻磨皮 | 关 | `--beauty` | `--beauty` | `polish.py` | `grade.py` | `polish.py` |
| 配乐 | 关 | `polish.py` | 时间线里写或 `polish.py` | 分镜里写或 `polish.py` | 自带 | 自带（配三首出 A/B/C） |
| 音效 | 关 | 代码里加 | 自带 | 自带 | 没有 | 没有（这种风格不要音效） |
| 封面 | 开 | 有 | 有 | 有 | 自带 | 有 |
| 换字体包 | 关 | 有 | 有 | 有 | 有 | 有 |

三个哪种风格都能用的通用工具（做法是从四条线里提出来的同一套）：

- `scripts/retakes.py`：重录、结巴、语气词检测。只看字面，换了说法的重录要助手通读补。
- `scripts/polish.py`：降噪（按底噪自动选档）、调光（以脸部亮度为准）、配乐（给曲子、音乐库或代码合成，人声在时自动压低）。**降噪和调光用在剪好的人物视频上，配乐用在成片上**，都不改时长。
- `scripts/fonts.py`：共用字体库。

## 四、字体

`fonts/library.json`：59 款可商用字体（黑体、标题、圆体、宋体、楷体、书法、手写、数字），搭成 21 个字体包。
样张：`fonts/字体包样张.jpg`、`fonts/字体库总览.jpg`。

每个包四个角色：`sub` 字幕、`title` 标题和花字、`accent` 金句和大字、`num` 数字。五种风格各取所需：

| 风格 | 用到的角色 |
|---|---|
| 财经解读风 | sub → 字幕，title → 章节标题（组件库里的字仍是 MiSans） |
| 商业快节奏风 | sub → 口播字幕，title → 卡片字幕和花字，num → 数字，accent → 结尾金句 |
| 知识科普风 | sub → 字幕，title → 钩子和黄字，accent → 白色大字 |
| 相框老板风 | title → 三行标题和署名，sub → 字幕和贴纸 |
| 访谈纪实风 | sub → 字幕和关键词，title → 小标题和片尾标语 |

```bash
python3 scripts/fonts.py list --style frame        # 这种风格适合哪些包
python3 scripts/fonts.py preview --style frame     # 出样张给用户挑
python3 scripts/fonts.py use boss --style frame    # 套上；use default 换回原配
```

字体文件不进仓库，用到时从 npm 镜像和 Google Fonts 下载到 `studio/public/fonts/`。授权按各字体官方公开声明整理，都是可免费商用的；发布商业内容前请到出处核对一次。自己买的商业字体可以登记进字体库，不会被打包分发。

## 五、加一种新风格要做什么

1. 拆对标片，写 `style-spec`；模板里把样式锁死，定一份决定表的格式和检查脚本。
2. 在 `styles/talk-styles.json` 加一项（适合谁、要给什么、步骤、每个可选功能怎么开）。
3. 在 `.claude/skills/` 加它的技能；`make-talk` 的选风格表里加一行。
4. 字体接共用字体库：在 `scripts/fontlib.py` 的 `apply` 里加一段，`fonts/library.json` 的 `styles` 里登记角色。
5. `scripts/talk.py` 的 `recipe` 里加这种风格的命令清单。
