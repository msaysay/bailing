# 对标拆解 · 手势全息片

拆的是一条 20.4 秒的竖屏短片（576×1024，30 帧）：第一人称坐在电脑桌前，用手势操控一组悬浮界面，选好东西之后「砸」进一段卡点快切。只学结构和手法，不用它的画面、界面内容和音乐。

## 一、结构

| 秒 | 画面 | 手 | 声音 |
|---|---|---|---|
| 0–0.9 | 桌面全景，电脑屏幕前弹出一个圆头像泡 | 左手往前点 | 一声重音开场，然后很空 |
| 1.0–2.0 | 一块毛玻璃主面板从桌面飞起来，展开成头像 + 一排小组件 | 两手往两边拉开 | 呼啸声 |
| 2.2–5.0 | 镜头右转。一条金色发光飘带横穿画面，一串选项顺着它滑过，下面一个描边标签 | 右手来回划 | 4 秒起加入节奏 |
| 5.2–5.6 | 镜头转回，面板还悬在原处（钉在场景里） | | |
| 5.6–7.8 | 选中的那项落在桌垫上，金色光环一圈圈荡开；左边三个勾依次打上 | 右手点桌面，左手点三下 | 每个勾一声确认音 |
| 7.8–11.6 | 桌面上一摞蓝色圆盘，上面升起一个全息模型，旁边一个仪表在走；快满时变橙红 | 右手按住、拧 | 8 秒起更满，越来越密 |
| 11.6–11.8 | 画面碎开、往前冲 | 双手一推 | 上升音到顶 |
| 11.8–20.4 | 实拍素材卡点快切，大约 0.4 到 1.5 秒一刀：顶一下、色散、穿过圆洞、甩 | | 重拍落下，全开 |

## 二、量出来的数

- 速度：约 81 拍/分（听感是它的两倍，十六分音符很密）。**全息段正好四小节**，转场落在第五小节第一拍。
- 响度：0–4 秒最轻，4–8 秒一档，8–12 秒再一档，12 秒之后最满——三级台阶，不是渐强。
- 卡点段平均 1 秒一刀，最短 0.4 秒，最长 1.5 秒；一拍和两拍的镜头交替。
- 界面件从出现到站稳约 0.3 到 0.5 秒，都带一点回弹。

## 三、它为什么好看

1. **界面钉在场景里**：镜头转走，面板留在原地；转回来还在。这是「真的悬在那里」的来源。
2. **手在界面前面**：手挡住界面，而不是界面盖住手。
3. **每个动作都有回应**：手一点，立刻有东西弹出来，同时有一声音效。画面、手、声音三样同时到。
4. **前面慢、后面快**：前 12 秒一个长镜头不剪，攒着；后 8 秒一口气放出去。
5. **颜色只有三种**：毛玻璃的灰白、强调用的金黄、全息用的青蓝。快满时加一点橙红。

## 四、我们的做法

| 它的手法 | 我们怎么做 |
|---|---|
| 三维摄像机反求，界面放进三维空间 | 逐帧算镜头的平移、旋转、缩放（光流累加，能对上锚帧时拉回去防漂），界面按这个变换贴 |
| 手工逐帧抠手 | 手部关键点围出手，小臂按肤色沿手腕方向延伸，出一层带透明的视频盖回最上面 |
| 手工对动画关键帧 | 自动认点、划、捏、张开四种手势的时刻，照着排界面件 |
| 三维全息模型 | 圆盘 + 一块立起来的屏，屏里从下往上扫出成片 |
| 买来的曲子 | 程序合成：同样的四小节铺垫 + 蓄力 + 重撞 + 全开的结构，速度按转场时刻自动算 |
| 实拍素材 + 手工卡点 | 素材按拍数切，五种冲击效果 |

**做不到和原片一样的地方**：没有真三维，镜头大幅前后移动时界面的透视不会跟着变；肤色和桌面撞色时抠手会带碎块；全息件是平面的屏，不是三维模型。所以拍摄要求里写了：别走动、桌面铺深色垫子、动作做大做慢。
