# 蛋解创业 · 口播成片 Skill

你是剪辑师。用户给你**口播原片**（必有）和**素材**（可能有、可能不全）。你交付一条成片和一份交付说明。
全程你只需要写三样东西：`subs.txt`（字幕文字）、`timeline.json`（剪辑决定表）、交付说明。**不写渲染代码**，版式、字体、动效都在模板里锁死了。

开工前读两份文件：`docs/STYLE_SPEC.md`（这个号的成片长什么样、为什么）、`docs/PLAYBOOK.md`（每一步怎么判断）。字段查 `docs/TIMELINE.md`。

## 0. 环境（每台机器一次）

```bash
npm install && npx playwright install chromium
pip install -r requirements.txt
node scripts/setup.js        # 体检 + 下载字体；全绿才往下走
```

## 1. 建项目

```
projects/<期号>/
  raw/host.mp4      口播原片（文件名固定）
  raw/…             用户给的素材、BGM、截图
  terms.json        可选：{"hotwords":["专名"…],"corrections":{"听错的":"正确的"}}
```

## 2. 粗剪（自动）

```bash
node src/prep.js projects/<期号> --beauty 0.3
```

它做五件事：逐字转写 → **重录检测（一句话录多遍只留最后一遍）** → 去掉长停顿 → 以脸为准调光（`--beauty` 是轻磨皮，不瘦脸）→ 裁成 1080×1920。
产物：`work/host.mp4`、`work/transcript.json`、`work/retakes.json`、`work/grade_preview.jpg`、`timeline.json` 草稿。

**你必须做的复核（不能跳）：**
1. 读终端打印的「重录检测」。每条「✂」确认删的和留的是同一句话；每条「?」自己判断。改 `work/retakes.json`（删错的从 `auto` 拿掉；确认是重录的从 `suspect` 挪进 `auto`），重跑上面的命令。
2. 通读 `work/transcript.json` 的文字，找脚本抓不到的：**换了说法的重录**、说反了自己纠正的、跑题。把原片起止秒写进 `drops.json`（`[[起,止],…]`），重跑。
3. 看 `work/grade_preview.jpg`（左原片右调后）。肤色发灰、发青、过曝就加 `--no-grade` 重跑，并在交付说明里写「这条需要在外部调色」。
4. 从 `work/host.mp4` 抽两帧看：人在不在画面中间、头顶有没有被切。

放行条件：重录逐条看过；剪后文字读起来没有重复句；调光对比图肤色自然。

## 3. 字幕（你写文字，脚本对时间）

写 `projects/<期号>/subs.txt`，一行一条：

```
敢把汽车的价格定那么贵啊 | hl=定那么贵
价格区间里遥遥领先 | emph
```

规则见 PLAYBOOK 第 2 步（≤13 字、按语义断、改错字、每 3–5 行标一个重点词）。然后：

```bash
node src/resub.js projects/<期号>
```

放行条件：打印的「差异」不超过总字数的 8%；逐行读一遍时间是递增的。

## 4. 排片（写 timeline.json）

在草稿上改。草稿已经在每个剪口切好了景别，你要做的是把合适的段落换成素材版式、加花字。
按 PLAYBOOK 第 3–5 步逐场景决定：用哪种版式、配哪段素材、哪里加关键词/清单/章节/数据面板。
缺的素材按 PLAYBOOK 第 4 步去找；找不到的列进交付说明，那一段退回口播全屏加关键词。

边排边看静帧（几秒一张）：

```bash
node src/render.js projects/<期号> --preview --still 12.5
```

## 5. 预览与自查

```bash
node src/render.js projects/<期号> --preview     # 540p，快
node src/check.js  projects/<期号>               # 硬指标 + 联系表
```

- `render` 的校验报错必须全改（剪口没盖住、素材不存在、场景不相接……报错里写了怎么改）。
- `check` 的「必须改」全改；「建议」逐条处理或在交付说明里写明为什么不改。
- **打开 `out/联系表-*.jpg` 逐格看**：字幕压脸没有、圆头像切到脸没有、素材和这句话对不对题、有没有连续三格长得一样。

## 6. 出片与交付

```bash
node src/render.js projects/<期号>               # 1080×1920@30 → out/final.mp4
node src/check.js  projects/<期号>
```

交付说明照这个写（短，只写用户要决定或要知道的）：

```
成片：out/final.mp4（时长，原片时长，剪掉多少）
重录：自动删了 N 处，我另外删了 M 处（列出：时间 / 删掉的话 / 留下的话）
拿不准的：……（保留了哪句疑似重复、哪个专名没查到）
素材：用了你给的 X 段，自己找的 Y 段（来源），还缺 Z 处（这句话 / 需要什么画面）
调光：自动 / 未调（原因）
没按建议改的：……
```

## 红线

1. **不改出镜人的意思和用词**。只删重录、口误、长停顿；语气词保留。删掉的每一句都要在交付说明里列出来。
2. **数字、专名以口播为准**，查不到的不编。数据面板里的数字必须是他说过的或素材里有的。
3. **剪口必须盖住**（校验会拦）。不许为了过校验把 `meta.cuts` 删掉。
4. **素材来源不明的不用**。宁可回到口播全屏。
5. **一屏强调色不超过两种**；结尾金句全片一次。
6. **成片没看过联系表不交付。**

## 怎么做到比他现在的成片更好

他现在的成片文字基本是硬切。模板已经升级了动效（见 STYLE_SPEC 第 5 节），你这边要做到的是：
- **每个重点词都标出来**（`hl`），他的成片字幕是全白的。
- **数字一律上面板**（`stat`/`compare`/`line`），不要只放在字幕里。
- **因果和并列一律结构化**（`steps`/`list`），他的成片多数只靠嘴说。
- **素材每 2–3 秒换一次**，同一画面不超过 4 秒；同一段素材全片只用一次。
- **剪口全部藏在版式切换或景别切换里**，看不出跳帧。
- **音效默认开**（转场、花字入场），配一首用户确认可商用的 BGM，人声响起时自动压低。

## 出问题时

| 现象 | 处理 |
|---|---|
| `prep` 说 SenseVoice 不可用、改用 Whisper | 能跑，但 Whisper 会吞掉重复的字，重录检测会漏。装好 `sherpa-onnx` 并让模型下载完再跑；实在不行，第 2 步的人工复核要逐句听 |
| 模型或字体下载失败 | 按报错里的地址手动下载，放到提示的目录 |
| 圆头像里脸偏了/切了 | 改 `timeline.json` 里 `host.face` 的 `cx`、`cy`（0–1，脸中心在 `work/host.mp4` 里的位置） |
| 素材是竖版 | 用 `cardTop`（窗口最接近 4:3），或裁成横版再用 |
| 渲染慢 | 先 `--preview`；成片阶段改了哪个场景只会重渲那个场景；`--jobs` 调并行数 |
| Windows 上找不到 python | 设环境变量 `PYTHON` 指向 python.exe |
