# AI 剪辑师操作手册（给 Claude 的排片规则）

输入：`work/transcript.json`（逐字稿）、`timeline.json` 草稿、`raw/` 里客户给的素材清单。
输出：`subs.txt`、`timeline.json`，以及一份“缺素材清单”。每一步做完用 `--still` 或 `--preview` 自检。

## 第 1 步 · 审稿与粗剪
1. 看 `prep` 打印的「重录检测」和 `work/retakes.json`：逐条确认 `auto` 没删错（删掉的和留下的确实是同一句话）；`suspect` 逐条判断，是重录就挪进 `auto`。约定是留最后一遍；出镜人明说「用前一遍」的，把那条的 `range` 改成后一遍的起止。
2. 通读转写文字，找检测漏掉的：换了说法的重录（意思一样但字面差别大）、说反了自己纠正的、卡壳、跑题。把要删的原片时间段写进 `drops.json`（`[[起,止],…]`，原片时间），重跑 `prep`。判断依据是「意思重复且后一遍更完整、更顺」；拿不准就保留，并在交付说明里点出来。
3. 专名、数字、英文缩写核对一遍；反复出现的错字写进 `terms.json` 的 `corrections`，下一期自动生效。
4. 剪口：`prep` 把每个剪口记在 `meta.cuts`，草稿已在每个剪口硬切景别（1.0 ↔ 1.12）。之后排片时，剪口要么落在素材版式里（人很小，看不出跳），要么正好是场景交界并且换版式或换 `zoom`（差 ≥0.08）。渲染前会校验。景别只硬切；`push` 缓推只用在没有剪口的长句上。

## 第 2 步 · 字幕（subs.txt）
- 一行一条，≤13 字，按**语义**断，不在词中间断；语气词可留（这个号的口语感是特色），错字必须改。
- 每 3–5 行挑一个词标 `hl=`（数字、专名、反常识的词）；全片 1–3 句金句标 `emph`。
- 跑 `node src/resub.js <项目>`，看输出的“差异”数：明显偏大说明文字改多了或漏了句子。

## 第 3 步 · 分场景排版式
按“一个意思一个场景”切，场景边界对齐字幕行的起点。选版式的规则：

| 这段在讲什么 | 用什么 |
|---|---|
| 钩子、观点、情绪、转折、结尾 | `talk`（相邻两段 talk 之间换 `zoom`：1.0 ↔ 1.1~1.15） |
| 在描述一个看得见的东西/事件，且有横版视频素材 | `band` |
| 素材是图片、截图、地图、报道 | `cardTop`（素材为主）或 `cardBottom`（人为主、素材为证） |
| 出现关键数字、对比、因果链、走势 | `data` + `stat / compare / steps / line` |
| 念一段原话、公告、文件 | `data` + `quote` |
| 提到一篇报道、一张截图、一个 logo，但还想让人留在画面里 | `talk` + `image` 贴片（放在头的两侧上方，别压脸） |
| 进入新的大段落 | 该段第一个素材场景叠 `chapter` 角标 |

节奏约束：开场 3 秒内必须切一次画面；口播全屏单段不超过 20 秒；素材版式里一个画面不超过 4 秒
（同一版式连续多个场景、只换 `media` 即可）；全片口播全屏占比保持在 45–55%。

## 第 4 步 · 素材
1. 先用客户给的；每个 `media` 核对文件存在、时长够（不够会定格最后一帧）。
2. 没有的，列“缺素材清单”：`场景序号 / 这句话 / 需要什么画面 / 建议检索词`。
3. 自己找时的优先级：官方发布会/宣传片与新闻画面 > 可商用素材库（Pexels、Pixabay 等）> 用 `data` 面板或花字替代。
   不确定版权的素材不要用；实在没有画面，就别硬配，退回 `talk` + `keyword`。
4. 竖版素材放不进横版窗口时，优先用 `cardTop`（窗口更接近 4:3）。

## 第 5 步 · 花字
- `keyword`：一个场景最多一个，≤8 字，停留 2–3 秒，和字幕里的 `hl` 不重复同一个词。
- `list`：口播说“分几种/几步/几点”时用，每条 ≤8 字，`at` 对齐说到那一条的时刻。
- `label`：只放在素材上，用来点名画面里的东西（名词，不是句子）。
- `punch`：全片只用一次，放在最后一句。对应那行字幕设 `hide: true`。
- `image`：一次只放一张，宽 360–460，放在头两侧的上方空处；停 2–3 秒。
- 强调色：默认金色；只有“对立面/风险/第二项”才用红色。

## 声音
- 音效默认开（`audio.sfx`），由事件自动合成：换版式、关键词、清单每条、章节、图片卡、数据面板、结尾金句。觉得吵就把 `audio.sfxVolume` 调到 0.6。
- BGM 由用户给或确认可商用后放进 `raw/`，写到 `audio.bgm`。人声响起时自动压低，不用手调。没有 BGM 也能出片，但要在交付说明里提醒。

## 第 6 步 · 自检清单
- [ ] `render --preview` 校验无报错（剪口都盖住了）
- [ ] `node src/check.js` 没有「必须改」；「建议」逐条处理过
- [ ] 打开 `out/联系表-*.jpg` 逐格看：字幕不压脸、不压素材里的字；圆头像没切到脸；没有连续三格一样的画面
- [ ] 数字、专名与口播一致；面板上的数字都有出处
- [ ] `work/grade_preview.jpg` 肤色正常；不正常就告知「这条需要外部调色」，改用 `--no-grade`
- [ ] 交付说明里列了：删掉的每一句、拿不准的地方、缺的素材
