# 横屏深度解读风（子祺见微式）· 长视频成片

目标：**一条分章的横屏长视频，一半时间是画面在讲，主持人串场。**
开工前读 `docs/对标拆解-子祺见微.md`（两条真实成片的拆解，所有数值的出处）。有 `reference/` 目录的话（单独的工具包里带），先用看图工具看里面的联系表。

你（AI）负责：分章、断句、找口误、排版式表、找素材、做数据面板、搭画面。时间一律从声音里取，不手写秒数。
用户出面五次：**稿子和章节 → 剪掉了什么 → 版式表和素材 → 第一章小样 → 成片**。每次停下来只问一件事。

**先告诉用户工作量**：这种片子素材量大，两秒左右一个画面，十分钟的片子要两三百个画面。整片渲染要几十分钟。所以一定先做第一章给他看，定了再做后面的。

## 六步

| 步 | 做什么 | 命令 | 要用户确认 |
|---|---|---|---|
| 0 | 环境 | `python3 scripts/doctor.py --line talk --fix`；`python3 scripts/fonts.py install ziqi-default` | |
| 1 | 收原片，建期（没拍就先写稿） | `episode.py new … --line wide` | ✔ 稿子和章节 |
| 2 | 转写、找口误和重录、粗剪、对齐 | `talk_prep.py transcribe` → `cut` | ✔ **剪掉了哪几句** |
| 3 | 定章节名、排版式表 | 写 `03_制作过程/版式表.md` | ✔ **章节名、版式表、素材清单** |
| 4 | 备素材、做数据 | 放进 `studio/public/<代号>/footage/` | |
| 5 | 搭画面 → 第一章小样 → 整片 → 自查 | `remotion still / render`，`qc.py`，`wide_check.py` | ✔ **第一章小样**；✔ **成片** |
| 6 | 封面 | 横屏 | 封面和标题 |

每确认一步：`python3 scripts/episode.py done <期名> <步骤号> --note "做了什么"`。中断后 `python3 scripts/episode.py status`。

## 第 1 步 · 收原片，建期

```bash
python3 scripts/episode.py new <两位序号_主题> --line wide      # 完整仓库里用 talk.py new … --style ziqi 也一样
```
原片放到 `episodes/<期名>/01_输入素材/口播原片.mp4`。分章拍了好几条的，先按顺序接成一条（`ffmpeg -f concat`）。
再问三样：**频道名、主持人名字、一行身份**（名片和标志条上用）。

**还没拍**：问清讲什么、给谁看、多长，按下面的结构写稿。事实、数据要有出处，查不到的不写；涉及国际局势和宏观判断的，把「这是观点」和「这是数据」分清楚。给用户确认后把拍摄要求原样发给他。

稿子结构（量自两条成片）：
1. **开头直接抛核心问题**，不寒暄：「我们今天就想探讨一个核心的话题：……？」可以连着三四个设问。
2. **立一个概念**：咬住题目里的一个词讲清楚（「注意，我们用的是经济权力，不是经济总量」），配一个反例。这是全片的题眼。
3. **预告框架**：几张牌、几个错配、几个阶段。
4. **四到六章**，每章 1.5 到 3 分钟。**章节名是对仗的八个字，中间空一格**（「大国博弈 金融为核」）。
5. 每章：一句判断 → 一组数据 → 两三个例子 → 一个比方或故事 → 收一句。
6. 多用设问和口语：「那么为什么……呢」「你看」「注意啊」。
7. **结尾升华**，落在一句有分量的话上（兵法、典故、古诗都行），不求关注。

语速按 370 字/分算：8 分钟约 3000 字，12 分钟约 4400 字。

> 拍的时候：横着拍，一条 16:9；中景，腰以上；**人站在或坐在画面左边三分之一处**，右边留空（要开素材窗）；背景有内容但不乱（书架、黑板）；关掉相机水印；可以分章拍，说错了停一秒**整句重说**。

## 第 2 步 · 粗剪（确认点）

```bash
python3 scripts/talk_prep.py <期名> transcribe
```
它打印逐字时间，机器找到的重录、结巴、语气词，以及横屏原片的人脸位置（`FACE = {…}`，记下来）和粗剪要用的 `--vf`。
- 「自动删」逐条看；「待判断」对着上下文定；通读一遍找换了说法的重录。
- 长稿子识别错字多，**专名、数字、英文缩写逐个核对**。

```bash
python3 scripts/talk_prep.py <期名> cut --drop "你补的时间段" --auto-drop --vf "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080" [--grade] [--denoise auto]
```
没有稿子时它用转写结果生成 `script.txt`：校对错字，按章节加 `## 章节名`（**每章一个 `##`**，章节导航条靠它定时间），调整断句后再跑一次 `cut`。
断句：一行一句字幕，**不超过 16 个字**，按语义断，不留标点，数字用阿拉伯数字。

告诉用户剪掉了哪几句。

## 第 3 步 · 章节和版式表（确认点）

先定章节导航条：`前言 | 四到六章 | 结语`，章节名八个字左右。

再逐句排版式，写成 `episodes/<期名>/03_制作过程/版式表.md`（行号、这句话、版式、放什么、素材文件名）。

| 这一句在干嘛 | 版式 | 模板里 |
|---|---|---|
| 抛问题、下判断、转折、收束 | **主持人全景**；每段 5 到 10 秒，中间换一次景别 | `mode: 'full'` |
| 边讲边给一个例子，人还要在 | **主持人 + 右侧素材窗**，窗里两秒一换 | `mode: 'side'` + `Shots area="right"` |
| 一段较长的解释，画面为主、人为辅 | **素材窗 + 主持人名片** | `mode: 'card'` + `Shots area="left"` |
| 连着讲几个现象、几个地方 | **满屏素材**，两秒一换 | `mode: 'off'` + `Shots area="full"` |
| 同上，但这段话是主持人的评价 | **满屏素材 + 圆头像** | `mode: 'circle'` |
| 一章里分小点讲 | **满屏素材 + 小头像**，左上挂话题角标 | `mode: 'avatar'` + `TopicTag` |
| 一组数据连着讲 | **数据面板**：大数字加十格图标，或对比条 | `DataPanel`、`CompareBars` |
| 打比方、讲故事、讲历史 | **画框素材** | `Shots area="framed"` |
| 题眼、每章开头 | **大字标题卡**，一两秒 | `TitleCard` |
| 讲一个有名字的小节 | 满屏素材 + 左侧**竖幅** | `SideBanner` |
| 主持人说到关键词 | 身边弹一个**黑板字** | `PopWord` |

排完对一遍硬指标（成片后 `wide_check.py` 会量）：
- 主持人大（全景、带右侧素材窗）**三成到四成**；主持人小（名片、圆头像、小头像）**一成半到两成**；人不在**四成到五成半**。
- 平均 9 到 12 秒换一次版式；主持人全景一段不超过 30 秒；人不在一段不超过 55 秒。
- **每个剪口都要盖住**（`cuts.json` 里的时刻）：落在人不在或人很小的版式里，或在那一帧换景别（`zoom` 1 ↔ 1.2，`dur: 0`）。
- 素材两秒左右一个画面，同一个画面不超过四秒；同一条素材全片只用一次。
- **每个数字都上画面**（数据面板、对比条或黑板字），不要只放在字幕里。
- 每章开头有标题卡，章节条亮的是当前这一章。
- 第一句话在主持人全景上说，前 15 秒内切到素材。

把版式表**用大白话讲给用户**：章节是哪几个、每章大概怎么走、哪些数据做成面板、题眼是哪几个字，附上素材清单（要多少个画面、已经有多少）。问：「这样排可以吗？素材你来出还是我来找？」

## 第 4 步 · 备素材

放进 `studio/public/<代号>/footage/`，横的，1920 宽以上最好。来源按顺序：
1. **用户给的**。
2. **搜来的**：`python3 scripts/tikhub.py`（要 TikHub 钥匙），或用户发链接。每条登记来源，在 `Shots` 的 `credit` 里写「画面：谁 · 日期」。有别人字幕、水印、台标的不用。
3. **免版权素材站**的航拍、工厂、港口、城市、货币、地图空镜（让用户下载或给链接）。
4. **截图**：公告、报道、数据页，用 `fit: 'contain'`。必须真实存在。
5. **自己做**：数据一律用 `DataPanel`、`CompareBars` 或组件库的图表（`studio/src/components/`），不找图。

一段素材不够两秒一换时：同一条视频取不同时间点（`startFrom`），或把这一段改成主持人带右侧素材窗（窗里可以慢一点）。
缺素材不挡流程：先用纯色占位图出小样，列清单让用户补。**数据的出处要能说出来**，说不出来的数不上面板。

## 第 5 步 · 搭画面 → 第一章小样 → 整片（两个确认点）

在 `studio/src/episodes/<代号>/index.tsx` 里搭（骨架已生成）。**照抄 `studio/src/episodes/wide01/index.tsx`**，它把每种版式和挂件各用了一遍。引擎在 `studio/src/kit/wide.tsx`，每个组件上面有说明。

- 填 `CHANNEL`、`HOST`、`FACE`、`CHAPTERS`、`CHAPTER_AT`（每章第一行的 `at(行号)`）。
- 时间全部用 `at(行号)` 或 `at(行号, '词')`。
- 换字体：`python3 scripts/fonts.py preview --style ziqi` 出样张，`fonts.py use <包> --style ziqi`。

```bash
cd studio
npx remotion still src/index.tsx <代号> out/<代号>-k1.png --frame=<帧>                 # 每种版式各出一张
npx remotion render src/index.tsx <代号> out/<代号>-第一章.mp4 --frames=0-<第一章最后一帧>  # 先只渲前言和第一章
npx remotion render src/index.tsx <代号> out/<代号>.mp4                                 # 用户点头后渲整片
cd ..
python3 scripts/qc.py studio/out/<代号>.mp4
python3 scripts/wide_check.py studio/out/<代号>.mp4 --full-w <主持人全景时脸宽占比，站着约 0.08，坐着约 0.11>
```

`qc.py` 报的「亮度突变」落在素材换画面的时刻是正常的（素材就是硬切）；黑场、闪帧、画面停滞必须是空的。

**关键帧必须用看图工具看**，对着 `docs/对标拆解-子祺见微.md` 第三节逐条过，至少改两轮再给用户：
1. 右侧素材窗有没有挡住主持人的脸和手；圆头像有没有挡住素材的主体。
2. 字幕有没有压住素材里的字、有没有超出画面。
3. 素材和这句话是不是说的同一件事；数据面板上的数和口播是不是一致。
4. 章节条亮的是不是当前这一章；有没有连续几张关键帧长得一样。

选了配乐：`python3 scripts/polish.py studio/out/<代号>.mp4 --music auto --mood calm -o studio/out/<代号>-配乐.mp4`。

交付时说清：剪掉了哪几句；哪些素材是别人的（来源）、哪些是占位；每个数据的出处；机器查不了的——嘴型、剪口顺不顺、素材出现得早还是晚、降噪后人声闷不闷、配乐响不响。

## 第 6 步 · 封面

横屏，和成片同尺寸：主持人全景里挑一帧，压题眼的金色大字（不超过 8 个字），可以再加一行小字。给两版让用户选。

## 不能破的规矩

1. **不改出镜人的意思和用词**。只删重录、口误、长停顿；删掉的每一句都告诉用户。
2. **嘴型永远对声音**。
3. **时间只从声音里取**。
4. **不编造**：数据、引语、截图、出处以口播和真实材料为准；别人的画面写来源。这种题材尤其要分清数据和观点，数据面板上只放有出处的数。
5. **剪口必须盖住**。
6. **没看过关键帧不交付；没给用户看过第一章不渲整片。**
7. 「以后都这样」的意见改模板，并把规则写回 `docs/对标拆解-子祺见微.md`。
