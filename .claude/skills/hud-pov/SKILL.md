# 手势全息风 · 第一人称悬浮界面 + 卡点快切

成片分两段：
1. **全息段**（8 到 14 秒）：原片打底，界面件按手势一个个出来；手那一层盖回最上面，看着像手伸到了界面前面。
2. **卡点段**（6 到 10 秒）：全息段结束那一刻画面往前冲、过曝，「砸」进素材；素材跟着拍子硬切，每一刀带一种冲击。

你（AI）负责：看手势时刻表、排界面件、挑卡点素材、出配乐、渲染、自查。
用户出面三次：**拍之前对一遍分镜 → 看关键帧 → 看成片**。每次只问一件事。

## 开工前先告诉用户怎么拍（这一步决定成败）

| 要求 | 为什么 |
|---|---|
| 手机或运动相机固定在**胸前或额头**，竖屏，**超广角**（0.5×） | 要同时拍到桌面和两只手 |
| **1080p 60 帧或 30 帧，快门尽量快**（光线要足） | 手一糊就认不出来 |
| 桌面**不要和肤色接近**（原木色桌面铺一块深色桌垫）；别穿肤色的长袖 | 抠手靠肤色，颜色撞了会把桌子也抠进来 |
| 桌上留几样**有纹理的固定物**（电脑、键盘、桌垫上的字） | 界面靠它们「钉」住；纯色空桌面钉不稳 |
| 身体可以转，但**别走动**；转出去再转回来没问题 | 镜头运动只按平移、旋转、缩放算 |
| 一条拍到底，10 到 14 秒；动作**做大、做慢半拍、每个动作后停一下** | 好认，也好对界面 |
| 按分镜做动作（见下），想象面前真的有东西 | |

**默认分镜**（可以按用户的主题改词，动作顺序尽量留着）：

| 秒 | 手上的动作 | 画面上出什么 |
|---|---|---|
| 0–1 | 左手食指往前点一下 | 头像泡弹出来 |
| 1–2 | 两手从中间往两边一拉 | 主面板展开，悬在电脑上方 |
| 2–5 | 身体往右转，右手往左划两三下 | 金色飘带横穿画面，六个选项顺着它滑过 |
| 5–6 | 转回来，右手食指往桌面一点 | 选中的那一项落到桌面，光环荡开 |
| 6–8 | 左手食指点三下（上中下） | 三项打勾 |
| 8–11.5 | 右手张开按在桌面上方，慢慢拧 | 全息屏从圆盘上升起，进度旋钮从 0 走到 100 |
| 最后 0.3 | 双手往前一推（或一拍） | 砸进卡点段 |

## 五步

| 步 | 做什么 | 命令 | 要用户确认 |
|---|---|---|---|
| 0 | 环境 | `pip install mediapipe opencv-python numpy soundfile`；`cd studio && npm install`；字体 `python3 scripts/fonts.py install xiaolin-default`（要 HarmonyOS Sans 和 D-DIN） | |
| 1 | 对分镜、收原片、看懂它 | `python3 scripts/hud.py new <期名> --video 原片.mp4 [--start --end]` | ✔ 拍之前的分镜 |
| 2 | 排界面件、填卡点素材 | 改 `episodes/<期名>/plan.json`，`hud.py check` | |
| 3 | 配乐 | `python3 scripts/hud.py music <期名> [--seed 3 --key 43]` | |
| 4 | 关键帧 → 成片 | `hud.py sheet <期名>` → `hud.py render <期名>` | ✔ 关键帧；✔ 成片 |

没有原片也能先看界面动画：`hud.py demo <期名> && hud.py music <期名> && hud.py render <期名>`（替身背景，没有手）。

## 第 1 步 · 看懂原片

`hud.py new` 会在 `studio/public/<期名>/` 放四样东西：`base.mp4`（裁好的底片）、`hands.webm`（手和小臂，带透明）、`track.json`（每帧的镜头运动和手的关键点）、`moments.jpg`（手势时刻表），并打印每个手势的时刻、哪只手、位置。

**必须用看图工具看 `moments.jpg`**，再决定哪个手势触发哪个界面件。它认四种：点、划（带方向）、捏、张开。会有多报（「捏」最容易多报），挑分镜里对得上的用。

看两个数：
- 「看得到手的帧」明显少于总帧数 → 手太糊或出画太多，告诉用户补拍。
- 「能直接对上锚帧的比例」低于 20% → 桌面纹理不够或镜头走动了，界面会漂；可以用 `--anchor <秒>` 换一个更清楚的锚帧重跑。

## 第 2 步 · plan.json

这一期唯一要改的文件。时刻是秒；位置是 1080×1920 里的像素。

- `anchor: "world"`：钉在场景里。x、y 按**锚帧（默认第 0 帧）看到的位置**写——想放在电脑上方，就看第 0 帧里电脑在哪。
- `anchor: "screen"`：贴在屏幕上不动（飘带默认这样）。
- `follow: "R.palm"`（只有 dial 支持）：跟着手走。可选 `L` / `R` + `palm` / `wrist` / `index` / `thumb` / `middle`，`dx`、`dy` 偏移。

| 界面件 | 干什么 | 主要参数 |
|---|---|---|
| `avatar` | 头像泡 | `img`（放 `studio/public/` 下的路径）或 `name`，`size` |
| `panel` | 主面板：头像、名字、一句话、一排小组件 | `title` `sub` `slogan` `img` `tiles:[{k,v,hot}]` `from:[x,y]`（从哪飞来）`tilt:[俯仰,左右]` `w` `h` |
| `ribbon` | 金色飘带 + 顺着滑的选项 | `items:[…]` `label` `pick`（选第几个）`pickAt` `y` `speed` `gap` |
| `pick` | 选中项落在桌面，光环荡开 | `label` `r` |
| `checks` | 勾选清单，每项自己带时刻 | `items:[{t,text}]` |
| `dial` | 进度旋钮 | `t0` `t1`（从几秒走到几秒）`label` `done` `r` `follow` |
| `holo` | 全息屏：圆盘上立一块屏，从下往上扫出成片 | `src`（成片）`srcFrom` `t0` `t1` `w` `h` |
| `tag` | 一块文字标签 | `text` `hot` `size` |

`hudEnd` 是全息段结束（砸下去）的时刻，一般取原片最后一个动作那一帧。`bpm` 不用手填，`960 ÷ hudEnd`，脚本会自动改对。

`cuts` 是卡点段，一刀一条：`src`（`studio/public/` 下的视频）、`from`（从第几秒取）、`beats`（占几拍，1 拍约 0.7 秒）、`fx`、`fit`、`label`（左上角小标签）、`big`（中间大字）。

| fx | 效果 | 用在哪 |
|---|---|---|
| `punch` | 猛地顶一下再回来 | 第一刀、重拍 |
| `rgb` | 红蓝错开再合上 | 第二刀、换场景 |
| `whip` | 横向甩进来，带拖影 | 一拍的短镜头 |
| `iris` | 圆洞由小到大穿进去 | 一拍的短镜头 |
| `flash` | 白闪 | 最后一刀、最长的那条 |

`fit: "screen"`：横屏素材不裁，整块放在一个微微倾斜的屏里，后面是它自己的虚化。竖屏素材不用写。

**排卡点段的规矩**：第一刀 2 拍用 `punch`；中间夹一两个 1 拍的短镜头；最后一刀最长（4 拍）；相邻两刀不用同一种 fx；总共 6 到 8 刀、12 到 16 拍。

## 第 3 步 · 配乐

`hud.py music` 现场合成一条曲子：全息段四小节，一小节比一小节满，第四小节军鼓加密、上升音蓄力；转场那一下是一声重撞；卡点段鼓、808 低音、牛铃旋律全开。界面件出现的时刻自动打上音效（弹出、呼啸、确认、玻璃、上升）。**全是程序合成的，不用署名。**

`--seed` 换一套音色细节，`--key` 换调（MIDI 号，默认 43；往上加亮一点，往下减沉一点）。不想给某个界面件打音效，在它上面写 `"sfx": "none"`。

用户想用自己的曲子：放到 `studio/public/<期名>/music.wav`，然后**量一下它的速度和重拍**，把 `hudEnd` 对到曲子「砸」下去的那一刻（原片可以用 `--start --end` 重新裁）。

## 第 4 步 · 出片和自查

先 `hud.py sheet`，**用看图工具看 `episodes/<期名>/out/关键帧.jpg`**：
- 界面件有没有压住手要点的位置、有没有互相叠住
- 钉在场景里的件，镜头转走再转回来之后还在不在原处
- 手的边缘有没有带出桌面的碎块（有就让用户换深色桌垫补拍，或用 `hud_track.py --no-hands-layer` 不要手那一层）
- 卡点段每一刀的画面是不是有内容（别切到黑场或转场中间）

没问题再 `hud.py render`。交付时明说：**界面和手对得准不准、节奏和音乐的听感，机器查不了，请用户完整看一遍。**

## 不能破的规矩

1. 不照搬别人片子里的界面内容、人名、品牌标志。界面上的字和选项按用户自己的主题写。
2. 别人的片子只拿来学结构，不当素材进成片。
3. 没看过关键帧不渲整条，没看过成片不交付。
4. 抠手和跟踪有局限（见上），有问题先让用户按拍摄要求补拍，不要硬修。
