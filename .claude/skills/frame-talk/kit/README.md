# 约读书房 · 口播成片工具包

给一条横屏口播原片，出一条 1080×1920 的竖屏成片：固定相框（纸纹底、三行标题、署名条、标志），中间画面窗里是人、素材、贴纸、生成卡片和字幕。
由 AI 助手（Claude Code、Codex、Cursor 等能读文件、跑命令的助手）照着 `skills/` 里的说明一步步做，人只确认三次：文字、标题和版式表、成片。

成品长什么样：`episodes/14_约读书房_样片/04_成片/关键帧.jpg`。十三张生成卡片长什么样：`.claude/skills/frame-talk/steps/卡片总览.jpg`。

## 怎么用

1. 装好 Python 3.10+、Node.js 20+、ffmpeg。
2. 把这个文件夹交给 AI 助手，对它说（原片路径换成你的）：

   > 读 AGENTS.md，然后用这套工具把 `D:\video\口播原片.mp4` 剪成约读书房的竖屏成片。

3. 它会先装环境（第一次约下载 500 MB），然后依次找你确认：转写的文字 → 三组标题选一组、版式表 → 成片。

## 你能改的

| 想改什么 | 改哪里 |
|---|---|
| 署名条的名字和头衔 | `brands/yuedu/speaker.json` |
| 每期的三行标题 | 助手出三组，你选 |
| 配乐 | 把有授权的音乐放进 `brands/yuedu/music/`；不放就用代码合成的 |
| 识别老错的专名 | `brands/yuedu/glossary.txt` 加一行 |
| 以后每期都要遵守的要求 | 告诉助手，它会记进 `brands/yuedu/rules.md` |

底图、标志、版式位置、颜色、字体是锁定的。

## 目录

```
AGENTS.md            给 AI 助手的入口说明
skills/              四步操作说明（frame-00 到 frame-03）和卡片目录
scripts/             转写、口误检测、粗剪、对齐、降噪配乐、检查、渲染
studio/              Remotion 工程（版式引擎和卡片库在 src/yuedu/）
brands/yuedu/        品牌包：底图、标志、署名、专名表、规则、音乐库
episodes/            每期一个目录；14_约读书房_样片 是完整例子（不含视频文件）
docs/                设计说明
```

## 已知的限制

- Windows 上请把这个文件夹放在**不含中文和空格的路径**下（比如 `D:\yuedu-kit`），原片文件名可以是中文。
- 四分半的片子整片渲染约二十多分钟（4 核）。
- 助手听不到声音、看不到动态：降噪后人声有没有发闷、音乐会不会太响、口型和卡片出现的早晚，需要你看一遍成片。
- 「测评报告」「后台看板」「增长曲线」三张卡画的是示意图，右上角带「示意」角标；有真实截图时让助手换成「录屏放大」卡。
- 搜来的素材版权不归你，助手会列出来请你确认。
