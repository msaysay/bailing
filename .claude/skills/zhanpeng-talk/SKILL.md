# 张展鹏 · 科普口播成片

目标：**成片看起来和对标片是同一个剪辑师剪的。**
风格锁在模板 `studio/src/zhanpeng/` 里，每期只变一份数据 `分镜.json`，不写场景代码、不改模板里的数值。
你（AI）负责三件事：断句、排分镜、配素材。时间一律从声音里取，不手写秒数。

没看过对标片也能做：`reference/` 里有对标片的逐秒联系表和「对标 / 本模板」并排图（独立包里带，仓库里不带），**开工前用看图工具把它们看一遍**，心里有那条片子的样子再排分镜。

开工前读两份：`references/style-spec.md`（对标片拆解和每个样式的数值）、`references/board.md`（分镜表怎么写、每句话选什么处理）。
完整样例：`examples/分镜.对标复刻.json` 是把对标片原样排一遍的分镜表。

> 这是口播剪辑五种风格里的「知识科普风」。从 `make-talk` 过来的，期已经用 `talk.py new` 登记好了：`python3 scripts/talk.py recipe <期名>` 会打印带好参数的命令（第一条就是下面的 `zp.py new`），选了降噪、调光、配乐的话也写在里面（`scripts/polish.py`）。每个确认点做完记一下：`python3 scripts/episode.py done <期名> <步骤号>`。

## 一共六步，人只出面三次

| 步 | 做什么 | 命令 | 要他确认 |
|---|---|---|---|
| 0 | 环境 | `python3 scripts/zp.py setup` | |
| 1 | 收原片和文案，建一期 | `zp.py new` | |
| 2 | 文案对到声音上，粗剪 | `zp.py align` → `zp.py cut` | ✔ **剪掉了哪些话、字幕断句** |
| 3 | 排分镜 | 写 `分镜.json` → `zp.py board` | ✔ **分镜表和素材清单** |
| 4 | 备素材 | 按 `素材清单.md` 放文件 → `zp.py board` | |
| 5 | 看关键帧，再整片渲染，自查 | `zp.py stills` → `zp.py render` → `zp.py check` | ✔ **成片** |

上一步没确认不进下一步。每次停下来只问一件事，问完等他回答。

## 第 1 步 · 收原片和文案

问他要两样：口播原片（一条到底的那种，说错重说没关系）、定稿文案。
没有文案也能做：先建期，把识别稿 `script.draft.txt` 发给他改成定稿。

```bash
python3 scripts/zp.py new <期名> --video <原片路径> --script <文案.txt> --slug zp01
```

期名用「序号_选题」，例如 `01_生理期同步`；`--slug` 是英文代号，素材目录用它。

`new` 会生成 `out/原片联系表.jpg`，**用看图工具看它**。不合适的当场告诉他（成片会受什么影响，由他决定重拍还是将就）：
- 竖屏 9:16；人站着或坐着的中景，**脸宽占画面宽 20%–25%**，眼睛在上三分之一。脸太大，头像和花字都没地方放。
- 背景干净不动，胸口到腰这一段别有杂物——字幕和花字都压在这里。
- 说错了停一秒**整句重说**。半句半句补的，剪口会落在句子中间。

## 第 2 步 · 对齐与粗剪（确认点一）

**先整理文案的断句**：一行就是一句字幕。规则在 `references/board.md` 第 1 节，最要紧的三条——
一行不超过 13 个字；**要做成花字的词单独占一行**（「生理期会传染」「安全稳定」「圈子」）；不留标点。

```bash
python3 scripts/zp.py align <期名>          # 改过 script.txt 就重跑
```

它打印三样东西，原样转给他看：
1. 每行字幕和起点。
2. **剪掉的话**：原片里说了、文案里没有的（重说的前几遍、口误、题外话）。同一句说了几遍，自动留最后一遍。
3. 打 `←` 的行：这句没对齐好，多半是他念的和文案不一样。按他实际说的改文案，不要改他的意思。

问他：「剪掉的这几句对吗？有没有哪句想留前面那一遍？」想留别的那一遍，就把文案那一行改成那一遍的说法再对齐。
他点头后：

```bash
python3 scripts/zp.py cut <期名>
```

产出 `studio/public/<代号>/person.mp4`（剪好的人物视频）、`timing.json`、`cuts.json`、人脸位置和逐帧人脸轨迹（头像靠它追着头走）。它报的 ⚠ 要转告他。

## 第 3 步 · 排分镜（确认点二）

打开 `episodes/<期名>/03_制作过程/分镜.json`，照 `references/board.md` 逐句决定：这句是人全屏、切插画、上论文卡，还是出花字。
写完检查：

```bash
python3 scripts/zp.py board <期名>
```

- 报 ✗ 的是写错了（行号不存在、词在字幕里找不到），改完再跑。
- 报 ⚠ 的是不像对标片的地方（一张图停太久、人离场太久、剪口没盖住），逐条处理或想清楚为什么不处理。
- 通过后生成 `素材清单.md`。

把分镜讲给他听（不要把 JSON 贴给他）：按时间顺序说「第几句到第几句切什么画面、哪几个词做成花字」，再附上素材清单。问：「这样排可以吗？素材你来出还是我来想办法？」

## 第 4 步 · 备素材

`素材清单.md` 每行一个文件：文件名、用在哪句、要多长、画面要求。文件放进 `episodes/<期名>/01_输入素材/素材/`，文件名对上就行，图片视频都可以。

来源按这个顺序：
1. **他自己的**：实拍空镜（走路、训练、生活）、文献截图。空镜一定用他本人的画面，这是对标片里最有人味的一段。
2. **生成插画**：清单里的提示词直接可用（即梦、可灵、Midjourney 都行）。同一组图用同一句风格描述，一次出齐，不然画风对不上。能图生视频就把关键的两三张做成 3–5 秒的微动视频，对标片的插画是会动的。
3. **文献**：去期刊官网截标题、作者、摘要第一段。**文献必须真实存在、他在口播里确实引用了**，不编造出处。
4. 你有生图工具就直接生成后放进素材目录；没有就把清单交给他。

缺的素材不挡流程：渲染时用写着提示词的占位图顶上，小样照出。放进新素材后重跑 `zp.py board`。

## 第 5 步 · 关键帧 → 成片（确认点三）

```bash
python3 scripts/zp.py stills <期名>      # 每个场景、每处花字各一张，拼成联系表
```

**必须用 Read 看联系表**（`episodes/<期名>/out/关键帧联系表-*.jpg`），对照 `references/style-spec.md` 末尾的清单逐条过：头像有没有挡住插画的主体、花字有没有压脸或出框、黄字落在浅色背景上看不看得清。有问题改分镜（换 `pip` 的左右、换花字类型、换图），不要改模板。

```bash
python3 scripts/zp.py render <期名> --preview              # 半尺寸小样，先发他看节奏
python3 scripts/zp.py render <期名>                        # 成片：episodes/<期名>/out/成片.mp4
python3 scripts/zp.py render <期名> --from 20 --to 30      # 只重渲一段
python3 scripts/zp.py check <期名>                         # 黑场、闪帧、响度
```

交付时说清楚：
- 剪掉了哪几句；哪些素材是 AI 生成的、哪些是占位图还没换。
- 机器查不了的：嘴型对不对、剪口顺不顺、花字出现得早还是晚。「这几处我没法听和看动态，请你看一遍。」
- 转场和花字带很轻的音效（分镜表里 `"sfx": false` 可关）；没有配乐（对标片有轻配乐）。他给了音乐文件就放进素材目录，在分镜表里写 `"music": "文件名"`。

### 出片前自己先改两轮

关键帧不是看一遍就过。每一轮：看联系表 → 对着交片清单和 `reference/` 的并排图挑出最不像的三处 → 改分镜或换素材 → 重出。至少做两轮再给他看。最常见的三个毛病：
1. **花字太多**。对标片 57 秒只有 10 处，平均五六秒一处。删到每处都有理由。
2. **插画和口播对不上**。一张图要正好画着这一句在说的东西，不是「大概相关」。对不上就重写提示词重出，不要将就。
3. **头像挡住了插画的主体**。换 `pip` 的左右，或者让提示词把主体放到另一侧。

他提的修改，属于这一期的改 `分镜.json`；属于「以后都这样」的，改 `studio/src/zhanpeng/theme.json` 或模板，并把规则写回 `references/`。

## 不能破的规矩

1. **时间只有一个来源**：声音。分镜表里只写行号和词，不写秒数。
2. **字幕是他的原话**：只改错别字和断句，不改意思、不替他加话。
3. **嘴型永远对声音**：人物画面只来自和声音同一时刻的原片。
4. **不编造**：文献、数据、出处查不到就不上画面。
5. **样式不在分镜里调**：颜色、字号、位置都在模板里。觉得哪里不像对标片，先对照 `style-spec.md`，确实要改就改模板并说明。
6. **人别消失太久**：插画场景默认带头像；人完全不在画面的时间不超过全片四分之一。

## 文件索引

- `references/style-spec.md` 对标片逐段拆解、样式数值、交片清单
- `references/board.md` 断句规则、分镜表字段、每句话选什么处理
- `examples/` 对标片的文案和分镜表
- `scripts/zp.py` 总入口；`scripts/zplib/` 对齐、分镜解析、人脸和抠像
- `studio/src/zhanpeng/` 模板（合成名 `ZP`），`theme.json` 是全部可调的数，`fonts.json` 是字体库
- 换字体：`python3 scripts/zp.py fonts --preview` 出样张挑，规则见 `style-spec.md` 第 4 节。默认的寒蝉正楷最接近对标片
- 这条线建在视频生产线上：识别用 `scripts/asr.py`，自查用 `scripts/qc.py`，时间格式同 `timing.json`，生产线的说明见 `docs/流程总览.md`
