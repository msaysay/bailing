# 交给别的 AI 跑：环境与排错

## 需要什么

| 项 | 要求 |
|---|---|
| 系统 | macOS、Linux、Windows 都行；不需要显卡 |
| 软件 | Python 3.10+、Node.js 20+、ffmpeg（含 ffprobe） |
| 网络 | 第一次要下识别模型（GitHub，约 160MB）和 Remotion 的浏览器内核（约 100MB） |
| 磁盘 | 2GB 空余 |
| 能力 | 能跑命令、读写文件、**能看图片**（看关键帧联系表）。不能看图的 AI 只能出片，没法自查像不像 |

```bash
pip install -r requirements.txt
python3 scripts/zp.py setup        # 下模型、装渲染依赖、查字体；全是 ✓ 才往下走
python3 scripts/zplib/selftest.py  # 对齐算法自测，应输出「6 项全部通过」
```

## 一条片子要多久（4 核机器）

转写 10 秒内；粗剪约半分钟；关键帧每张 4–5 秒；57 秒的片子半尺寸小样约 4 分钟、全尺寸约 5 分半。

## 常见问题

| 现象 | 原因和处理 |
|---|---|
| `setup` 报缺识别模型 | 网络下不到 GitHub。手动下载 `setup` 打印的那个地址，解压到 `~/.cache/video-studio/`（解压后里面有 `model.int8.onnx`） |
| 渲染失败，提到 browser / chrome | 没有显示器的 Linux，或浏览器内核没下到。装一个 chrome-headless-shell，设环境变量 `ZP_BROWSER=<可执行文件路径>` 后重试 |
| 渲染失败，提到缺 `lib*.so` | Linux 缺图形库：`apt-get install -y libnss3 libatk-bridge2.0-0 libgbm1 libasound2 libxkbcommon0` |
| 论文卡没有虚线人像 | 没装 mediapipe，或 Linux 缺 `libegl1`（`apt-get install -y libegl1 libgles2`）。不装也能出片，只是退成不抠像 |
| `align` 很多行打 `←` | 文案不是这条原片的，或他念的和文案差得多。打开 `script.draft.txt` 对照着把 `script.txt` 改成他实际说的 |
| `align` 说「剪口超过每 10 秒一个」 | 原片口误多。成片会碎，如实告诉他；别为了少剪口留下口误 |
| 字幕和嘴对不上 | `cut` 时报了「剪后时长和预计差得多」。多半是原片帧率不稳（手机可变帧率），先 `ffmpeg -i 原片 -r 30 -c:v libx264 -crf 16 -c:a aac 新原片.mp4` 再建期 |
| 黄字看不清 | 落在浅色衣服或亮背景上了。换花字类型（`scatter` 改 `bullets`）、换 `side`，或把这句放进插画场景 |
| 头像露出硬边或太小 | 原片里人拍得太近（`cut` 会报脸宽占比）。能重拍就重拍；不能就少用带头像的场景，多用铺满的插画加 `"pip": "none"` |
| 横屏原片 | 能做，会以人脸为中心裁成竖屏。清晰度下降，花字位置按竖屏算 |
| 头像或花字位置想整体挪 | 只改 `studio/src/zhanpeng/theme.json`（字幕高度、头像位置和大小、钩子字号），不要去改组件里的数 |

## 没有生图能力时

流程不会卡住：缺的素材用写着提示词的占位图出小样。把 `素材清单.md` 交给人，他用即梦、可灵、Midjourney 按提示词出图，文件名对上放进 `01_输入素材/素材/`，重跑 `zp.py board` 和 `zp.py render`。

## 有生图、图生视频能力时，可以做得比对标片更好

- **插画动起来**：每个场景挑最关键的一张做 3–5 秒图生视频（篝火跳动、信号沿神经上行、人群走动），文件名同名换成 `.mp4` 即可，模板会自动按视频播。
- **一组图一致**：同一场景的几张图用同一张参考图或同一个种子，只换景别。
- **主体避开头像和字幕**：提示词里写明「画面左上角留空」「画面三分之二高处一带留空」。
- **文献用真截图**：到期刊官网截首页，比生成的假论文可信得多。查不到原文就不用论文卡。
