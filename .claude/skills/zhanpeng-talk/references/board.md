# 文案断句与分镜表

## 1. 文案怎么断句（`script.txt`）

一行就是一句字幕。对齐程序会把每一行对到他念这几个字的时间上。

- **一行不超过 13 个字**，按意思断，不留标点（行尾的问号可以留，不上屏）。超长的行会被自动拆，但自动拆不如你拆得好。
- **要做成花字的词单独一行**。花字是按「行」来顶替字幕的：
  - 钩子句单独一行：`生理期会传染`
  - 要上黑底黄字卡的结论单独一行：`安全稳定`
  - 要做白色大字的词单独一行：`圈子`
  - 并列词合成一行：`饮食 作息 情绪压力`、`内分泌 情绪 还有生育节奏`
- 只写他真的要留在成片里的话。原片里说了但文案里没有的，都会被剪掉。
- 用字以他念的为准。他把「调节」念成了「调整」，文案就写「调整」。
- `#` 开头的行是备注，不参与。

## 2. 分镜表的结构（`分镜.json`）

```json
{
  "title": "这一期的题目（只做记录）",
  "music": null,
  "camera": "auto",
  "scenes": [ … ],
  "overlays": [ … ]
}
```

`scenes` 是「画面换成什么」，`overlays` 是「字幕之外再压什么字」。两者都没写到的时间，就是人全屏加字幕。

### 定位：`from` 和 `to`

不写秒数，写字幕。四种写法：

| 写法 | 意思 |
|---|---|
| `5` | 第 5 行字幕（行号看 `zp.py align` 打印的表） |
| `"15:气味"` | 第 15 行里「气味」这个词被念到的那一刻 |
| `"下丘脑就像"` | 直接写一段字幕里的字（全片只出现一次时可用） |
| 省略 `to` | 到 `from` 这一行结束 |

`from` 取那一行（或那个词）开始的时刻，`to` 取那一行（或那个词）结束的时刻，所以 `"from": 5, "to": 10` 是第 5 行开头到第 10 行结尾。

### scenes

| 字段 | 取值 | 说明 |
|---|---|---|
| `type` | `illustration` 插画 / `broll` 外景空镜 / `paper` 论文卡 / `card` 黑底黄字卡 | 必填 |
| `from` `to` | 见上 | 必填 |
| `id` | 任意短名 | 报错和关键帧文件名里用，建议写中文短名 |
| `shots` | `[{asset, from, motion, prompt, marks}]` | 一个场景里依次出现的几张图或几段视频。只有一张时可以直接在场景上写 `asset` 和 `prompt` |
| `pip` | `left` / `right` / `none` | 头像位置。插画默认 `left`，其余默认 `none` |
| `frame` | `card` / `full` | 卡片式留边，或铺满。默认 `card` |
| `transition` | `ink` / `fade` / `blur` / `cut` | 进场。不写时：第一个卡片式插画用墨迹，其余插画淡入，别的硬切 |
| `out` | `blur` / `cut` / `fade` | 出场。插画默认带模糊回弹 |
| `text` | 文字 | 只有 `card` 用；不写就用这一行字幕 |

shot 的字段：

| 字段 | 说明 |
|---|---|
| `asset` | 素材文件名（放在 `01_输入素材/素材/`）。扩展名可以和实际文件不同 |
| `from` | 这张图从哪一行开始；不写就在场景里平均分 |
| `motion` | `zoom-in` `zoom-out` `pan-up` `pan-down` `pan-left` `pan-right` `still`。不写就推拉交替；视频默认不动 |
| `prompt` | 这张图要什么（会写进素材清单，也是生图提示词） |
| `marks` | `[{x, y, r}]` 图上跳动的红色光晕，坐标是 0–1 的比例 |

### overlays

| `type` | 样子 | 必填 | 底部字幕 |
|---|---|---|---|
| `hook` | 红色大字 | `from` | 这一行不显示，上一行留着变暗 |
| `question` | 顶部黄色问题条 | `from` `to` `text` | 期间不显示 |
| `float` | 头旁边飘一两个黄字 | `from` `text` | 期间不显示 |
| `scatter` | 身体周围弹出几个黄字词 | `from` `items` | 这一行不显示，上一行留着变暗 |
| `flow` | 「甲 ▸▸ 乙」 | `from` `to` `items` | 期间不显示 |
| `label` | 黄色圆角标签 | `from` `text` | 这一行不显示，上一行留着变暗 |
| `bullets` | 一排带圆点的黄字 | `from` `items` | 这一行不显示 |
| `bigword` | 白色大字加一行小字 | `from` `to` `text`，可选 `sub` | 期间不显示 |
| `ask` | 字幕变黄加灰色问号 | `from` | 这一行不显示 |
| `alert` | 字幕下三个红色感叹号 | `from` | 照常显示 |

- `text` 不写就用那一行字幕的原文；想比口播更精炼就自己写（口播「身体的总指挥官一样」，标签写「身体总指挥官」）。
- `items` 里的词要能在这几行字幕里找到，程序用它定每个词弹出的时刻；找不到的词按平均间隔出。
- `side`：`float` 放头的 `left` 还是 `right`。
- 想保留底部字幕写 `"captions": "keep"`；不想让上一行变暗留着写 `"linger": false`。

### camera

`"auto"`：每个剪口换一次景别，钩子推近，场景结束回到人时换一次，其余大约每两句换一次。一般不用管。
要自己定就写成列表：`[{"from": 3, "zoom": 1.13}, {"from": 11, "zoom": 1.0}]`。

### music

素材目录里的音乐文件名，或 `null`。音量固定在很低的铺底水平（`musicVolume` 可调，默认 0.07）。不要自己从网上找音乐。

## 3. 每句话选什么处理

| 这句话在干什么 | 处理 |
|---|---|
| 开头抛出的反常识结论（前 3 秒） | `hook` |
| 提问、转折、表态、过渡 | 人全屏，只有字幕 |
| 「假设…」「想象一下…」「在原始部落…」讲一个情境 | `illustration`，卡片式，头像在左 |
| 讲身体里的机制、通路、器官 | `illustration`，铺满，医学透视风，头像在右；路径用 `flow` |
| 一句话的落点是一个词（「就意味着安全稳定」） | `card` |
| 自问自答的那个问题 | `question`，挂到答案说完 |
| 答案是一两个字（「和气味有关」） | `float` |
| 给一个东西起比喻名（「就像身体的总指挥官」） | `label` |
| 提到研究、论文、数据出处 | `paper`，同时用 `bullets` 列它说明的几件事 |
| 连说两到四个并列的词 | 人全屏时用 `scatter`；在场景里用 `bullets` |
| 说到普通人的日常、「身边的人」 | `illustration`，铺满，绘本风，可以不带头像（3 秒内） |
| 对观众说「你…」的建议 | `broll`，他本人的外景实拍 |
| 全片的那个核心概念词 | `bigword`，一次 |
| 最后一句提问 | `ask` |
| 讲到危险、风险、警告 | 在场景里加 `alert`，插画上加 `marks` |

## 4. 节奏上的数（`zp.py board` 会查一部分）

- 前 3 秒必须有钩子。
- 人全屏占 45%–60%；人完全不在画面不超过 25%，一次不超过 5 秒。
- 一个插画场景 4–10 秒，里面每 2–3 秒换一张图；一张图不停超过 4 秒。
- 同一种花字全片不超过两次；`card` 最多两次，`bigword` 一次，`hook` 一次。
- 两处花字之间至少隔一行普通字幕，别连着出。
- 连续的人全屏不超过 8 秒就该有一次变化（换景别算）。
- 剪口：落在场景里，或落在换景别的那一帧。`board` 报「剪口落在一行字幕中间」时，回去调文案的断句，让剪口落在行首。

## 5. 插画提示词怎么写

对标片用了三套画风，一条片子里每套画风内部要一致：

| 用途 | 画风描述（每张图的提示词都以它开头） |
|---|---|
| 情境、故事 | 岩画质感的扁平插画，暖土黄与赭石色，粗颗粒纸纹，人物简笔、没有五官细节，无文字 |
| 身体机制 | 医学可视化，半透明蓝色 X 光质感的人体，冷蓝灰底，关键通路用青色发光线，柔光，无文字 |
| 日常、关系 | 温暖的手绘绘本风，暖米色调，俯视或中景，人物圆润，柔和长影，无文字 |

每张图再写三样：**景别**（俯视全景 / 洞内中景 / 特写）、**主体在哪**（头像在左上时主体放中下或右侧）、**留白**（字幕在 66% 高处，那一带别放细节）。
全部 9:16 竖图，1080×1920 以上。同一个场景的几张图一次生成，用同一个种子或同一张参考图保持一致。
