# 样式规范 · 对标片拆解

对标片：张展鹏《为什么一群女生在一起生理期会传染》，57 秒，9:16，30 帧。
数值是从成片逐帧量的，已换算到 1080×1920。它们都写死在 `studio/src/zhanpeng/`，可调的集中在 `theme.json`。
对标片本身不进仓库；要对照就放在 `_private/`（不入库）。

## 1. 一句话风格

**人说人话，画面讲故事。** 观点句是人全屏加白色楷体小字幕；一进入「假设」「原理」就整屏切成插画，人缩成左上角一个羽化的头像继续讲；全片只有三四个词被做成彩色大字。全片从字幕到花字是**同一套正楷**，只靠颜色和粗细分层次。安静、书卷气，不是综艺花字那一路。

## 3. 样式数值

### 字幕
- 正楷常规体，白色，58px，字距 0.1em，一行居中，不带标点。
- 中心在画面高度 **66.4%**（人的胸口到腰之间），全片不动，插画场景里也在这个位置。
- 只有软阴影，没有描边、没有底条。硬切出现，不做逐字动画。
- 被花字顶替时，上一行留在原位，不透明度降到 42%。

### 红色钩子（hook）
- 同一套正楷的粗体，`#D4161C`，138px（超过 7 个字自动缩小），外沿一圈很淡的白光。
- 中心在 71.6% 高，紧贴字幕下方。
- 进场 0.22 秒：从 1.28 倍、16px 模糊收到清晰；之后 1.5 秒里慢慢再放大 5%。
- 同一帧人物硬切推近到 1.18。

### 人物景别
- 只硬切，不做来回推拉；每一段里有一个 2.5% 的极慢推进，让画面不死。
- 四档：1.0、1.05、1.13、1.18。每个剪口必须换一档；没有剪口时大约每两句换一次。
- 缩放中心在脸下方（脖子），放大时头顶不出画。

### 插画场景（illustration）
- 卡片式（故事类）：深棕底 `#150D09`，图片四周留边（左右 52px、上下 44px），圆角 30px，边缘向内羽化。
- 铺满式（原理类、绘本类）：不留边。
- 每张图都在缓慢推、拉或平移（约 11%），换图用 0.3 秒叠化。
- **墨迹转场**：先 0.1 秒压黑，然后黑幕上几个毛边的洞在 0.4 秒里扩开。全片只在第一个故事场景用一次。
- 其余场景进场用淡入或模糊淡入；结束回到人时，人物从 22px 模糊、1.14 倍在 0.3 秒里收回来。
- 红色光晕（marks）：标在插画里某几个位置上跳动，用来指「这几个人」。

### 羽化头像（pip）
- 就是同一条人物视频，按人脸位置缩放平移，套一个椭圆羽化遮罩，能看到头和肩，四周融进插画。
- **头像追着头走**：`cut` 时逐帧测人脸（每秒 10 次，存在 `face-track.json`），人晃到哪，画面反着挪到哪，头始终在羽化圈正中。检测抖动做了 0.2 秒的平滑；脸宽做了 1 秒以上的平滑，头像不会忽大忽小。
- 左上：脸中心在 (29%, 20%)，脸宽 18.5%；右上：(79%, 20%)，脸宽 15%。
- 没有圆框、没有白边、没有投影。和生产线口播引擎里的「小圆头像」不是一回事。
- 头像放哪边看插画：主体在右就放左，反之放右。

### 黑底黄字卡（card）
- 人物 0.45 秒沉到全黑；楷体加粗 128px，`#F6E58A`，带直角引号「」，淡黄色光晕；中心在 43% 高。
- 只给一句话里最重的那个结论，全片最多两次。这一行不出底部字幕。

### 问题条（question）
- 顶部 9.2% 高处一条黄色横条 `#FBEE7E`（左右各留 7.6%，高 86px），深色楷体 52px（字多自动缩小），以「Q: 」开头，带问号。
- 横条先刷出，文字每秒 22 个字打出来，后面跟一个白色光标块。
- 一直挂到问题被回答完；这期间底部字幕不显示。

### 黄色关键词（float / scatter / bullets / label）
- 楷体加粗，`#F7E36B`，深色软阴影。弹出动作 0.28 秒：0.2 → 1.12 → 1。
- float：一两个字，贴在头的一侧，字比字大一号、带一点旋转，慢慢上飘。
- scatter：两到四个词，说到哪个弹哪个，位置错落在胸口以下、头两侧以外，大小不一。
- bullets：一排带圆点的词在字幕位置，说到一个落一个，落下时字距从宽收紧。
- label：黄色圆角底 `#FBEE7E` 加深色字，从左往右刷出，位置在字幕右下方。

### 流程（flow）
- 字幕位置上「甲 ▸▸ 乙」：白色楷体 72px，半透明深色底，中间两个灰色箭头在闪。说到哪个出哪个。

### 论文卡（paper）
- 背景：人物视频放大 1.32 倍、模糊 14px。
- 论文：上方 5.5%–46% 高、左右各留 7.5%，白底，外面一圈手绘感白色描边（边缘轻微抖动），从左下角翻开。
- 人：抠像后缩到 0.9 倍站在论文前面，轮廓外一圈白色虚线。
- 没装抠像依赖时退成「虚化背景加论文」，没有虚线人像。

### 外景空镜（broll）
- 深色底上一张圆角 34px 的卡片，几乎铺满（四周留 10–14px），边缘轻微向内压暗。没有头像，字幕照常。

### 白色大字（bigword）
- 楷体加粗，白色，第一个字 400px，后面的字小一号往右下错开，带弯引号；中心在画面中部偏下。
- 下面一行小字用字幕的样式。全片一次。

### 结尾提问（ask）
- 最后一行字幕变黄、加粗到 64px、深色描边；后面垫一个 330px 的灰色半透明问号。

## 4. 颜色与字体

全片只有四个颜色：白（字幕）、红 `#D4161C`（钩子、感叹号）、黄 `#F7E36B` / `#FBEE7E`（关键词、标签、问题条）、黑（卡片底）。

**对标片全片是一套传统正楷**：字幕是常规体，钩子、黄字、标签、问题条、大字是同一款的粗体。不是宋体，也不是圆润的现代楷体。
开源字体里笔形最接近的是寒蝉正楷，它只有一个字重，粗体靠同色描边补（`fonts.json` 里每个角色的 `stroke`）。

### 字体库

字体按「包」切换，每包给三个角色配字：`sub` 字幕和小字、`strong` 钩子和所有花字、`big` 白色大字。定义在 `studio/src/zhanpeng/fonts.json`。

| 包名 | 字体 | 什么时候用 |
|---|---|---|
| `chill` | 寒蝉正楷（默认） | 最接近对标片，没有特别理由就用它 |
| `chill-brush` | 寒蝉正楷 + 马善政毛笔大字 | 想让那个核心大字更有手写的劲 |
| `wenkai` | 霞鹜文楷 | 偏现代、圆润、亲和，轻松一点的选题 |
| `song-kai` | 宋体字幕 + 正楷花字 | 字幕想更清楚、更正式，花字保留对标片的味道 |
| `song` | 思源宋体 | 书卷气、偏严肃；和对标片不是一个路子 |
| `xiaowei` | 站酷小薇 | 细瘦文艺，情感、生活方式类 |
| `custom` | 自备字体 | 他有授权的商业楷体（方正楷体、方正粗楷、汉仪楷体等） |

```bash
python3 scripts/zp.py fonts                       # 列出字体包和安装情况
python3 scripts/zp.py fonts --preview             # 出一张样张（studio/out/字体包样张.jpg），每包同样几行字，用看图工具比
python3 scripts/zp.py fonts --preview "这一期的第一句" --hook "这一期的钩子"
python3 scripts/zp.py fonts --use wenkai          # 换默认；只换某一期就在 分镜.json 里写 "fontPack": "wenkai"
python3 scripts/zp.py fonts --install all         # 把所有包的字体都下好
```

以上字体都是 SIL OFL 1.1，可商用、可随包分发。**要和对标片一模一样**，让他从剪映里确认那款楷体的名字，拿到有授权的字体文件后放进 `studio/public/fonts/`，命名为 `custom-sub.ttf`（常规）、`custom-strong.ttf`（粗体）、`custom-big.ttf`（可省），再 `fonts --use custom`。商业字体不要放进公开仓库。

一条片子只用一个字体包，不要混着换。

## 5. 交片清单（看关键帧联系表时逐条过）

- [ ] 头像里的头始终在圈正中（人晃动最大的那几秒各抽一帧看）。
- [ ] 字幕全片在同一高度，没有两行，没有标点，没有超出左右边。
- [ ] 钩子在前 3 秒内出现，红字没有压住脸。
- [ ] 每个插画场景：头像没有挡住插画主体；头像四周是羽化的，看不到视频的硬边。
- [ ] 一张图没有停超过 4 秒；同一组插画画风一致。
- [ ] 黄字落在深色或中间调的背景上看得清（落在白衣服、亮墙上就换位置或换类型）。
- [ ] 花字出现时底部字幕没有和它重复。
- [ ] 黑底黄字卡不超过两次，白色大字不超过一次，红色只用在钩子和感叹号。
- [ ] 论文卡上的文献是真的，标题能读出来。
- [ ] 每个剪口都落在换景别、换场景的那一帧上（`zp.py board` 没有报剪口的 ⚠）。
- [ ] 最后一句是提问或金句，有结尾处理。
- [ ] 没有占位图（联系表里出现「素材占位」就是还没换）。
