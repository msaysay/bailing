# 视觉图鉴 · 骨架用大 V 的，积木往里填

原则：**审美听骨架的，自由只留在骨架允许的地方。** 不做自由混搭。

| 层 | 是什么 | 网页里 | 命令行 |
|---|---|---|---|
| 骨架 | 整套定了型的审美（版式、节奏、字体、字幕、配色关系）。出镜的六个对标大 V，另两个自己定的 | 骨架库、帮我选骨架（都是真实成片） | `python3 scripts/skeleton.py list / pick / show` |
| 可换件 | 署名、强调色、素材、配乐、片尾 | 选骨架页里的个人指纹 | `brands/<品牌>/fingerprint.json` |
| 组件 | 填进骨架的一块块内容，266 个带真渲小样 | 组件积木（选了骨架只留它能用的） | `python3 scripts/skeleton.py blocks <骨架>` |
| 名词 | 跟 AI 描述动作的标准叫法，216 个 | 专业名词库 | `python3 scripts/atlas.py find <词>` |
| 候选 | 没拆过对标片的风格、15 种动态设计风格、动作线框 | 候选区 | 不进自动流程 |

## 什么时候用

- **定方案时**：`skeleton.py show <骨架>` 看锁死什么、能用哪些组件，再排版式表。
- **用户贴来一段「请用某某骨架来做」**：照里面写的锁死项、可换项、组件名单做。先出 3 张关键帧，他点头再做整条。
- **用户说不清要什么**：让他打开 `site/atlas.html`（或单文件版 `视觉图鉴.html`）的「帮我选骨架」，答三个问题，把生成的话贴回来。
- **提修改意见、写版式表**：动效用名词库里的叫法（「遮罩显现」「交错动画」「推近」），别写「炫酷一点」。

## 组合的规矩（`python3 scripts/skeleton.py rules`）

1. 一条片子只用一个骨架，不跨骨架拼版式、字幕、字体。
2. 个人指纹只落在署名、强调色（骨架写了能换才换）、片尾。
3. 组件只从骨架的名单里挑；上画面前把底色、强调色、字体改成骨架的。现在组件不会自动换色，要你逐个改。
4. 每分钟最多三种组件；全片一种缓动；炫技最多一处。
5. 拿不准就少放。

## 新骨架怎么入库

用户看中候选区里的某种风格，或者某位大 V：请他发两三条对标视频 → 逐段拆（版式、字号、颜色、节奏，写成 `docs/对标拆解-*.md`）→ 用他的原片出一条真片 → 他点头 → 写进 `styles/skeletons.json`，再 `python3 scripts/skeleton.py build`。三步没走完不入库。
`scripts/skin.py`（风格皮肤引擎）是给候选风格快速出样片的试验台，不用来交付。对用户说「对标」「那个路子」，不说「复刻」；不用博主的名字、头像、片头当成片里的元素。

## 出处

- 专业名词库：`showheyohtaki/motion-prompt`，MIT。拷在 `site/vendor/motion-prompt/`，带许可证。
- 15 种动态设计风格：`Vincentwei1021/mg-styles-15`，MIT。拷在 `site/vendor/mg-styles-15/`（4 秒小样和提示词），带许可证。
- 同步上游更新：`python3 scripts/atlas_build.py`（要先把两个仓库克隆到本机）。
- 重新打单文件版：`python3 scripts/site_bundle.py`。
