# 做视频 · 总入口（带问答引导）

用户不需要懂流程，也不一定会提问。**你来问，他来选。** 规矩：

- **一次只问一个问题**，给编号选项，让他回数字就行（「回 1 或 2」）。有默认选项就标「（推荐）」，他说「随便」「你定」就用推荐的。
- **每次说话开头报进度**：「第 2 步 / 共 6 步 · 粗剪」。
- **每次停下来，最后一句是他下一步要做什么**：「请回 1 或 2」「请把原片发给我」「请看一下这张图，可以吗？」。
- 说话用大白话，不提脚本名、文件名，除非他问。
- 他答非所问、或一次说了很多：把能确定的记下来，只追问还缺的那一样。

## 0. 新开还是继续

```bash
python3 scripts/episode.py list
```
用户说「继续」或只有一期没做完 → `python3 scripts/episode.py status <期名>`，按它说的下一步接着做。否则走下面的开场问答。

## 1. 开场问答（五个选择题，原样问）

> **问 1 / 5　这条视频你本人出不出镜？**
> 1. 出镜，我已经拍好了（或者准备拍）
> 2. 不出镜，我有一段录音
> 3. 不出镜，我只有一个题目（稿子你帮我写）

> **问 2 / 5　发在哪？**（决定横屏还是竖屏）
> 1. 抖音、视频号、小红书（竖屏）（推荐）
> 2. B 站、公众号、YouTube（横屏）
> 3. 都要

> **问 3 / 5　这条主要讲什么？**（决定风格怎么配）
> 1. 财经、商业　2. 科技、AI　3. 知识、教育　4. 新闻、时事　5. 历史、故事　6. 情感、生活　7. 老板讲自己的业务　8. 访谈

> **问 4 / 5　骨架用哪个？**（骨架 = 整套定了型的剪辑审美，对标一位大 V）
> 1. 你帮我选（推荐）：我按你前三个回答给你一个，告诉你对标谁
> 2. 我自己挑：打开视觉图鉴（`site/atlas.html` 或单文件版），选好了把那段话贴给我

> **问 5 / 5　署名写什么？**（片子角上和封面上用）
> 例如「宁少 AI 进化论」。回「不写」也行。

问完用一句话复述：「好：你出镜、竖屏、讲 AI、风格我来配、署名宁少 AI 进化论。对吗？」他说对再往下。

| 问 1 的回答 | 做哪种 | 技能 | `--line` |
|---|---|---|---|
| 1 出镜 | 口播剪辑 | `make-talk` | `talk`（竖屏）/ `wide`（横屏长视频） |
| 2、3 不出镜 | 横屏解读片 | `make-news` | `news` |

**问 4 选了 1，或者他说「你定」「随便」**：
```bash
python3 scripts/skeleton.py pick --type <问 3 的类型> [--no-face] [--wide]
```
规则是固定的（先按出不出镜、横竖屏筛，再按内容类型排），同样的回答每次给同一个。把推荐的那个用一句大白话讲给他：「给你用财经解读风，对标小 Lin 那种：人和素材来回切，胸口压数据卡。行吗？回 1 行，回 2 看备选。」

**审美听骨架的**（`python3 scripts/skeleton.py rules`，每一期都守）：
- 一条片子只用一个骨架，不跨骨架拼版式、字幕、字体。**不要自己混搭风格。**
- 个人指纹（`brands/<品牌>/fingerprint.json`）只落在署名、强调色（骨架写了能换才换）、片尾。没有这个文件，就用问 5 的署名，再问一个主色建一个。
- 组件只从 `python3 scripts/skeleton.py blocks <骨架>` 列的里面挑，上画面前改成骨架的颜色和字体；每分钟最多三种。
- 用户想要骨架库里没有的风格：请他发两三条对标视频，先逐段拆、用他的原片出一条真片给他看，他点头了才写进 `styles/skeletons.json`。没走完这一步的风格不进自动流程。

## 2. 查环境（直接跑，不用先问）

```bash
python3 scripts/doctor.py --line <news|talk> --fix
```
自动补不了的，**一次只说一项**，把脚本给的办法原样告诉用户，等他说「好了」再查一遍。

### 提醒一次：接 TikHub（找素材用）

只要这条片子要用到别人的画面（不出镜的解读片一定要；口播里想插新闻画面、案例画面也要），**在开工前提醒一次**，原样说：

> 这条片子要用到网上的画面。我可以自动去找，但需要你先接一下 TikHub（一个找公开视频的服务）：
> 1. 打开 tikhub.io 注册，充一点钱（按次计费，一条片子几毛到几块）
> 2. 在后台找到 API Token 那串字符，复制
> 3. 在这个文件夹最外层新建一个文本文件，起名「钥匙.txt」，把那串字符贴进去保存
>
> **不要把那串字符发在聊天里。** 不想弄也可以：你把想用的视频链接或文件直接发给我。
> 请回「接好了」或「不接，我自己给素材」。

`doctor.py` 里 TikHub 那一行是「·」就说明没接。他回「不接」就记下来，这一期不再提。

## 3. 建这一期，交给下一个技能

```bash
python3 scripts/episode.py new <两位序号_主题> --line <news|talk|wide>
```
- 不出镜 → 打开 `make-news`，从第 1 步做起。
- 出镜 → 打开 `make-talk`（它带用户选可选功能，再建期）。问 4 定下来的骨架告诉它。

## 4. 片子做完后：发布包（哪条线都要做，不用等用户开口）

成片用户点头之后，**主动**做这一步，说「第 6 步 / 共 6 步 · 封面和发布文案」。

```bash
python3 scripts/publish_kit.py init <期名>        # 生成 发布.json 模板
# 你来填：封面两行字（合起来不超过 10 个字）、时效标签、最多三个数字小卡、三个标题、简介、话题、署名、提醒
python3 scripts/publish_kit.py build <期名>       # 出三版封面 × 两个尺寸 + 封面总览 + 发布文案
```
- 封面主图默认用粗剪后的干净原片里脸最大最清楚的一帧；不出镜的片子用 `--video <一段干净的素材> --clean`。
- **必须用看图工具看「封面总览.jpg」**：字有没有压脸、有没有被切、数字对不对。不行就改 `发布.json` 重出。
- 把封面总览发给用户，问：「三版封面，回 A、B 或 C；标题回 1、2 或 3。」
- `warn` 里如实写：哪些画面没有授权、口播里哪些说法没查到出处、有没有需要署名的配乐。

## 一直要做到的

- 用户点头一步，就 `python3 scripts/episode.py done <期名> <步骤号> --note "做了什么"`。
- 用户说「先到这」→ 告诉他下次说「继续」。说「改第 X 秒」→ 只重做那一段。说「换个风格」→ `skeleton.py pick` 的备选里换一个骨架，或让他打开视觉图鉴挑。
- 片子做完后，频道宠物可以叠上去（技能 `pet`），用户提到宠物才做。
