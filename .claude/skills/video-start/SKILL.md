# 做视频 · 总入口

用户不需要懂流程。你负责判断、准备、记进度；**每次只问用户要一样东西**。

## 1. 新开还是继续

```bash
python3 scripts/episode.py list
```
用户说「继续」或只有一期没做完 → `python3 scripts/episode.py status <期名>`，按它说的下一步接着做（打开对应技能）。否则往下。

## 2. 问一句话，定做哪种

> 这条视频**你本人出不出镜**？手上有什么：一个想法、一段录音，还是一条拍好的视频？

| 回答 | 做哪种 | 技能 | `--line` |
|---|---|---|---|
| 不出镜（讲新闻、事件、产品、任何题目） | 横屏解读片：真实画面 + 动效 + 配音 | `make-news` | `news` |
| 出镜，已经拍了或打算拍（口播、访谈都算） | 口播剪辑：五种风格选一种 | `make-talk` | `talk` |

用户只说「做条视频」、没说别的：默认 `news`，题目问他一句「讲什么？」。
片子做完后，频道宠物可以叠上去（技能 `pet`），用户提到宠物才做。

## 3. 查环境（直接跑，不用先问）

```bash
python3 scripts/doctor.py --line <news|talk> --fix
```
自动补不了的，**一次只说一项**，把脚本给的办法原样告诉用户，等他说「好了」再查一遍。TikHub 密钥是可选的，没有就跳过。

## 4. 建这一期，交给下一个技能

```bash
python3 scripts/episode.py new <两位序号_主题> --line <news|talk>
```
然后打开 `make-news`，从第 1 步做起。

**口播（`talk`）不在这里建期**：直接打开 `make-talk`，它先带用户选风格和可选功能，再用 `python3 scripts/talk.py new … --style …` 建期（五种风格要的目录不一样）。

## 一直要做到的

- **每次停下来，最后一句是「下一步需要你给我：……」或「请你看一下……，可以吗？」**
- 用户点头一步，就 `python3 scripts/episode.py done <期名> <步骤号> --note "做了什么"`。
- 用户说「先到这」→ 告诉他下次说「继续」。说「改第 X 秒」→ 只重做那一段。说「换个效果」→ 给他看 `studio/out/组件包/组件总览.jpg`，按编号换。
- 说话用大白话，不提脚本名、文件名，除非用户问。
