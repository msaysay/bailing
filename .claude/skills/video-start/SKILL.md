# 做视频 · 总入口

用户不需要懂流程，也不一定会提问。规矩：

- **开工要定的事一次问完**，不要一问一答地挤牙膏（做法见第 2 节）。开工之后每个确认点才是一次一件事。
- **环境你来装**，不让用户自己装东西（第 1 节）。
- **说到风格就给图**，不光用字描述（第 3 节）。
- 每次说话开头报进度：「第 2 步 / 共 6 步 · 粗剪」。每次停下来，最后一句是他下一步要做什么。
- 说话用大白话，不提脚本名、文件名，除非他问。

## 0. 新开还是继续

```bash
python3 scripts/episode.py list
```
用户说「继续」或只有一期没做完 → `python3 scripts/episode.py status <期名>`，按它说的下一步接着做。否则往下。

## 1. 环境：你来查、你来装（先做，不用问）

```bash
python3 scripts/doctor.py --fix
```
它会自己装：Python 包、工程依赖、语音模型、字体；系统里缺 ffmpeg 或 Node.js 时，会用这台电脑的包管理器（Mac 的 brew、Windows 的 winget、Linux 的 apt）直接装。

- 装的时候跟用户说一句「我在装环境，第一次要几分钟（要下大约 600MB 的模型），你不用管」，然后**同时把第 2 节的开工问题发给他**，别让他干等。
- `--fix` 之后还有 ✗：**照它打印的命令你自己接着装**，装完再跑一遍确认。不要把命令丢给用户让他去敲。
- 只有这几种情况才找用户，而且一次只说一件，说清点哪里：系统弹出密码框或授权框（「请在弹出的窗口里输入开机密码」）；公司电脑禁止安装软件；没有网。
- 宠物用的 Blender 和海豹底模、TikHub 钥匙是可选的，没有不算环境没装好，不要为它们打扰用户。

## 2. 开工单：一次问完

要定八件事：出不出镜、发在哪、讲什么、用哪个骨架、署名、要哪些处理、要不要网上的画面、怎么确认。**一次给出去，让他一次答完。** 按下面的顺序选一种方式：

**方式 A · 你的工具能弹选择题表单**（比如一次能问多道选择题的提问工具）：用它把选择题一次发出去。署名那几项是填空，放在同一轮里用文字问。

**方式 B · 让他打开「开工单」网页（有图，最省事）**：
> 这个文件夹最外层有个「开工单.html」，双击打开，里面每种风格都有样图。点一遍，按底部的「复制给 AI」，粘贴回来就行。

**方式 C · 直接在聊天里答**：把下面这一整段原样发出去（先把 `styles/previews/总览.jpg` 这张图发给他），他回一行就行：

> 开工前一次问完，你回一行就行，比如「1 1 3 推荐 都不要 2 1」。拿不准的写「默认」。
>
> ① 出不出镜？　1 出镜（我拍了口播）　2 不出镜（我有录音）　3 不出镜（只有题目）
> ② 发在哪？　1 竖屏：抖音、视频号、小红书（默认）　2 横屏：B 站、公众号
> ③ 讲什么？　1 财经商业　2 科技 AI　3 知识教育　4 新闻时事　5 历史故事　6 情感生活　7 老板讲业务　8 访谈
> ④ 用哪个样子？　看上面那张图，回编号；或者回「推荐」，我按前三项替你选
> ⑤ 要哪些处理（可多选）？　降噪　调光　配乐　换字体　都不要（默认）
> ⑥ 要用网上的画面吗？　1 要，帮我接 TikHub 自动找　2 要，我自己给链接或文件（默认）　3 不用
> ⑦ 怎么确认？　1 每一步给我看一眼（默认）　2 不用问我，一路做到底
>
> 另外请填署名（不想要的留空）：
> 角标（底部小牌子，像「小 Lin 说」，2 到 6 个字）：
> 称呼（2 到 6 个字）：
> 身份（一行，不超过 14 个字）：
> 简介（结尾才出，最多两行）：

用户已经在第一句话里说过的（「帮我把这条竖屏口播剪了」= 出镜 + 竖屏）不要再问，只问还缺的，也是一次问完。
他只答了一部分：没答的用默认，在复述里标出来「这几项我按默认来了：……」，不追问。
收到答案后**用一段话复述**，问一句「对吗？」，他说对就开工。

### 收到「这是我填好的开工单」

用户从网页复制来的。里面八项都有了，**不要再问**，直接：存署名（第 4 节）→ 建期（第 5 节）→ 告诉他下一步要给什么。

## 3. 骨架：说到风格就给图

骨架 = 整套定了型的剪辑审美，对标一位大 V。一条片子只用一个。

```bash
python3 scripts/skeleton.py pick --type <内容类型> [--no-face] [--wide]   # 用户回「推荐」「默认」「你定」时用；规则固定
python3 scripts/skeleton.py show <骨架>                                  # 锁死什么、能换什么、能用哪些组件
```
- **每次提到某个骨架，都把它的样图发给用户**：单个的在 `styles/previews/<骨架>.jpg`，全部的在 `styles/previews/总览.jpg`。只有字的描述不算。
- 样图是别人的原片做的。**粗剪完之后，用他自己的原片出一张关键帧**再确认一次：「这是套在你片子上的样子，可以吗？」
- 相框老板风、访谈纪实风的样图是版式示意，还没有真实成片，推荐这两个时要说明。
- 审美听骨架的（`python3 scripts/skeleton.py rules`）：不跨骨架拼；组件只从 `skeleton.py blocks <骨架>` 里挑，改成骨架的颜色和字体；用户想要库里没有的风格，请他发两三条对标视频，先拆、出真片、他点头才入库。

## 4. 署名：三样东西，都不是全程挂着

```bash
python3 scripts/sign.py set --badge <角标> --name <称呼> --title <身份> --bio <简介> [--brand <品牌>]
python3 scripts/sign.py show                # 还缺哪样
python3 scripts/sign.py demo --video <人物视频> [--wide]    # 粗剪后出三张图给用户看
```
- **内容用户来填，你不要替他编**身份和简介。他留空的那样就不出。
- 出现时机按 `docs/署名规则.md`（看对标片定的）：个人介绍在开头钩子之后出一次、停 4 秒；角标只在人全屏时在；简介只在结尾。画面里用 `studio/src/kit/sign.tsx` 的 `<Sign>`，时间它自己排。
- 骨架自己带角标或名片的，用骨架的那件，`<Sign parts={[…]}>` 只补缺的（各骨架怎么配写在 `docs/署名规则.md`）。
- 粗剪完跑一次 `sign.py demo`，把图发给用户确认位置和大小。

## 5. 建这一期，交给下一个技能

```bash
python3 scripts/episode.py new <两位序号_主题> --line <news|talk|wide>
```
| 开工单的回答 | 做哪种 | 技能 | `--line` |
|---|---|---|---|
| 出镜 | 口播剪辑 | `make-talk`（把选好的骨架、处理项告诉它，它不再问） | `talk`（竖屏）/ `wide`（横屏长视频） |
| 不出镜 | 横屏解读片 | `make-news` | `news` |

**要用网上的画面**：到备素材那一步时读技能 `footage-guide`。顺序是先用没风险的（他自己的、组件画的、免费素材库），不够才把接 TikHub 的话术发给他；TikHub 是第三方的收费服务，和这套工具没关系，要跟他说清楚。他选了「自己给」，就在那一步问他要链接或文件。

## 6. 片子做完后：发布包（哪条线都要做，不用等用户开口）

成片用户点头之后，主动做：

```bash
python3 scripts/publish_kit.py init <期名>        # 生成 发布.json 模板
# 你来填：封面两行字（合起来不超过 10 个字）、时效标签、最多三个数字小卡、三个标题、简介、话题、署名、提醒
python3 scripts/publish_kit.py build <期名>       # 三版封面 × 两个尺寸 + 封面总览 + 发布文案
```
- 封面主图默认用粗剪后的干净原片里脸最清楚的一帧；不出镜的用 `--video <一段干净的素材> --clean`。
- 必须用看图工具看「封面总览.jpg」：字有没有压脸、有没有被切、数字对不对。不行就改 `发布.json` 重出。
- 把封面总览发给用户，一次问完：「封面回 A、B 或 C；标题回 1、2 或 3。比如回『B 2』。」
- `warn` 里如实写：哪些画面没有授权、口播里哪些说法没查到出处、有没有需要署名的配乐。

## 一直要做到的

- 用户点头一步，就 `python3 scripts/episode.py done <期名> <步骤号> --note "做了什么"`。
- 他选了「一路做到底」：中间不停，但每个本来要确认的地方把你的决定记下来，最后一起汇报（剪掉了哪几句、用了哪些素材、哪些你验证不了）。
- 用户说「先到这」→ 告诉他下次说「继续」。说「改第 X 秒」→ 只重做那一段。说「换个风格」→ 发总览图让他重选。
- 频道宠物（技能 `pet`）用户提到才做。
