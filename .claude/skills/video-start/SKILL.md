# 做视频 · 总入口

**原则：用户不需要知道有哪些步骤、哪些脚本。** 你负责判断走哪条线、查环境、建目录、记进度，每一步只问用户「现在需要你给我的那一样东西」，给完就往下做。

## 第 0 步：先看是新开还是继续

```bash
python3 scripts/episode.py list
```
- 用户说「继续」「上次那个」，或者只有一期没做完：直接 `python3 scripts/episode.py status <期名>`，跳到「每一步怎么推进」。
- 否则新开一期，往下走。

## 第 1 步：只问两个问题，判断走哪条线

用一句话问，给选项，不要讲术语：

> 这条视频，**你本人出不出镜？** 手上**已经有什么**？（一个想法 / 一段录音 / 一条拍好的视频）

| 用户的回答 | 走哪条线 | `--line` |
|---|---|---|
| 不出镜，只有想法或录音；讲新闻、财报、事件 | 事为主（横屏新闻解读） | `news` |
| 出镜；已经拍了，或者打算对着镜头讲 | 人为主（竖屏口播） | `talk` |
| 要更新频道宠物（每期一次） | 频道宠物 | `pet` |

拿不准就按「人出不出镜」定。宠物线是叠加在另外两条线上的：先做完片子，再走宠物线把它放进去。

## 第 2 步：查环境，缺什么带着补

```bash
python3 scripts/doctor.py --line <线> --fix
```
- `--fix` 会自动装 Python 包、npm 依赖，下载两个模型。直接跑，不用先问。
- 剩下自动补不了的（字体、Node、ffmpeg、Blender、TikHub 密钥），**一次只说一项**，把脚本给的办法原样告诉用户，等用户说「好了」再重跑检查。
- TikHub 密钥是可选的：没有就告诉用户「找新闻画面这一步需要你自己给素材链接或文件」，继续往下走。

## 第 3 步：建这一期

期名用「两位序号_一句话主题」，比如 `05_英伟达财报`，序号接着 `episodes/` 里已有的往下排。

```bash
python3 scripts/episode.py new <期名> --line <线>
```
它会打印第一步要用户给什么。照着问。

## 每一步怎么推进

1. 跑 `python3 scripts/episode.py status <期名>`，看「下一步」和「需要你给」。
2. **只向用户要那一样东西**。用户给的文件放进 `episodes/<期名>/01_输入素材/`。
3. 打开那一步对应的技能（`status` 里写着技能名），照着做。
4. 那一步要用户确认的（`status` 里「做完后要你确认」），把结果给用户看，**明确问一句「可以吗？」**，等回复。用户提了意见就改，改完再问。
5. 用户点头后：`python3 scripts/episode.py done <期名> <步骤号> --note "一句话说做了什么"`，然后回到第 1 条。
6. 不需要确认的步骤，做完直接 `done`，接着做下一步，不用停下来问。

**每次停下来等用户时，最后一句永远是「下一步需要你给我：……」或者「请你看一下……，可以吗？」**，让用户知道该干嘛。

## 用户中途说的话

| 用户说 | 你做 |
|---|---|
| 「先到这」「明天再说」 | 告诉他下次说「继续」就行，进度已经记下 |
| 「改一下第 X 秒 / 某一段」 | 只重做那一段（`scripts/seg_render.py`），不整片重渲 |
| 「换个组件」「想要更酷的效果」 | 打开 `studio/out/组件包/组件总览.jpg` 给他挑，按编号换 |
| 「这一步跳过」 | 在 `done` 的 `--note` 里写「用户要求跳过」，提醒他跳过的后果 |
| 「我不懂」「这是什么」 | 用一句大白话解释，然后回到「下一步需要你给我」 |

## 两条线可以叠加

- 口播里要插新闻画面：在口播线的「找证据画面」一步用新闻线的找素材方法。
- 任何一条线做完的片子，都可以再走宠物线，把右下角的宠物叠上去。
