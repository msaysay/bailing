# 找素材 · 先用没风险的

工具都在 `python3 scripts/footage.py`。规则的完整说明：`docs/素材规则.md`。

## 一、什么时候用到这一步

各风格做到「备素材」那一步时（财经解读风第 4 步、不出镜解读片第 3 步、红顶风的手机截图、访谈纪实风的空镜……）。
**先问自己这句话到底要不要画面**：能用图表、流程、文字卡讲清的，不找画面（第 2 档）。

## 二、五档来源，从前往后用

```bash
python3 scripts/footage.py ladder
```

| 档 | 来源 | 风险 | 要做什么 |
|---|---|---|---|
| 1 | 用户自己的：自己拍的、自己的截图和录屏 | 没有 | 先问他有没有 |
| 2 | 自己做的：组件画的图表、流程、文字卡 | 没有 | 优先考虑 |
| 3 | 明确授权的：维基共享资源、Pexels | 很低 | 按许可署名 |
| 4 | 新闻机构和官方账号发的原片（走 TikHub 搜） | 有 | **先问用户**；只截几秒、裁台标、标来源 |
| 5 | 抖音上别人的作品（走 TikHub） | 最高 | **每条都要用户点头**；有作者字幕、贴纸的不用 |

前三档不用问用户，直接找：
```bash
python3 scripts/footage.py find "关键词" --en "english keywords" [--video]
```
关键词写**看得见的东西**（码头、交易大厅、数据中心），不写抽象概念。维基和 Pexels 用英文搜得到的多。

## 三、前三档不够时：引导用户接 TikHub

先看接没接：`python3 scripts/footage.py guide`（它会打印下面这些，并告诉你现在的状态）。

**没接，而且这条片子确实需要网上的画面**：把下面这段原样发给用户，一次说清，等他回话。

> 这条片子有几处要用网上的画面，免费素材库里没找到合适的。有两个办法：
>
> **办法一：你把想用的视频链接或文件直接发给我。** 不花钱。
>
> **办法二：接一个叫 TikHub 的服务，我自己去搜。** 先说清楚三点：
> 1. TikHub 是第三方的服务，**和这套剪辑工具没有关系**，不是我们的产品。
> 2. 它是**收费的**：要先充值，按搜索和下载的次数扣钱，一条片子大概几毛到几块。钱付给 TikHub，价格以它官网为准。
> 3. 它搜来的都是平台上的公开视频，**没有取得授权**。用不用、发不发由你定，我会把每条的来源列给你。
>
> 想接的话三步：打开 tikhub.io 注册并充值 → 在后台复制 API Token 那串字符 → 在这个文件夹最外层新建一个文本文件叫「钥匙.txt」，把那串字符贴进去保存。**不要把那串字符发在聊天里。**
>
> 请回「发链接」或「接好了」。也可以回「不用网上的画面」，我就全用图表和文字卡做。

- 他回「接好了」：再跑一次 `guide` 确认，然后 `python3 scripts/footage.py find "关键词" --level 4`。
- 他回「发链接」：`python3 scripts/tikhub.py url <链接> --out <目录> --name <别名>`（免费，不走 TikHub）；平台要求登录时就停，请他在自己电脑上下好把文件发来。
- 这一期他说过不接：不再提。
- **第 5 档（抖音）只在第 4 档也没有时用**，而且要再单独问一句：「只在抖音上找到了，是别人发的视频，用吗？」

## 四、下回来的每一条：查 → 裁 → 记

```bash
python3 scripts/footage.py check <文件>                                  # 查平台水印、台标角标、烧进去的字幕
python3 scripts/footage.py fit <文件> --slot <槽位> --out <输出> --ss 起点 --t 时长 --level <档位> --who <谁的> --page <页面链接>
python3 scripts/footage.py ledger <素材目录>                             # 交片前列一遍
```

1. **`check` 出的检查图必须用看图工具看**。红框是机器发现的东西，绿框是建议留下的范围。机器会漏也会多报，你要自己判断：
   - 角上跳来跳去的平台水印（在抖音 App 里点「保存」存下来的就有）：**不用**，换来源。走 TikHub 取的原画没有这个。
   - 一直在角上的台标、账号名：裁掉；裁不掉就换。
   - 烧在画面里的字幕、新闻横条：裁掉；占了三分之一以上就换。
   - 别人的脸（不是这条新闻的当事人）、别人的账号名、别的品牌的贴纸：不用。
2. **`fit` 把它裁进这种风格的素材框**，自动避开查到的东西、去掉声音。槽位：

   | 风格 | 槽位 | 尺寸 |
   |---|---|---|
   | 财经解读风的素材带 | `xiaolin-band` | 1080×842 |
   | 横屏深度解读风的素材窗 | `ziqi-window` | 1204×910 |
   | 不出镜解读片铺满 | `news-full` | 1920×1080 |
   | 相框老板风的画面窗 | `frame-window` | 1440×1080 |
   | 访谈纪实风的满屏空镜 | `tall-full` | 1080×1920 |
   | 红顶风的手机壳（截图） | `redtop-phone` | 不裁 |

   裁完不到原画面三成它会提醒：横屏素材塞进竖框、或者水印占得多，换一条。
3. **第 4、5 档的画面上要标来源**（「画面：谁 · 日期」，各风格都有写来源的位置），**只用几秒**，不整段搬。
4. **登记**：`fit` 自动记到素材目录的 `sources.json`。交片前跑 `ledger`，把它打印的「交片时要告诉用户」原样转给用户，并写进发布包的提醒里。

## 五、不能破的规矩

- 能不用别人的画面就不用。组件和用户自己的东西永远优先。
- 4、5 档没有用户点头不用。
- 不给下载工具传登录信息，不伪装浏览器绕过验证。平台拦了就停，请用户自己下。
- 别人的原声、配乐不用（`fit` 已经去掉声音）。
- 不把钥匙写进任何文件（除了用户自己建的「钥匙.txt」），不发在聊天里。
- 来源如实登记。查不到来源的不用。
