# 口播剪辑 · 选风格 → 选功能 → 出片

六种风格背后是六套模板，但流程是同一套（`docs/口播剪辑-标准流程.md`）。你只做四件事：**帮用户选、照那种风格的技能做、每个确认点停下来问、最后出发布包**。

和用户说话的规矩同 `video-start`：一次只问一个选择题，让他回数字；每次开头报「第几步 / 共 6 步」；每次停下来最后一句是他下一步要给什么。`video-start` 已经问过的（横竖屏、讲什么、风格怎么定）不要再问。

## 第 0 步 · 选风格（问一次）

```bash
python3 scripts/talk.py styles
```

把打印的内容用大白话讲给用户，让他挑。**先问横屏还是竖屏**：要做 8 分钟以上分章的横屏长视频，直接是横屏深度解读风；竖屏的在前五种里挑。用户说不清就按下表替他选一个，再问「按这个做行吗？」。

| 用户的情况 | 风格 | `--style` | 接下来读哪个技能 |
|---|---|---|---|
| 讲财经、商业分析，要图表和数据动效 | 财经解读风（小 Lin 式） | `xiaolin` | `xiaolin-talk` |
| 商业财经、信息密、素材多，要花字和数据面板 | 商业快节奏风（蛋解创业式） | `danjie` | `danjie-cut` |
| 健身、健康、科普，要插画和论文卡 | 知识科普风（张展鹏式） | `zhanpeng` | `zhanpeng-talk` |
| 老板、创始人，横屏机位，要品牌相框 | 相框老板风（约读书房式） | `frame` | `frame-talk` |
| 访谈、采访、企业宣传，要满屏空镜 | 访谈纪实风（天图通逊式） | `interview` | `tiantu-interview-cut` |
| **横屏长视频**：国际局势、宏观经济、产业深度，8 到 15 分钟、分章 | 横屏深度解读风（子祺见微式） | `ziqi` | `ziqi-wide` |

### 六种之外：风格皮肤（37 种风格配方，可混搭）

六套模板是手工搭的，细节最多。用户想要别的调子（纸感、综艺、国风、杂志、程序员风……），或者想混搭，用风格皮肤引擎：同一条粗剪好的原片，换一套配方就换一种包装（版式、配色、字体、字幕、强调方式）。

```bash
python3 scripts/skin.py styles                              # 全部风格配方
python3 scripts/skin.py auto --type <财经|科技|知识|新闻|历史|情感|老板|访谈> --seed <期名>   # 用户不选：按内容自动配三个方案
python3 scripts/skin.py render <期名> --style d-paper --still 2      # 先出一张关键帧给用户看
python3 scripts/skin.py render <期名> --mix h-split,d-ink,d-breaking  # 混搭：结构,皮肤,点睛
```
- **用户没选风格、或说「你定」**：跑 `auto`，把三个方案各用一句大白话讲给他，问「回 1、2 或 3」；他还是不选就用方案 1，并告诉他一句用的是什么。
- 用户从视觉图鉴的混搭器里贴来一段话：里面有混好的配方，照它用 `--mix`。
- 个人指纹（`brands/<品牌>/fingerprint.json`）默认套上，强调色以指纹为准。
- 如实告诉用户：皮肤引擎是第一版，版式六种，细节不如六套手工模板；14 种「对标大博主」的风格是按公开视频的常见特征整理的，不是逐帧复刻。

## 第 0.5 步 · 选可选功能（问一次，别逐项念）

```bash
python3 scripts/talk.py options --style <风格>
```

默认已经开着：去重录、去口吃和语气词、收紧停顿、封面。**只问用户这四句**，按回答开关：

> 1. 录的地方吵不吵（空调、风机、马路）？ → 吵就开 `denoise`
> 2. 光线怎么样，脸暗不暗？要不要轻微磨皮？ → `grade`、`beauty`
> 3. 要不要配乐？有自己的曲子吗？ → `music`
> 4. 字体用这种风格原配的，还是想换一套？ → 想换就出样张让他挑（见下）

换字体：`python3 scripts/fonts.py preview --style <风格>` 出样张，**用看图工具看过再把图发给用户**，他挑中哪个包就记下包名。字体库说明见 `fonts/library.json`（59 款可商用字体、21 套搭配）。

## 第 1 步 · 建期

```bash
python3 scripts/talk.py new <两位序号_主题> --style <风格> --video <原片> [--script 文案.txt] [--opts denoise,music,…] [--font 字体包]
```

它会建目录、把原片放到这种风格要的位置、记下选的功能，然后**打印这一期按顺序要跑的命令**（已经把选的功能配进去了）。之后随时：

```bash
python3 scripts/talk.py recipe <期名>                 # 再看一遍做法
python3 scripts/talk.py set <期名> --opts music,-denoise --font boss    # 中途改主意
python3 scripts/episode.py status <期名>              # 到哪一步了
```

### 备素材之前：提醒一次接 TikHub

要往口播里插新闻画面、案例画面，而 `python3 scripts/doctor.py --line talk` 里 TikHub 那行是「·」（没接），原样发给用户，等他回话（这一期只提一次）：

> 这条片子要用到网上的画面。我可以自动去找，但需要你先接一下 TikHub（一个找公开视频的服务）：
> 1. 打开 tikhub.io 注册，充一点钱（按次计费，一条片子几毛到几块）
> 2. 在后台找到 API Token 那串字符，复制
> 3. 在这个文件夹最外层新建一个文本文件，起名「钥匙.txt」，把那串字符贴进去保存
>
> **不要把那串字符发在聊天里。** 不想弄也可以：你把想用的视频链接或文件直接发给我。
> 请回「接好了」或「不接，我自己给素材」。

然后打开那种风格的技能照做。`recipe` 只管命令和开关；怎么断句、怎么排画面、每一步要用户确认什么，都在各自的技能里。

## 最后一步 · 发布包（六种风格都一样）

成片用户点头之后**主动**做，不用等他开口：

```bash
python3 scripts/publish_kit.py init <期名>     # 生成 发布.json 模板，你来填（填法见 -h）
python3 scripts/publish_kit.py build <期名>    # 三版封面 × 两个尺寸 + 封面总览.jpg + 发布文案.md（标题三选一、简介、话题、署名、提醒）
```
用看图工具看过「封面总览.jpg」（字不压脸、不被切、数字有出处）再发给用户，问：「三版封面，回 A、B 或 C；标题回 1、2 或 3。」

## 通用的可选处理（哪种风格都能用）

| 工具 | 干什么 | 用在哪 |
|---|---|---|
| `scripts/retakes.py <asr.json>` | 找重录、结巴、语气词，给出要删的时间段 | 粗剪之前；逐条看过再用 |
| `scripts/polish.py <视频> --inplace --denoise auto` | 人声降噪加修音 | 剪好的人物视频上（渲染之前） |
| `scripts/polish.py <视频> --inplace --grade [--beauty 0.3] --preview 对比.jpg` | 自动调光、轻磨皮 | 同上；**先看对比图**，肤色不自然就不用 |
| `scripts/polish.py <成片> --music auto --mood light\|calm\|drive\|warm -o 新文件` | 从默认配乐库（`music/`，19 首）挑一首配上，人声在时自动压低；`--no-credit` 只用不用署名的；也可以 `--music 曲子文件` | 成片上（渲染之后），换曲子不用重渲。用到需署名的曲子时它会打印署名文字，**交付时原样转给用户** |
| `scripts/fonts.py use <包> --style <风格>` | 换字体包 | 渲染之前 |

有的风格自带其中几样（比如访谈纪实风自带降噪和配乐匹配），以 `talk.py options --style` 说的为准，自带的不要再叠一遍。

## 六种风格都不能破的规矩

1. **不改出镜人的意思和用词**。只删重录、口误、长停顿；删掉的每一句都告诉用户。
2. **嘴型永远对声音**。人物画面只来自和声音同一时刻的原片。
3. **时间只从声音里取**。决定表里写行号和词，不手写秒数。
4. **剪口必须盖住**：换景别、换版式或盖素材。
5. **不编造**：数字、文献、出处以口播和素材为准，查不到不上画面。
6. **没看过关键帧联系表不交付**；机器查不了的（口型、节奏、降噪和配乐的听感）交付时明说，请用户看一遍。
7. 属于「以后都这样」的意见记进 `brands/<品牌>/rules.md`，只针对这一期的不记。
