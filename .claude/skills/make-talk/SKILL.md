# 竖屏口播 · 四步

一期的东西在 `episodes/<期名>/`，代号在 `进度.json` 的 `slug`。细节问题查 `docs/steps/talk-0X-*.md`，平时不用读。

## 第 1 步 · 稿子与拍摄（要用户确认一次）

- **用户已经拍好了**：要视频文件，放进 `01_输入素材/口播原片.mp4`，直接去第 2 步（稿子从录音里整理）。
- **还没拍**：问讲什么、多长；写稿（同 `make-news` 第 1 步的写法，事实要有出处），每 20 到 30 秒安排一句提问或转折。给用户稿子，再把下面这段**原样发给他**：

> 拍的时候：竖着拍；人别太近，脸宽占画面五分之一到四分之一；头顶留一个头的空；关掉相机水印；一条拍到底；说错了停一秒，**整句重说**。

## 第 2 步 · 粗剪（要用户确认剪掉了什么）

```bash
python3 scripts/talk_prep.py <期名> transcribe
```
它打印逐字时间。你读一遍，找出「说了一半重说的」「说反了自己纠正的」，记下要删的时间段；看它报的水印位置和人脸位置定裁切。然后：

```bash
python3 scripts/talk_prep.py <期名> cut --drop "7.55-10.48,70.80-71.72" [--vf "delogo=...,crop=1080:1620:0:240"]
```
它会剪片、去长停顿、对齐字幕。**告诉用户剪掉了哪几句**；粗口、口头禅照留，问他要不要改。

## 第 3 步 · 排版出片（要用户确认两次）

1. 逐句定版式（规律来自对标拆解 `docs/对标拆解-小Lin口播.md`）：

| 这一句在干嘛 | 版式 |
|---|---|
| 提问、转折、表态、玩笑 | 人全屏，只有字幕（每次不超过 6 秒） |
| 讲一个概念、一个数字 | 人全屏，组件放在下巴以下 |
| 「你看」「比如」后面给证据 | 人缩成右上角小圆，素材占上半屏 |
| 一步步算账、对着一样东西讲 | 人缩成卡片，和内容并排 |
| 章节开头 | 整屏标题一秒多 |

   每个剪口都要盖住：落在人很小的版式里，或在剪口那一帧换版式、切景别。
2. 在 `studio/src/episodes/<代号>/index.tsx` 里搭（骨架已生成，引擎 `studio/src/kit/talk.tsx`，参考 `studio/src/episodes/talk01/`）。
3. 先出十几张关键帧给用户看（`npx remotion still …`），问「可以吗？」。
4. 整片渲染，自查：`python3 scripts/qc.py …` 和 `python3 scripts/talk_check.py … --full-w <全屏时脸宽占比>`。给用户成片，说清哪些没法验证（口型、剪口顺不顺），问「可以吗？」。

## 第 4 步 · 封面和发布

同 `make-news` 第 5 步，封面用竖屏 1080×1440，从人全屏的画面里挑一帧。

底线同 `make-news` 文末。
