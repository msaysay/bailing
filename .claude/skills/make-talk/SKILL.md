# 口播剪辑 · 选风格 → 选功能 → 出片

五种风格背后是五套模板，但流程是同一套（`docs/口播剪辑-标准流程.md`）。你只做三件事：**帮用户选、照那种风格的技能做、每个确认点停下来问**。

## 第 0 步 · 选风格（问一次）

```bash
python3 scripts/talk.py styles
```

把打印的内容用大白话讲给用户，让他挑。用户说不清就按下表替他选一个，再问「按这个做行吗？」。

| 用户的情况 | 风格 | `--style` | 接下来读哪个技能 |
|---|---|---|---|
| 讲财经、商业分析，要图表和数据动效 | 财经解读风（小 Lin 式） | `xiaolin` | `xiaolin-talk` |
| 商业财经、信息密、素材多，要花字和数据面板 | 商业快节奏风（蛋解创业式） | `danjie` | `danjie-cut` |
| 健身、健康、科普，要插画和论文卡 | 知识科普风（张展鹏式） | `zhanpeng` | `zhanpeng-talk` |
| 老板、创始人，横屏机位，要品牌相框 | 相框老板风（约读书房式） | `frame` | `frame-talk` |
| 访谈、采访、企业宣传，要满屏空镜 | 访谈纪实风（天图通逊式） | `interview` | `tiantu-interview-cut` |

## 第 0.5 步 · 选可选功能（问一次，别逐项念）

```bash
python3 scripts/talk.py options --style <风格>
```

默认已经开着：去重录、去口吃和语气词、收紧停顿、封面。**只问用户这四句**，按回答开关：

> 1. 录的地方吵不吵（空调、风机、马路）？ → 吵就开 `denoise`
> 2. 光线怎么样，脸暗不暗？要不要轻微磨皮？ → `grade`、`beauty`
> 3. 要不要配乐？有自己的曲子吗？ → `music`
> 4. 字体用这种风格原配的，还是想换一套？ → 想换就出样张让他挑（见下）

换字体：`python3 scripts/fonts.py preview --style <风格>` 出样张，**用看图工具看过再把图发给用户**，他挑中哪个包就记下包名。字体库说明见 `fonts/library.json`（59 款可商用字体、21 套搭配）。

## 第 1 步 · 建期

```bash
python3 scripts/talk.py new <两位序号_主题> --style <风格> --video <原片> [--script 文案.txt] [--opts denoise,music,…] [--font 字体包]
```

它会建目录、把原片放到这种风格要的位置、记下选的功能，然后**打印这一期按顺序要跑的命令**（已经把选的功能配进去了）。之后随时：

```bash
python3 scripts/talk.py recipe <期名>                 # 再看一遍做法
python3 scripts/talk.py set <期名> --opts music,-denoise --font boss    # 中途改主意
python3 scripts/episode.py status <期名>              # 到哪一步了
```

然后打开那种风格的技能照做。`recipe` 只管命令和开关；怎么断句、怎么排画面、每一步要用户确认什么，都在各自的技能里。

## 通用的可选处理（哪种风格都能用）

| 工具 | 干什么 | 用在哪 |
|---|---|---|
| `scripts/retakes.py <asr.json>` | 找重录、结巴、语气词，给出要删的时间段 | 粗剪之前；逐条看过再用 |
| `scripts/polish.py <视频> --inplace --denoise auto` | 人声降噪加修音 | 剪好的人物视频上（渲染之前） |
| `scripts/polish.py <视频> --inplace --grade [--beauty 0.3] --preview 对比.jpg` | 自动调光、轻磨皮 | 同上；**先看对比图**，肤色不自然就不用 |
| `scripts/polish.py <成片> --music auto\|曲子 -o 新文件` | 配乐，人声在时自动压低 | 成片上（渲染之后），换曲子不用重渲 |
| `scripts/fonts.py use <包> --style <风格>` | 换字体包 | 渲染之前 |

有的风格自带其中几样（比如访谈纪实风自带降噪和配乐匹配），以 `talk.py options --style` 说的为准，自带的不要再叠一遍。

## 五种风格都不能破的规矩

1. **不改出镜人的意思和用词**。只删重录、口误、长停顿；删掉的每一句都告诉用户。
2. **嘴型永远对声音**。人物画面只来自和声音同一时刻的原片。
3. **时间只从声音里取**。决定表里写行号和词，不手写秒数。
4. **剪口必须盖住**：换景别、换版式或盖素材。
5. **不编造**：数字、文献、出处以口播和素材为准，查不到不上画面。
6. **没看过关键帧联系表不交付**；机器查不了的（口型、节奏、降噪和配乐的听感）交付时明说，请用户看一遍。
7. 属于「以后都这样」的意见记进 `brands/<品牌>/rules.md`，只针对这一期的不记。
