# 动效与匹配 · 两样工具

这个包不是一种风格，是给各个风格加料的。骨架（风格）还是说了算：人后面的效果用骨架的强调色和字体；匹配表只推荐骨架允许用的组件。

**和用户说话**：大白话，不提脚本名。每次停下来，最后一句是他下一步要做什么。

## 一、匹配表：文案 → 画面、素材、配乐、音效

粗剪完、排版式之前跑一次：

```bash
python3 scripts/match.py <期名> --skeleton <骨架> [--depth]
```
- 读这一期的字幕（带每个字的时间），按固定规则逐句标线索（数字、对比、涨跌、列举、设问、转折、人物、地点……十七种），给出：这句配什么画面、骨架里能用哪几个组件、要不要找素材（找什么、第几档）、加不加音效、配乐在哪进、分几段、每段什么情绪、哪几句要压低。
- 结果在这一期的「03_制作过程/匹配表.md」。规则本身：`python3 scripts/match.py rules`，出处和道理在 `docs/匹配规则.md`。
- `--depth`：这条片子的人像抠得出来（见第二节）才加，它会在合适的句子上推荐「人后面」的效果，全片不超过每 25 秒一次。

**它是初稿，你必须通读一遍再用**：
1. 删掉牵强的。规则只认字面，「第二次机会」会被当成列举，这种要删。
2. 同一种组件不连着用；全片挑一块主面板（清单、时间线、对照表之一）反复回来，其余的点到为止。
3. 人名、公司、地点只在第一次提到时配画面，规则已经这么做了，你再核一遍有没有漏认的名字。
4. 「要找的素材」那张单子交给技能 `footage-guide`：先用没风险的，不够再引导接 TikHub。
5. 配乐只用包里的或用户自己给的。表里写的进点、分段点要对在句子之间的停顿上。
6. 你听不到声音：配乐和音效的建议是按规则排的，听感要用户自己确认，交片时说清楚。

没有字级时间也能跑（给一个纯文本字幕稿），秒数按语速估，只能用来提前看「这条片子要找多少素材」。

## 二、人后面的效果

原理：同一条口播放两层，下面是原画面，上面是只有人、背景透明的那条；夹在中间的字和图就被人挡住了。所以要先把人抠出来。

```bash
python3 scripts/matte.py demo <人物视频> [--from 秒]        # 先做这个：用他自己的片子把 14 个效果各放 3.5 秒，出一条演示片和一张总览图
python3 scripts/matte.py make <人物视频> --from 12 --to 18 --check   # 正式用：只抠要用的那几秒
```
- **抠像慢**（这台机器上 1 秒画面大约要 15 到 20 秒），所以只抠用得上的那几段，一条片子用两三处就够了。
- **一定看检查图**（人贴在品红底上）：人身上透出品红 = 漏抠，品红里露出背景 = 多抠。不干净就别用，换成字在人旁边。常见原因：衣服和背景一个颜色、背景里有别人、手伸出画面。
- 把总览图发给用户挑：「这是用你自己的片子试的，想用哪几个？回编号。」

画面里这样用（`studio/src/kit/depth.tsx`）：

```tsx
<Depth base="ep08/person.mp4" fg="ep08/person-fg" fgFrom={12} fgFor={6} startFrom={12}
       head={{ x: 0.5, y: 0.31, r: 0.09 }}            // 在 person-fg/info.json 里
       behind={<BehindWord text="复利" at={0.4} until={4} color="#F2E26B" />} />
```

| 效果 | 组件 | 什么时候用 | 别用在 |
|---|---|---|---|
| 身后大字 | `BehindWord`（升起 / 砸下 / 滑入，可空心） | 一句话里最重的那个词，两到四个字 | 超过 4 个字；字幕已经在强调同一个词 |
| 身后大数字 | `BehindNumber` | 全片最重的那个数 | 一屏有两个数 |
| 身后滚字墙 | `BehindMarquee` | 「铺天盖地都在说」「刷屏了」 | 要让人读清每一行的时候 |
| 头后光环 | `Halo` | 主角登场、高光时刻 | 严肃话题；一条片子用两次 |
| 换背景 | `BgSwap`（纯色 / 图 / 虚化 / 压暗） | 回忆、假设、「换个场景想」 | 背景本来就干净的片子没必要 |
| 环绕字 | `OrbitText`（前后各放一次，用 `orbit()` 省事） | 口号、栏目名绕着头转 | 超过 16 个字 |
| 肩后弹卡 | `PopCards` | 「这几家公司」「这几样东西」，最多 4 张 | 卡上要放小字 |
| 两侧词条 | `SideTags` | 三到六个标签、原因 | 每条超过 6 个字 |
| 残影 | `Echo` | 速度、变化快 | 抠像边缘不干净时（会放大毛边） |
| 身后走势线 | `BehindTrend` | 讲涨跌时不想切走画面 | 没有真实数据的走势 |
| 聚光 | `Spot` | 全片最重的那句话，配乐同时压低 | 画面本来就暗 |
| 符号冒出 | `SymbolBurst` | 设问、「凭什么」 | 连着两句都用 |
| 贴纸描边 | `<Depth outline={{ width: 7 }}>` | 配换背景用，像贴纸 | 抠像边缘不干净时 |
| 压暗背景 | `<Depth dim={0.35}>` | 让身后的字更清楚 | — |

规矩：
1. 一条片子里「人后面」的效果不超过每 25 秒一次，同一种不重复。它是点睛的，不是底色。
2. 字要够大（宽度至少占画面七成），被头挡住的部分不超过一半，不然读不出来。出图后看一眼。
3. 颜色、字体跟骨架走；财经解读风用黄，红顶风用金。
4. 字幕还在胸口照常走，身后的字不能和字幕说同一个词。
5. 抠像只为这几秒服务，其余时间还是用原片（`fgFor` 要写对，不然抠像放完后会找不到帧）。

## 三、你验证不了的

- 配乐和音效的听感。
- 抠像在动得快的地方（甩手、转头）会不会闪：出片后逐帧看那几秒的联系表，拿不准就告诉用户「第 X 秒请你看一眼边缘」。
