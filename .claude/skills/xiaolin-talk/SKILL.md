# 财经解读风（小 Lin 式）· 口播成片

目标：**成片的节奏和版式看起来像小 Lin 的片子**——人只占三分之一时间，一半时间把画面交给证据。
开工前读 `docs/对标拆解-小Lin口播.md`（三条真实成片的拆解，所有数值的出处）。有 `reference/` 目录的话（单独的工具包里带），先用看图工具看里面的联系表。

你（AI）负责：断句、找口误、排版式表、找素材、搭画面。时间一律从声音里取，不手写秒数。
用户只出面四次：**稿子（没拍时）→ 剪掉了什么 → 版式表和素材 → 成片**。每次停下来只问一件事。

## 六步

| 步 | 做什么 | 命令 | 要用户确认 |
|---|---|---|---|
| 0 | 环境（**你来装，不让用户装**）和开工单（要用户定的事**一次问完**） | `python3 scripts/doctor.py --line talk --fix` | ✔ 开工单 |
| 1 | 收原片，建期（没拍就先写稿） | `episode.py new` | ✔ 稿子（已经拍好就跳过） |
| 2 | 转写、找口误和重录、粗剪、对齐 | `talk_prep.py transcribe` → `cut` | ✔ **剪掉了哪几句** |
| 3 | 排版式表 | 写 `03_制作过程/版式表.md` | ✔ **版式表和素材清单** |
| 4 | 备素材 | 放进 `studio/public/<代号>/footage/` | |
| 5 | 搭画面 → 关键帧 → 成片 → 自查 | `remotion still / render`，`qc.py`，`talk_check.py` | ✔ **成片** |
| 6 | 发布包：三版封面、三个标题、简介、话题 | `publish_kit.py init / build` | ✔ 挑封面和标题 |

每确认一步：`python3 scripts/episode.py done <期名> <步骤号> --note "做了什么"`。中断后 `python3 scripts/episode.py status` 看到哪了。

## 第 0 步 · 环境和开工单

**环境你来装**：`python3 scripts/doctor.py --line talk --fix` 会装 Python 包、渲染依赖、语音模型、字体，缺 ffmpeg / Node.js 也会用包管理器装。没装上的照它打印的命令你接着装。只有系统弹密码框、没网时才找用户。

**开工单一次问完**（装环境的同时发出去，别让他干等）：让用户双击打开最外层的「开工单.html」，点完按「复制给 AI」贴回来；他的工具打不开网页，就把下面几项在聊天里**一条消息**列完，让他回一行。贴回来之后这些不再问：

1. 署名三件套（不想要的留空）：角标（底部小牌子，像「小 Lin 说」，2 到 6 个字）、称呼和一行身份（开头出 4 秒）、简介（结尾才出）。不替他编。
2. 要哪些处理：降噪、调光、配乐。去重录、去口吃、收紧停顿默认就做。
3. 片子里要不要用网上的画面：帮我接 TikHub 自动找 / 我自己给链接或文件 / 不用。
4. 怎么确认：每一步给我看一眼 / 不用问我，一路做到底。

**横拍还是竖拍不用问。** 成片固定是竖屏 1080×1920；原片是横的还是竖的由程序自己看，自动以人脸为中心裁好（第 2 步）。横屏原片裁完清晰度会降一截，转写时它会提示，你转告用户一句就行。

## 第 1 步 · 收原片，建期

```bash
python3 scripts/episode.py new <两位序号_主题> --line talk      # 完整仓库里用 talk.py new … --style xiaolin 也一样
```
把原片放到 `episodes/<期名>/01_输入素材/口播原片.mp4`。代号（`slug`）在它打印的那一行里，后面素材目录、合成名都用它。

**还没拍**：问清讲什么、多长，按下面的结构写稿（事实要有出处，查不到的不写），给用户确认后把拍摄要求原样发给他。

稿子结构（量自三条成片）：
1. 开头不自我介绍，**直接讲一件具体的事**，有人、有数字：「哎，前一阵子某某花了 510 万买了一张上太空的船票。」
2. 10 到 30 秒把这件事讲完。
3. 40 到 50 秒**抛出两个问题**：「那你说它到底是怎么回事？这些人又在争什么？」
4. **先给框架再展开**：「主要就三家，对应三种方式。第一种……」框架两到四块，全片靠它串。
5. 每一块：一句定义 → 两三个例子 → 一句自己的评价或玩笑。
6. 结尾**一句话收束**在一个判断上，不求关注、不预告。

语速按 350 字/分算：三分钟约 1050 字，五分钟约 1750 字。

> 拍的时候：竖着拍；人别太近，脸宽占画面五分之一；头顶留一个头的空；胸口到腰别有杂物（卡片和字幕压在这里）；关掉相机水印；一条拍到底；说错了停一秒，**整句重说**。

## 第 2 步 · 粗剪（确认点）

```bash
python3 scripts/talk_prep.py <期名> transcribe
```
它打印逐字时间，再打印机器找到的重录、结巴、语气词，以及人脸位置和建议的裁切。你要做的：
- 「自动删」逐条看：删的和留的确实是同一句话才算数。「待判断」对着上下文定。
- 通读一遍，找机器抓不到的：**换了说法的重录**、说反了自己纠正的。记下时间段。
- 看第 3 秒截图顶部有没有水印。

```bash
python3 scripts/talk_prep.py <期名> cut --drop "你补的时间段" --auto-drop [--grade] [--beauty 0.3] [--denoise auto]
```
- `--auto-drop` 把「自动删」的一起剪。**画面不用管**：横屏竖屏都按 `transcribe` 算好的自动裁成 1080×1620（要去水印等特殊处理才自己写 `--vf`，写了就以你写的为准，结尾要带 `scale=1080:1620`）。
- 光线不好加 `--grade`（**先看 `03_制作过程/调光对比.jpg`**，肤色不自然就去掉重跑）；环境吵加 `--denoise auto`。
- 它会剪片、收紧长停顿、对齐字幕，产出 `studio/public/<代号>/person.mp4`、`voice.wav` 和 `studio/src/episodes/<代号>/timing.json`、`cuts.json`。

没有稿子时它用转写结果生成 `script.txt`：**校对错字、按下面的规则断句，再跑一次 `cut`**。
断句：一行一句字幕，6 到 10 个字最好，**不超过 14 个字**，按语义断，不留标点，数字用阿拉伯数字。

告诉用户剪掉了哪几句；粗口、口头禅照留，问他要不要改。

## 第 3 步 · 版式表（确认点）

逐句决定这一句用哪种版式，写成 `episodes/<期名>/03_制作过程/版式表.md`（行号、这句话、版式、放什么、素材文件名）。

| 这一句在干嘛 | 版式 | 模板里 |
|---|---|---|
| 提问、转折、表态、玩笑、一句定义 | **人全屏**，什么都不压；每段 4 秒左右 | `mode: 'full'` |
| 列框架、说一组并列的东西 | **人全屏 + 胸口一排卡片**，说到一个弹一个 | `Chest` + `Card2` |
| 「你看」「比如」「当时」后面跟例子、证据、现场 | **素材带**：素材横在中间，人缩成右上小圆；约两秒换一个画面 | `mode: 'bubble'` + `Band` |
| 引用别人的原话 | 素材带放他的采访画面，右半边打引语 | `BandQuote` |
| 一个关键数据 | 素材带上压大数字，带来源 | `BandStat` |
| 讲一个有名字的概念 | 素材带 + 左上竖排大标题 | `SideTitle` |
| 两个人、两家公司较劲 | 人全屏，头两侧一边贴一个，说到谁谁亮 | `HeadSide` |
| 一个新词第一次出现、全片的题眼 | 整屏关键词大字一秒多 | `mode: 'off'` + `BigWord` |
| 逐个介绍框架里的每一块 | 主题面板摆卡片，人是小圆 | `Panel` + `Card2` |

再定三样贯穿全片的东西：
- **进度牌**（`Progress`）：稿子的框架（两到四块）做成一排小牌子，每次换到下一块时亮出来几秒，讲到哪个哪个变金色。**全片最重要的一个挂件**，观众靠它知道讲到哪了。
- **章节角标**（`ChapterTag`）：每一块从头到尾挂在左上角。
- **频道角标**（`ChannelTag`）：频道名，人全屏时在底边正中。

排完对一遍硬指标（成片后 `talk_check.py` 会量）：

- 人全屏 **30% 到 45%**；小圆（素材带、面板）**40% 到 55%**；人不在不超过 20%。
- 平均 5 到 7 秒换一次版式；人全屏一段不超过 16 秒；人不在一段不超过 12 秒。
- **每个剪口都要盖住**（`cuts.json` 里的时刻）：落在小圆版式里，或在那一帧换景别（`zoom` 1 ↔ 1.18，`dur: 0`）、换版式。
- 人全屏时每 4 到 6 秒换一次景别，没有剪口也换。
- 卡片只放胸口（纵向 1030 到 1320），**不压脸、不压字幕**。字幕全片在同一个位置，不变色。
- 前 3 秒：人全屏，胸口就压着这件事的一张图；第 4 秒切素材。

把版式表**用大白话讲给用户**（不要贴代码）：「第几句到第几句切什么画面、框架是哪几块、哪几个词做成大字」，附上素材清单。问：「这样排可以吗？素材你来出还是我来找？」

### 排版式表之前：先定「主面板」和开头（2026 年新拆的四条成片里量到的）

详见 `docs/对标拆解-小Lin口播-第三批.md`，组件在 `studio/src/kit/talk3.tsx`。

1. **先定一块贯穿全片的主面板**：这期讲的是「一笔钱谁出的」用构成树图 `Treemap`；「几种做法比几项指标」用对照表 `MatrixBoard`；「谁去了哪」用去向清单 `PeopleFlow`。它隔一两分钟回来一次，每次多填一格，最后填满当总结。
2. **面板里的东西跟着口播一步步出**，先摆「？」再揭开；一块面板停 10 到 40 秒，但每 2 到 4 秒要有一格在变。
3. **开头三秒三选一**：胸口虚字 `GhostWord`、选择题 `QuizBoard`、直接上图表。不要先自我介绍。
4. **每章开头或抛概念时**用关键词光球 `KeywordOrb`，2 到 3 秒。
5. 引用别人的原话用 `QuoteCard3`，**必须写出处**；对比两个价格用 `StackBars`；人全屏时列选项用 `Bubbles`，说到大数用 `ChestNumber`。
6. 满屏面板要先垫 `Starfield`，那一段人切成小圆；面板占满上半屏时小圆挪到左上。
7. **先定这一期的主题色**（按题材：科技蓝、行情红、消费紫绿……），所有面板的 `color` 都传它；人全屏的部分不变。
8. 讲行情、讲增长用走势图面板 `LineBoard`：线画到哪口播讲到哪，拐点用 `marks` 打点。**数据必须是真的**，用户给数或从他给的截图里读，`source` 写来源；没有数据就不上这块面板，不要编。
9. 一套打法分几步用 `StepList`；从上游到下游过几道关用 `ChainCards`；「几家加起来才占这么点」用 `Waffle`。

## 第 4 步 · 备素材

放进 `studio/public/<代号>/footage/`，图片视频都行，横的最好（素材带是 1080×842，接近 4:3）。来源按顺序：
**接 TikHub（自动找素材用）**：`python3 scripts/doctor.py --line news` 里 TikHub 那行是「·」说明没接。片子要用网上的画面而用户在开工单里选了「帮我接」时，把这段原样发给他，等他回「接好了」：

> 接 TikHub 三步：1. 打开 tikhub.io 注册，充一点钱（按次计费，一条片子几毛到几块）；2. 在后台复制 API Token 那串字符；3. 在这个文件夹最外层新建一个文本文件，起名「钥匙.txt」，把那串字符贴进去保存。**不要把那串字符发在聊天里。** 好了回我「接好了」。

接好后：`python3 scripts/tikhub.py search "<关键词>"` 搜抖音、`xsearch` 搜海外，`get` / `xget` / `url <链接>` 下载（`python3 scripts/tikhub.py -h`）。他不想接：请他把视频链接或文件直接发来。**搜来的都是别人的公开内容，没有授权，交片时要告诉用户，发不发他自己定。**

1. **用户给的**。
2. **搜来的**：`python3 scripts/tikhub.py`（要 TikHub 钥匙，接法见上），或用户发链接。每条都要登记来源，在 `Band` 的 `credit` 里写「画面：谁 · 日期」。有别人字幕、水印、贴纸的不用。
3. **截图**：新闻页、公告、帖子、应用页面，用 `fit: 'contain'` 完整放进去。**必须真实存在**，不编造。
4. **自己画**：数据用组件库的图表（`studio/src/components/`），放在素材带的位置。

素材带约两秒一个画面，一段十秒的素材带要四五个画面。不够就同一条视频取不同时间点（`startFrom`），或者缩短这一段。缺素材不挡流程：先用纯色占位图出关键帧，标出来让用户补。

## 第 5 步 · 搭画面 → 关键帧 → 成片（确认点）

在 `studio/src/episodes/<代号>/index.tsx` 里搭（骨架已生成）。**照抄 `studio/src/episodes/talk02/index.tsx`**，它把每种版式和挂件各用了一遍。引擎在 `studio/src/kit/talk2.tsx`，每个组件上面有说明。

- `FACE` 填 `transcribe` 打印的「裁切后的人脸」。
- `SIGN` 填开工单里的署名三件套（留空的不出）。角标只在人全屏时在；称呼和身份在开头出 4 秒；简介在结尾，落在底部黑边里。规矩见 `docs/署名规则.md`。
- 时间全部用 `at(行号)` 或 `at(行号, '词')`，不写秒数。
- 字体默认是庞门正道标题体（最接近对标片）。用户想换：`python3 scripts/fonts.py preview --style xiaolin` 出样张挑，`fonts.py use <包> --style xiaolin`。

```bash
cd studio
npx remotion still src/index.tsx <代号> out/<代号>-k1.png --frame=<帧>      # 每种版式各出一张，十几张
npx remotion render src/index.tsx <代号> out/<代号>.mp4
cd ..
python3 scripts/qc.py studio/out/<代号>.mp4                                 # 黑场、闪帧、响度
python3 scripts/talk_check.py studio/out/<代号>.mp4 --full-w <全屏时脸宽占比，一般 0.20>
```

`qc.py` 报的「亮度突变」如果正好落在素材带换画面、换版式的时刻，是正常的（素材带就是硬切），逐个对一下时间即可；落在别处的要查。黑场、闪帧、画面停滞必须是空的。

**关键帧必须用看图工具看**，对着 `docs/对标拆解-小Lin口播.md` 第三到五节逐条过，至少改两轮再给用户：
1. 小圆有没有挡住素材里的主体（挡了就换素材或用 `fit: 'contain'`）。
2. 卡片有没有压脸、压字幕；字幕有没有超出画面。
3. 素材和这句话是不是说的同一件事，不是「大概相关」。
4. 有没有连续三张关键帧长得一样（素材换得太慢）。

**配乐**（开工单里选了才做）：`python3 scripts/polish.py studio/out/<代号>.mp4 --music auto --mood light --no-credit -o studio/out/<代号>-配乐.mp4`（在成片上做，不用重渲；人说话时自动压低；`--mood` 可选 light 轻快、calm 安静、warm 温暖、drive 推进；用户自己给曲子就 `--music 曲子.mp3`）。它用到要署名的曲子时会打印署名文字，交片时原样转给用户。

交付时说清：剪掉了哪几句；哪些素材是别人的（来源）、哪些是占位；机器查不了的——嘴型、剪口顺不顺、素材出现得早还是晚、降噪后人声闷不闷、配乐响不响，「这几处请你看一遍」。

## 第 6 步 · 发布包（成片点头后主动做）

```bash
python3 scripts/publish_kit.py init <期名>      # 生成 发布.json，你来填：封面两行字（合起来不超过 10 个字）、时效标签、三个标题、简介、话题、提醒
python3 scripts/publish_kit.py build <期名>     # 三版封面（大字压底、满图描边、色块分屏）× 抖音和视频号两个尺寸 + 封面总览 + 发布文案
```
- 封面主图自动取粗剪后干净原片里脸最清楚的一帧；想指定就 `--at 秒数`。
- **用看图工具看「封面总览.jpg」**：字有没有压脸、有没有被切。
- 发给用户，一次问完：「封面回 A、B 或 C；标题回 1、2 或 3。」
- 提醒里如实写：哪些画面是别人的没有授权、口播里哪些说法你没查到出处、配乐要不要署名。

## 不能破的规矩

1. **不改出镜人的意思和用词**。只删重录、口误、长停顿；删掉的每一句都告诉用户。
2. **嘴型永远对声音**：人物画面只来自和声音同一时刻的原片。
3. **时间只从声音里取**，不手写秒数。
4. **不编造**：数字、引语、截图、来源以口播和真实材料为准。别人的画面必须写来源。
5. **剪口必须盖住**。
6. **没看过关键帧不交付**。
7. 用户提的意见，只针对这一期的改这一期；「以后都这样」的改模板，并把规则写回 `docs/对标拆解-小Lin口播.md`。
