# 网格取景框口播风 · 丢一条原片，出一条成片

对标片的拆解和每个数的出处：`docs/对标拆解-直男财经.md`（参考图在 `docs/reference/zhinan/`）。命令都在 `python3 scripts/zhinan.py`。

这种风格的命根子是**密度**：对标片画面平均两秒变一次，语速每分钟三百七八十个字，几乎没有气口。所以它比别的风格更吃素材，也更要求原片说得紧。

**和用户说话的规矩**
- 大白话，不提脚本名和文件名。每次停下来，最后一句是他下一步要做什么。
- **环境你来装**：`python3 scripts/doctor.py --fix`，没装上的照它打印的命令你接着装。
- **要用户定的事集中在开剪之前，一次问完**（第 2 步）。之后只在「备素材」「看关键帧」「看成片」三处停。
- 你听不到声音、看不了动态：交片时把没法验证的地方如实告诉他。

## 一共七步

| 步 | 做什么 | 要用户做什么 |
|---|---|---|
| 1 | 收原片、转写 | 给一条竖屏口播原片 |
| 2 | **确认单**：字幕稿、要剪的地方、开头金句、封面标题、账号名、配乐 | 打开一页网页，改完复制回来 |
| 3 | 粗剪（气口收紧） | 不用 |
| 4 | 出匹配表、备素材 | 给素材，或同意你去找 |
| 5 | 排版式、配乐、出关键帧 | 看一张图，说行不行 |
| 6 | 渲成片、自查 | 看成片 |
| 7 | 发布包 | 挑封面和标题 |

## 第 1 步 · 收原片、转写

```bash
python3 scripts/doctor.py --fix
python3 scripts/zhinan.py new <两位序号_主题> --video <原片>
python3 scripts/zhinan.py transcribe <期名>
```
- 原片：竖屏、一个人对着镜头、有原声。**坐在桌前、胸口以下留出空（手和桌面）最合适**，因为素材、数字、词牌都贴在胸口。脸太大（脸宽超过画面四成）时胸口没地方贴东西，要告诉用户效果打折。
- 语速慢于每分钟 300 字的原片做不出这种感觉，先跟用户说：「这种风格要说得快、说得密，你这条偏慢，我会把停顿都收紧，但节奏还是会比对标片松。」

## 第 2 步 · 确认单（开剪之前，一次问完）

先自己做三件事：
1. **校字幕稿**（`episodes/<期名>/字幕稿.txt`）：改同音错字，按意思断行。**一行 8 到 9 个字，最多 12 个字**；一行就是一条字幕，整句出、整句换。只改错字和标点，不改意思。
2. **想三组封面标题**（两行，合起来不超过 12 个字）。片子里没有常驻标题，这个只用在封面上。
3. **挑两句开头金句候选**。对标片不挪金句，第一个字就是内容，2 秒内出第一样素材；所以默认不挪，只有原片开头太平才建议挪。

```bash
python3 scripts/zhinan.py confirm <期名> --titles "行一|行二;行一|行二;行一|行二" [--hooks "候选一;候选二"]
```
对用户说：
> 开剪之前有几样要你定。我做了一页「确认单」，在这一期的文件夹里，双击打开：字幕稿直接改错字、要剪掉的地方打了勾、封面标题三选一，再填一下你的账号名（会出现在素材框的角上）。改完点底部的「复制给 AI」，粘贴回来。

他贴回来之后把字幕稿写回 `字幕稿.txt`（第一行加 `## 全文`），其余记下，不再问。

## 第 3 步 · 粗剪

```bash
python3 scripts/zhinan.py cut <期名> [--drop "<要剪掉的时间段>"] [--hook "<他选的金句>"] [--denoise] [--grade]
```
字之间超过 0.45 秒的停顿会自动收紧。对齐率低于 0.85 的段，回去看字幕稿。

## 第 4 步 · 匹配表、备素材

```bash
python3 scripts/zhinan.py suggest <期名>
```
出「匹配表」：逐句标出这句配什么、要找什么素材，并告诉你这条片子大约要多少个素材镜头。通读一遍，删掉牵强的（规矩见 `docs/匹配规则.md`）。

然后备素材（技能 `footage-guide`，先用没风险的）。对用户说清楚要什么：
> 这种风格很吃画面。这条 X 秒的片子，我需要大约 N 个镜头：讲到 A 的现场画面、B 的截图……你手上有的直接发我；没有的，我可以用图表和大字顶上，也可以帮你接 TikHub 去找（那是第三方的收费服务，和这套工具没关系）。

每条素材：`python3 scripts/footage.py check <文件>` → `fit <文件> --slot zhinan-window`（取景框和胸口窗，16:9）或 `--slot tall-full`（满屏）→ 交片前 `ledger`。

**素材不够怎么办**（对标片里有一条户外手持的，98% 是人全屏，照样成立）：少用面板，多用不花钱的五样：怼脸、黄色数字、白色大字、黄色词牌、身后大黄字。宁可少一种版式，不要拿不相干的画面凑数。

**不能照搬的**：对标片里大量的表情包、影视片段、名人照片、品牌标志，我们一样都不能直接用。表情用系统自带的表情符号（`--emoji`、`--float`）；人物照片要有授权或来自官方公开场合；影视片段不用。

## 第 5 步 · 排版式、配乐、关键帧

```bash
python3 scripts/zhinan.py plan <期名> --badge <账号名> \
    --panel "a.mp4,b.mp4,c.jpg@从这几个字~到这几个字" \
    --cover "d.mp4@从~到+mini" \
    --chest "e.jpg@这几个字"  --num "1499|两人票价@这几个字"  --word "LV的老板@这几个字" \
    --tags "比较,炫耀,量化@这几个字"  --behind "倒反天罡@这几个字"  --emoji "🤔@这几个字"
python3 scripts/zhinan.py music <期名>          # 默认很轻（比人声低 26 分贝）；不要配乐加 --off
python3 scripts/zhinan.py stills <期名>
```
`@` 后面写字幕里的几个字，表示「说到这里时出现」。每样东西什么时候用：

| 参数 | 是什么 | 什么时候用 | 量 |
|---|---|---|---|
| `--panel` | 取景框面板：网格底上一个框，里面的素材约两秒一换 | 讲现场、讲一件事的经过，有三条以上相关素材 | 全片 14% 到 20%，一段 4 到 7 秒 |
| `--cover` | 满屏素材（加 `+mini` 带小人窗） | 素材本身是竖的、或者特别有冲击力 | 10% 到 18%，一段 2 到 4 秒 |
| `--chest` | 胸口素材窗 | 一张图、一段几秒的画面，当证据亮一下 | 2 到 4.5 秒 |
| `--num` | 胸口黄色大数字 | 这句话里最重的那个数（有两位以上数字的句子会自动加，不要就 `--no-auto-num`） | 讲数字的段落 10 秒一个 |
| `--word` | 胸口白色大字（这几秒不出字幕） | 一个称呼、一个梗、一句反问 | 约 30 秒一处 |
| `--tags` | 黄色词牌，念到哪个弹哪个 | 三四个并列的词 | 一条一两次 |
| `--behind` | 身后大黄字（自动抠像，1 秒画面要算十几秒） | 全片最想让人记住的两到四个字 | 一条 2 到 5 次，每次 1.5 到 3 秒 |
| `--emoji` / `--float` | 胸口一个大表情 / 满屏飘 | 吐槽、自嘲、夸张 | 约 30 秒一个，开头更密 |
| `--card` | 网格底卡片：大黄字加一张抠好的图 | 第一次介绍一个人、一样东西 | 8% 到 12% |
| `--doc` | 网格底歪着的文件截图 | 报告、公告、规定当证据 | 3 到 5 秒 |

景别不用你管：人全屏时 1.0 和 1.1 倍来回换（剪口上必换，否则 2.7 秒一换）；短的反问句和全片最后一句会自动怼脸（不要就 `--no-punch`）。

`plan` 会打印版式表和两个数，**这两个数要对上对标片**：
1. **画面平均几秒变一次**：目标 2.0 到 2.5 秒。它会列出「超过 5 秒没动」的地方，在这些地方补一样东西。
2. **版式占比**：人全屏 55% 到 60% 最像；素材少时人全屏可以更高，但那就更要靠数字、词牌、表情把密度撑住。

**必须用看图工具看 `out/关键帧.jpg`**：字幕有没有出框或压住素材、取景框里有没有黑边、数字和词牌有没有挡脸、身后大字读不读得出来（被头挡住不超过一半；`plan` 打印的抠像检查图也要看）。然后发给用户：「这是套在你片子上的样子，可以吗？」

## 第 6 步 · 成片

```bash
python3 scripts/zhinan.py render <期名>
```
- 机器自查里「亮度突变」报在进出面板的时刻是正常的；黑场、闪帧、画面停滞有内容才要查。
- 逐秒看 `out/qc/sheet-1fps.jpg`。
- 交片时说清：剪掉了哪几句、每条素材的来源、用了哪首配乐、哪些你验证不了（节奏听感、音效轻重、抠像边缘在动得快的地方会不会闪）。

## 第 7 步 · 发布包（成片点头后主动做）

```bash
python3 scripts/zhinan.py publish <期名>     # 第一次生成 发布.json，你填好封面两行字、三个标题、简介、话题、提醒，再跑一次
```
看「封面总览.jpg」，发给用户：「封面回 A、B 或 C；标题回 1、2 或 3。」`warn` 里如实写哪些画面没有授权。

## 不能破的规矩

1. 全部硬切。不加淡入淡出、不加转场特效。
2. 字幕一句一句整句出，白色粗斜宋体，不逐词变色。强调靠大字和数字，不靠字幕。
3. 人全屏时画面上不常驻任何东西（没有标题条、没有角标）。账号名只出现在取景框的角上。
4. 没有片头片尾：第一个字就是内容，最后一句说完就结束。
5. 不改出镜人的意思和用词；画面上的字只来自口播；数字要和口播一致。
6. 对标片里的表情包、影视片段、名人照、品牌标志、配乐，一样都不照搬。
7. 没看过关键帧不渲整片，没看过每秒联系表不交片。
