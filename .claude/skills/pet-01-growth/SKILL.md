# 宠物 · 第 1 步 · 成长结算

规则全文见 `docs/宠物成长规则.md`，参数在 `pet/config.json`。

## 要用户给
1. 上期视频的**点赞、评论、转发、收藏、新增关注**五个数（创作者后台截图也行，你自己读）。
2. 上期的**评论**：后台导出的文件，或者视频链接（抖音可以用 `scripts/tikhub.py` 拉）。

## 读评论、判路线（这一步必须真做，不许编）
- 取前 200 条有效评论（去掉纯表情、广告、重复）。
- 逐条判断更贴近哪条路线：机芯（讲道理、数据、技术方法）、金羽（生意、赚钱、机会）、焰心（情绪浓、观点冲突）、星语（个人故事、共鸣、温暖）；都不像就不算。
- 数 `#机芯` `#金羽` `#焰心` `#星语` 投票，每人每期一票。
- 每条路线摘 2 到 3 条最有代表性的评论原文当证据。
- 写进 `pet/episodes/<期名>.json`：`{"ai": {...}, "votes": {...}, "evidence": {...}, "note": "这期大家在聊……"}`

## 结算
```bash
python3 scripts/pet.py add <期名> --likes … --comments … --shares … --saves … --follows … --judge pet/episodes/<期名>.json
python3 scripts/pet.py export <期名> studio/src/episodes/<期名>/pet.json
python3 scripts/pet.py status
```

## 要用户确认
把「涨了多少经验、升没升级、各路线加了多少分、凭的哪几条评论」给用户看。**结果不许人为改**，用户觉得判错了，只能改判断依据（比如漏读了评论）后重算。

## 顺手做
写一段置顶评论用的「成长日志」草稿（三四行），交给用户发。
