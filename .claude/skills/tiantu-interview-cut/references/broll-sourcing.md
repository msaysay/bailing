# B-roll：找、选、生成

## 先列需求单

对每个准备盖素材的句子写一行：`cue 范围 | 说了什么 | 想要的画面 | 来源`。例：

```
2-3   | 美国时间周一要提货          | 仓库分拣线 / 收货区堆货      | 用户素材
6-9   | 周三开船 10天或11天船期     | 集装箱货轮航拍（正面+俯拍）   | TikHub
16-18 | 很多客人走了一次发现真的快   | 港口堆场大全景航拍           | TikHub
40-42 | 其实也是我们王牌渠道        | 带品牌露出的自家现场          | 必须用户素材
```

讲“我们/我们的仓/我们的渠道”的句子**只用用户自己的实拍**，不能用别人的画面冒充。

## 来源一：用户素材

`sheet.py` 每个文件出缩略图 → Read → 记录 `文件 | 可用区间 | 内容 | 质量`。优先用。

## 来源二：TikHub（抖音搜索）

```
python3 scripts/tikhub_broll.py "关键词" -n 3 -o broll --max-dur 60      # 下载前 3 个合格视频
python3 scripts/tikhub_broll.py "关键词" --list                          # 只看结果不下载
```

- 鉴权：Claude 云端会话里 `api.tikhub.io` 已由代理注入凭证；其他环境 `export TIKHUB_API_KEY=...`。没有凭证就让用户连接 TikHub。视频文件来自抖音 CDN（`*.douyinvod.com`、`*.zjcdn.com`），网络策略需放行。
- 每次请求计费：一个画面需求搜 1–2 次，别撒网。
- 关键词写法：`主体 + 场景 + 拍法`，加“航拍/实拍/空镜/素材/延时”更容易出干净画面。例：`集装箱货轮 航拍 素材`、`集装箱码头 航拍`、`海外仓 仓库 实拍`、`叉车 装柜 实拍`、`物流园 卡车 航拍`、`快递分拣线 实拍`。
- 下载后**必须逐个看 `_sheet.jpg`**，以下一律不用：
  - 画面上有字幕、标题、贴纸、解说字（很多抖音视频全程压字）
  - 明显水印/账号名/其他品牌 logo 占位明显
  - 有可辨认的人脸特写、车牌
  - 抖动、过曝、低清（短边 <720）、画幅怪异
  - 与行业/地域不符（讲美国仓却给国内快递站）
- 只取其中 1–4 秒最干净的一段，记下 `src_in`。竖素材优先；横素材要确认居中裁 9:16 后主体还在（用 `focus_x` 调）。
- 版权：这些是创作者的作品。`broll/manifest.json` 记录了来源；**交付时列出实际用到的条目**，提醒用户取得授权或用自有素材替换后再发布。

## 来源三：生成关键帧

当实拍找不到合适画面时，用你可用的生图能力生成**竖版 9:16、≥1080×1920** 的关键帧，再转成运动镜头：

```
python3 scripts/still_to_clip.py key.png -o broll/gen_ship.mp4 --dur 4 --move push --amount 0.08
# --move: push | pull | left | right | up | down ；有图生视频能力时，用关键帧生成 4 秒视频更好
```

提示词模板（保持纪录片实拍质感，与成片色调一致）：

```
竖构图 9:16，纪实摄影风格，{主体与场景，如：满载彩色集装箱的远洋货轮行驶在碧蓝海面，无人机俯拍}，
自然光，真实色彩，轻微胶片颗粒，景深自然，画面干净，
无文字、无水印、无logo、无人物正脸
```

- 不生成：真实人物、客户品牌的门头/车辆涂装（会出错字）、任何带文字的画面。
- AI 画面只用于通用意象（海运、港口、仓储、公路运输、城市天际线），单段 ≤4 秒，一条片不超过 2–3 段，并在交付说明里标明。
- 你没有生图能力时：不要用纯色/文字卡代替；改用原片换景别，或减少该处 B-roll。

## 片尾画面

优先用户的人物空镜；没有则从原片里找人物非说话状态的好看片段（整理资料、走动、侧脸），或品牌现场空镜。不要用第三方素材做片尾。
