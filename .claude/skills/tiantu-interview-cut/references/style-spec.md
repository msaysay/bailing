# 样式规范（SOP × 参考成片实测）

数值来源：客户《剪辑 SOP--试剪版》+ 对参考成片（576×1024，65.7s）逐帧测量后换算到 1080×1920。
两者冲突时**以成片为准**（下表“成片实测”列）。这些值已写死在 `scripts/common.py`，此文档用于理解与验收，不用于手调。

## 画布与编码

| 项 | 值 |
|---|---|
| 画幅 | 1080×1920（9:16），30fps，H.264 + AAC 48k |
| 时长 | 成片 65.7s = 口播 61.0s + 片尾 4.7s；允许口播 45–90s |
| 响度 | 整体 -16 LUFS；BGM 比人声低约 12dB，片尾无人声时 BGM 抬 6dB，最后 1.5s 淡出 |

## 文字（全部白字 + 阴影，无描边）

阴影统一：黑色、不透明度 83%、模糊 6%、距离 5、角度 -45°（向右下）。

| 元素 | 字体 | 剪映字号 | 成片实测（1080 宽） | 位置 | 动画 |
|---|---|---|---|---|---|
| 常规字幕 | 鸿蒙体粗 HarmonyOS Sans SC Bold | 11 | 字高约 49px | 水平居中，行中心在 72% 高度（y≈1385），单行 | 无，硬切，随语音逐句换 |
| 关键词 | 同上 | 15 | 字高约 62px（常规的 1.3 倍），与常规字同基线同色 | 行内 | 无 |
| 小标题（单行 ≤4 字） | 瑞意宋（替代：思源宋体 Light） | 16 起自由放大 | 字高约 180px，如「十三日达」宽占画面 73% | 左起 x≈150，字底 y≈1345（人物胸口位置，不挡脸） | 渐显 0.3s / 渐隐 |
| 小标题（单行 5–6 字） | 同上 |  | 字高约 137px，如「百分之九十几」 | 顶部：字底 y≈380（logo 下方、头顶上方） | 同上 |
| 小标题（2–3 行堆叠） | 同上 | 16 | 每行字高约 94px，行距≈字号 | 左对齐成块；第二行可右缩进约 190px 形成错落 | 每行随对应语音出现，整体一起消失 |
| 竖排小标题 | 同上 |  |  | 人物侧边 | 渐显 |
| 人物介绍 | 鸿蒙体 | 姓名 19 / 介绍 10，整体缩放 61% | 姓名约 52px，介绍约 27px | 靠右侧，右边一条浅黄色竖条（#FFE9A0） | 渐显 + 渐隐 |
| 片尾标语 | 瑞意宋 | 天图通逊 24 / 为客户 18 / 竭尽全力 22 | 字宽约 147 / 112 / 143 px | 左起 x≈72；两行字底 y≈1296 / 1464 | 渐显 0.4s |

规则：
- 小标题与常规字幕的关系（成片做法）：**下方小标题出现时，该句不再出常规字幕**——小标题就是这句话本身（「十三日达」「能够做到 / 14个自然日之内」「客户高货值 / 要求高周转 / 季节性产品」）；顶部小标题（「百分之九十几」）与常规字幕并存。
- 小标题只压在**人物镜头**上，放在不挡正脸的位置（下方胸口、头顶上方、侧边）。SOP 希望停留 ≥3s；成片实际 1.0–3.6s，以“这句话说完再消失”为准，尽量延长。
- 字幕不带标点（问号可留在小标题里），每行 ≤12 字（成片 3–11 字，平均 7 字，每行停留 0.6–2.2s）。
- 安全距离：任何文字距左右边 ≥60px；不要贴边。

## Logo

- 透明底 PNG，左上角：x=58, y=60，宽 408px（画面宽的 38%），全程显示（含 B-roll 和片尾）。

## 画面

| 项 | 规则 |
|---|---|
| 镜头切换 | 全部硬切。无转场、无闪白、无缩放转场 |
| 口播镜头 | 两种景别交替：`wide`（半身，脸高约占画面 17%）与 `tight`（近景，约 24%）；脸在画面上 1/3 处 |
| 缓推 | 口播单镜头 ≥3s 时关键帧慢放大，约 3%/s，总量 ≤10% |
| 黑角/穿帮/漏灯 | 放大裁掉（调大该 source 的 `zoom`） |
| B-roll | 必须铺满全屏竖画面；横素材居中裁成竖屏（用 `focus_x` 选裁切位置） |
| 节奏 | 平均 2.4s 一个镜头；B-roll 单镜 1.0–4.2s；口播单镜 1.2–6.4s；B-roll 连续最长 7.5s 后回到人物 |
| B-roll 占比 | 口播时长的 56%（允许 35–65%） |
| 调性 | 沉浸感、叙事感（对标「一条」）；**不要**综艺感、信息流风格、夸张动画、娱乐音效 |

## 片尾（加分项，成片已有，视为必做）

- 4–5 秒一段“好看的人物/品牌画面”（成片：西装背影打电话，慢动作，浅景深），无口播，仅 BGM。
- 左下叠标语两行：`天图通逊` / `为客户竭尽全力`（“为客户”小、“竭尽全力”大），渐显。

## 交片检查清单（复检图逐条对）

- [ ] 第 1 帧就是人物 + 钩子小标题，没有黑场/片头
- [ ] logo 每个镜头都在左上角，没被裁、没压在亮部看不清到无法辨认
- [ ] 常规字幕：白字、粗黑体、单行、居中、位置不跳；关键词只是变大
- [ ] 小标题：细宋体、白字、不挡脸；堆叠标题逐行出现
- [ ] 没有任何描边、色块、彩字、贴纸、转场特效
- [ ] B-roll 全屏、清晰、无他人水印/字幕/贴纸，内容与正在说的话对得上
- [ ] 没有超过 4 秒不变的 B-roll、没有超过 6.5 秒的口播镜头；口播长镜头在缓推
- [ ] 剪口处没有吞字、没有跳帧感（跳剪处已换景别或盖了素材）
- [ ] 结尾有 4–5 秒片尾 + 标语，BGM 淡出
