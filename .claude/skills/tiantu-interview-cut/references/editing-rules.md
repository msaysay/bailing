# 剪辑决策规则

脚本管样式，你管决策。按下面的顺序做，每条都能在 `qc.py` 里找到对应检查。

## 1. 选段（编辑 script.txt）

- 原片通常是几分钟到几十分钟的访谈。一条成片只讲**一个主题**（一个产品/一个问题/一个观点），口播 45–90 秒，目标 60 秒。原片够长就拆成多条，每条各做一份 script/plan。
- 第一句必须是钩子：产品名、结论或数字，0.7–1.5 秒说完。如果人物是从铺垫讲起的，把后面的结论句**挪到最前**。
- 保留：流程、数字、承诺、对比、适用人群、带情绪的口碑句。删除：寒暄、“嗯/那个/就是说”的空转、重复解释、说错重说的前一遍、与主题无关的展开。
- 句内口头禅（“其实”“呢”）不必清干净——成片保留了口语感，只剪掉停顿和废句。
- 结尾落在一句有记忆点的话上（成片：“它是真的快，其实它也真的贵”），不要落在半句或解释句上。
- 不改变原意，不拼接出人物没表达过的意思。

## 2. 断句与字幕文本

- 一行一个意群，3–11 字，上限 12 字；按停顿和语义断，不要把词劈开（“14个自/然日”是错的）。
- 第二列只做：改同音错字、专有名词、数字改阿拉伯数字（“十天或十一天”→“10天或11天”；产品名“十三日达”保持汉字）、补全被吞的字（“走我”→“走我们”）。
- 一行在屏上少于 0.5 秒就并到相邻行。

## 3. 关键词（第三列）

- 约 50% 的行标关键词，每行 1 个（数字对比句可 2 个），2–5 字。
- 标什么：产品/渠道名、数字与时效、动作节点（提货、派送）、结论性形容（真的快）。
- 不标：虚词、整句、连续三行以上都标。

## 4. 镜头编排（shots）

- 第 1 个镜头：A（wide），长度覆盖钩子句（1–2.5 秒）。
- 之后按“说到具体事物 → 盖 B-roll；说到观点/对比/承诺/情绪 → 回人物”来排。目标：B-roll 占 45–60%，平均镜头 2–3 秒。
- 每个 B 镜头覆盖 1–3 句、1.0–4.0 秒；同一素材不要连着用两段；相邻 B 镜头在景别或内容上要有变化（航拍 → 地面细节）。
- B-roll 连续不超过约 8 秒就回到人物。
- A 镜头在 wide / tight 之间交替；带小标题的 A 镜头用 wide（下方有空间）或把标题放顶部。
- cues 里的 ✂（原片被剪断处）必须落在镜头边界上：要么这里换成 B-roll，要么 wide↔tight 切换。
- 多机位时：主机位为主；对谈者/全景机位作为 A 镜头的变化穿插（`src` + `offset`）。
- 最后一个镜头回到人物说完收尾句，然后接片尾。

## 5. 小标题（titles）

- 数量：约每 12–15 秒一个，60 秒 4–5 个。第一个必须在第 0 句（钩子）。
- 内容：直接取台词里的结论词，≤9 字/行，≤3 行，不加标点。
- 三种形态（都来自成片）：
  1. 单行大字（下方，替代字幕）：产品名/核心词，如「十三日达」。
  2. 两行错落（下方，替代字幕）：承诺句拆两行，第二行缩进，逐行随语音出，如「能够做到 / 14个自然日之内」。
  3. 三行清单（下方，替代字幕）：并列项逐行出，如「客户高货值 / 要求高周转 / 季节性产品」。
  4. 顶部单行（与字幕并存）：把口语数字提炼成书面结论，如台词“是能够做到百分之九十几”→ 顶部「百分之九十几」，同时把字幕里重复的部分删掉只留“是能够做到”。
- 时长：尽量覆盖到这层意思说完（用 `cues` 范围或 `hold` 延长），目标 ≥2.5 秒。
- 位置避开人脸：默认位置适配“脸在上 1/3、半身”的构图；人物偏左/偏右或景别很近时用 `x`/`y`/`pos` 调整，渲染后必须看图确认没挡脸。

## 6. 人物介绍（person，可选）

- 用户给了姓名头衔才加；放在人物第一次出镜且没有小标题的 A 镜头上，停留约 4 秒，靠右。

## 7. 片尾（ending）

- 选 4–5 秒有质感的人物/品牌画面（走路、背影、工作状态、园区空镜），画面下半部要干净能压字。可 `speed: 0.5` 做慢动作（素材需 ≥50fps 或运动很缓）。
- 标语默认「天图通逊 / 为客户 / 竭尽全力」，换品牌时改 `brand.slogan`。

## 8. BGM

- 轻、慢、无人声、无强鼓点（纪录片/企业叙事感）。`gain_db` 默认 -22，人声必须清楚。没有授权音乐就不加。
