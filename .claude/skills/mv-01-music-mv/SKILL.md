# 把一首歌做成 MV（任意 AI 通用）

参考成片：《早早晚晚》，3 分 37 秒，竖屏 1080×1920，19 个场景，约 6500 帧。
音乐用 Suno 生成；画面没有用任何视频生成模型，全部是 AI 写代码画出来的剪影插画。

**这条线不要求出镜，也不要求录音。** 人只需要给一首歌，然后在三处看一眼：分镜表、第一批测试画面、成片。

## 你需要什么

| 东西 | 说明 |
|---|---|
| 一首歌 | mp3 或 wav。没有的话先走下面「第 0 步」。 |
| 一个能跑命令的 AI | Claude Code、Codex、WorkBuddy、Cursor 的 Agent 模式都行。它要能读写文件、跑 Python 和 Node。 |
| 环境 | Python 3.10+、Node 18+、ffmpeg、Playwright 自带的 Chromium（`npx playwright install chromium`）。 |
| 字体 | 思源宋体（Noto Serif SC）、马善政毛笔（Ma Shan Zheng）、志莽行书（Zhi Mang Xing），从 Google Fonts 下载，放进 `template/fonts/`，文件名见 `template/main.html`。都是 OFL 开源字体，可商用。 |

只有网页版聊天 AI（不能跑命令）怎么办：见文末「没有能跑命令的 AI」。

## 第 0 步 · 用 Suno 做歌（已有歌就跳过）

1. **先写词**。让任意 AI 写，或者自己写。给它三样：主题（例：三十多岁的人回头看自己）、情绪（温暖不丧）、结构（主歌 / 副歌 / 主歌 / 桥段 / 副歌）。副歌里放一句能当标题的话（例：「早早晚晚」）。
2. **进 Suno 的自定义模式**，歌词贴进 Lyrics，在 Style 里写风格词，例如：`Mandarin pop ballad, warm male vocal, piano, acoustic guitar, strings, nostalgic, 70 bpm`。
3. **一次生成两版**，挑人声最清楚、副歌最上头的那版。不满意就改风格词重来，不要改词。
4. **下载 mp3**。注意 Suno 的版权规则：免费账号生成的歌按其条款不能商用，发带货或商单前先看 Suno 官网的最新条款。
5. **记下第一句人声在第几秒**。Suno 的歌前奏常有十几秒，后面要切掉。

## 第 1 步 · 听歌：歌词和时间

```bash
cd template
python3 prep_audio.py transcribe ../song.mp3
```

- 输出 `lyrics_draft.txt`，每行「开始秒-结束秒 歌词」。
- **AI 要自己校对这份歌词**：伴奏会让 Whisper 听错同音字（例：「叮咛」听成「定义」），按上下文改；删掉「作词 作曲」这类幻听行。拿不准的字列给用户确认。
- **最容易出错的地方：第一句从哪开始。** 《早早晚晚》第一版就把前四句当前奏切掉了（以为人声从 31 秒开始，其实 16.8 秒就唱了）。规则：取第一行真实歌词的开始时间，往前留 1–2 秒放片名，不要凭听感判断前奏多长。

校对完：

```bash
python3 prep_audio.py build ../song.mp3 lyrics_draft.txt   # 生成 data.js
```

## 第 2 步 · 写分镜表（要人确认）

一句歌词一个画面太碎，按「段」分场：一个场景 6–15 秒，覆盖一到四句歌词。全片 15–20 个场景。

写成表给用户看，每行四列：开始秒、歌词、画面、转场。规则：

1. **画面讲故事，不翻译歌词**。歌词说「戒指戴上了手」，画面可以是戒指绕着月亮画出一圈，而不是一只手。
2. **一个主角贯穿全片**，用同一个剪影（背包 / 外套）让观众认得出。
3. **颜色跟着情绪走**：主歌偏冷（夜、蓝），副歌转暖（黄昏、日出），桥段换一种画风（《早早晚晚》在唱苏东坡时切成水墨）。
4. **副歌要有大场面**：大落日、云海山顶、满天星。副歌第一句用大号毛笔字砸出歌名。
5. **结尾回到开头的意象**（少年、日出、路），给一个往前走的背影。
6. 转场：同一情绪内用溶解（1 秒左右），换段落用白闪或黑闪。

参考：`reference/早早晚晚-分镜表.md`。

## 第 3 步 · 写场景代码，先做测试帧（要人确认第一批）

画面引擎在 `template/`：

| 文件 | 作用 |
|---|---|
| `lib.js` | 画画的基础件：天空渐变、太阳月亮、星星、云、山脊、城市天际线、树、草、人物剪影（走 / 站 / 坐）、鸟、花瓣、雨、雪、萤火、镜头光晕、胶片颗粒。 |
| `scenes.js` | 每个场景一个函数 `sXxx(ctx, T, A)`，T 是歌曲时间（秒），A 是当前帧的节拍和响度。底部 `SCENES` 数组写每个场景从第几秒开始、歌词放在哪个高度、用什么转场。 |
| `main.js` | 合成：场景切换、溶解和闪白、逐字点亮的歌词、片名和片尾卡。顶部 `OFF` 是 MV 从原曲第几秒开始，`END` 是原曲结束秒数。 |
| `still.js` | 出测试帧：`node still.js 20 35 60` 输出这些秒数的单帧到 `stills/`。 |
| `render.js` | 正式渲染：`node render.js 起始帧 结束帧 输出.mp4`，可以开 4 个进程分段并行。 |
| `cover.js` | 封面：取某一秒的画面（不带歌词），叠上标题和副标题，同时出 9:16 和 3:4 两张。 |

做法：

1. **改写 `scenes.js`**：保留 `lib.js` 不动，按分镜表一个场景写一个函数。`template/scenes.js` 是《早早晚晚》的 19 个场景，可以直接改，也可以照着写新的。
2. **改 `main.js` 顶部**：`OFF`、`END`、片名、片头副题、片尾两句。
3. **每个场景出两三张测试帧**，拼成一张联系表看：
   ```bash
   node still.js 20 25 35 40 49 53 && cd stills && ffmpeg -i 20.jpg -i 25.jpg -i 35.jpg -i 40.jpg -i 49.jpg -i 53.jpg -filter_complex hstack=6 sheet.jpg
   ```
4. **AI 自己先看一遍联系表再给人看**，逐张检查：
   - 歌词有没有压在人物、太阳、窗户上（每个场景的 `ly` 可以调高低）。
   - 人物是不是太小（竖屏里主角至少 150 像素高）。
   - 树、建筑有没有被画面边缘切掉一半。
   - 亮场景（白天、云海）有没有过曝，歌词白字看不清时加深描边或压暗天空。
   - 同一个场景前后两张时间点，人物有没有在动。
5. 看过没问题再把第一批联系表给用户确认。

## 第 4 步 · 渲染出片

```bash
# 总帧数 = (END - OFF) × 30。下例 6111 帧，切 4 段并行
for k in 0 1 2 3; do node render.js $((k*1528)) $(((k+1)*1528)) part$k.mp4 & done; wait
printf "file part0.mp4\nfile part1.mp4\nfile part2.mp4\nfile part3.mp4\n" > list.txt
ffmpeg -f concat -i list.txt -ss <OFF> -i ../song.mp3 -map 0:v -map 1:a \
  -c:v libx264 -crf 21 -maxrate 9M -bufsize 18M -pix_fmt yuv420p -c:a aac -b:a 256k \
  -af "afade=t=in:st=0:d=0.5,afade=t=out:st=<成片秒数-3>:d=3" -shortest -movflags +faststart MV.mp4
```

- 4 核机器上，3 分半的 MV 约 15–20 分钟。
- 只改了某一段：只重渲那一段的帧，用 ffmpeg 拼回去，不要整片重渲。
- 出片后抽帧看全片：`ffmpeg -i MV.mp4 -vf "fps=1/7,scale=240:-1,tile=10x3" -frames:v 1 overview.jpg`，重点看转场前后和片头 25 秒。

## 第 5 步 · 封面和发布文案

- 封面：`node cover.js`，取全片最有冲击力的一帧（大落日、剪影奔跑），不带歌词。抖音 9:16，视频号 3:4；字放在中间三分之二，裁成 3:4 时不会被切。
- **副标题选暖的那句**。「三十六岁，路还没走完」被用户否掉，理由是「有点丧」，换成了「致每一个赶路的人」。
- 发布文案：标题从歌词里挑最戳人的一句；正文三四句，最后一句是转发理由；话题 5–8 个。

## 放行条件

用户确认分镜表、第一批联系表和成片。

## 不要做

- 不要用 AI 视频生成模型去「补」画面：风格会对不上，这条线的统一感全靠代码画。
- 不要照搬某个现有游戏、电影、动画的角色和画面。
- 不要编造歌词。听不清的字列出来问用户。

## 没有能跑命令的 AI

网页版的豆包、Kimi、ChatGPT、DeepSeek 不能渲染视频，但能完成大半：

1. 把歌词和每句的大致时间（用剪映的「识别歌词」功能拿到）发给它，让它写分镜表。
2. 让它写一个**单独的 HTML 文件**：canvas 动画按 `requestAnimationFrame` 播放，同时用 `<audio>` 播歌，歌词按时间逐字出现。把 `template/lib.js` 和 `scenes.js` 的内容一起发给它当参考。
3. 在电脑浏览器里全屏打开这个 HTML，用剪映或 OBS 录屏，录完在剪映里裁成 9:16。

画质和帧率会比逐帧渲染差一些（录屏可能掉帧），但效果大体一致。
