03共用能力每条线都调用
粗剪

一句录了几遍只留最后一遍；结巴、语气词剪掉；0.1 秒以上的气口收紧。

字幕

本机语音识别，逐字对时间；错字按稿子改。

声音

降噪、响度拉齐；配乐库 19 首，或按片子节奏现场合成，人说话时自动压低。

画面

298 个动效组件（积木）、59 款字体、自动调光；人脸在哪都测过，字不压脸。

找素材和核对

接上 TikHub 后自动搜新闻机构的公开画面，裁掉台标；数字、引语逐条查出处。

自查

黑场、闪帧、卡顿、响度机器查；关键帧它自己看过再交。

03 · GUIDED

不会提问也没关系：它问，你回数字

打开文件夹只要说一句「我想做一条视频」。它一次只问一个选择题，每次都报进度（第几步 / 共几步），每次停下来最后一句都是「下一步请你给我什么」。

发在哪？1抖音、视频号、小红书（竖屏）2B 站、公众号（横屏）3都要
主要讲什么？财经、科技、知识、新闻、历史、情感、老板讲业务、访谈，八选一。它靠这个选骨架。
骨架用哪个？1你帮我选（按前三个回答给一个）2我自己去图鉴里挑
署名写什么？片子角上和封面上用。回「不写」也行。
找素材 · 先接 TikHub

片子里要用到网上的画面（新闻画面、案例画面）时，它会在开工前提醒你一次：去 tikhub.io 注册、充一点钱（按次计费），把那串 API Token 存进文件夹最外层的「钥匙.txt」。接好后它自己去搜、去下、去裁台标。不想接也行：把视频链接或文件直接发给它。那串字符不要发在聊天里。

你不选 · 它替你选骨架

按「出不出镜、横屏竖屏、讲什么」三个回答，用一张固定的表给你一个骨架，同样的回答每次给同一个，并告诉你一句选的是哪个、对标谁。它不会自己把几种风格拼在一起。

05 · HOW IT FITS

怎么组合，才会越做越好看

原来的想法是「风格可以自由混搭」，试下来容易越搭越丑。现在改成：审美听骨架的，自由只留在骨架允许的地方。

层是什么谁说了算能不能换
① 骨架整套定了型的审美：版式、节奏、字体、字幕、配色关系出镜：对标的大 V 成片。不出镜：我们自己定的那套锁死，一条片子只用一个
② 可换件署名、强调色、素材、配乐、片尾你的个人指纹只换骨架写明「可以换」的
③ 组件266 个带小样填进骨架里的一块块内容：数据卡、图表、时间轴、清单、对比、引语、视频窗AI 按你讲的内容逐段挑只从这个骨架的名单里挑，改成骨架的颜色和字体
④ 动效出现、消失、切镜头的方式骨架全片一种；炫技最多一处

新风格不是拼出来的，是「拆」出来的：你发两三条喜欢的对标视频 → AI 逐段拆（版式、字号、颜色、节奏）→ 用你的原片出一条真片 → 你点头 → 才进骨架库。没走完这三步的都留在图鉴的「候选区」，AI 不会主动用。

还没接上的：组件现在各自带着做它时的配色，不会自动跟着骨架换，要 AI 逐个改色。相框老板风、访谈纪实风两个骨架还没有用我们自己的原片出过样片，图鉴里是占位。

07 · HOW TO USE

怎么用

两种做法，随你。想省事就一键；想把关就一步步来。图鉴是在「定方案」那一步用的。

一键成片

把原片丢给它，说一句「不用问我，一路做到底」。做完它告诉你成片在哪、剪掉了什么、哪些要你看一眼。

读 AGENTS.md，把这条口播剪成财经解读风的成片。不用问我，一路做到底。
