配置教程

百灵开箱即用。这篇教程讲清楚：接入方怎么选、知识库怎么连、额度怎么算。

一、接入方：语音和润色走哪家

百灵云服务默认 · 推荐新手

什么都不用配。装好就能用，每天 3000 字免费额度（作者承担）。请求经作者服务器中转代签——中转只记字数，不记录任何语音和文字内容。

小米 MiMo不限量 · BYOK

识别（¥0.5/小时）和润色一个 key 全搞定，中文最强，配置最简单。

  1. 到 mimo.mi.com 注册，创建 API Key
  2. 百灵「设置 → 接入方」选 自定义接入方
  3. 点 填 MiMo 预设，粘贴你的 key
  4. 点 测试连接，通过后保存

DeepSeek不限量 · BYOK

润色便宜又快，适合说话量大的人。

  1. 到 platform.deepseek.com 注册，创建 API Key
  2. 「设置 → 接入方 → 自定义接入方」点 填 DeepSeek 预设
  3. 粘贴 key，测试，保存

注意：DeepSeek 只提供润色模型。语音识别请保持「MiMo 格式」走云服务，或按下一条配 OpenAI 音频格式的 ASR。

自定义（任何 OpenAI 兼容服务）

本质上在线 ASR / 大模型都是一套 OpenAI 格式的调用，理论上配什么都行：

  1. 润色：填 润色端点（chat/completions 的 baseURL）+ 模型名 + key
  2. 语音识别：引擎选 OpenAI 音频格式（Whisper API），填 ASR 端点 和 ASR 模型——Groq（whisper-large-v3，快且便宜）、OpenAI、DeepInfra 都可以

本地 Whisper（完全离线）

不想用任何云服务：引擎选「本地 Whisper」，按 README 装好 Python 环境和模型（约 500MB），识别全程离线，润色可关。

二、知识库：它「懂你」的来源

  1. 「设置 → 知识库」打开 知识库增强
  2. 点 选择文件夹，选你的 Obsidian 库（或任何装 .md/.txt 的目录）
  3. 选完自动建索引——只读、本地、不上传，库越大它越懂你

三、专名词库：让它写对你的名字

  1. 「设置 → 专名词库 → 管理词库」
  2. 点 从知识库挑专名：AI 自动从你笔记里挑出人名/公司/产品名，一键「全部加入」
  3. 也可以手动加；出字错了点悬浮窗「改错」，教一次永久记住

四、免费额度 FAQ

额度怎么算？
按字数计：识别和润色合并计算，每个装机每天 3000 字（约说 20~30 分钟），第二天自动重置。
用完了怎么办？
两个选择：等明天重置；或在「设置 → 接入方」配自己的 key，立刻不限量。
中转服务器会看到我的内容吗？
不会。中转只做代签转发和字数计量，不记录任何音频和文本。你的录音、历史、词库、知识库索引全部在你自己电脑上。
换电脑了额度怎么算？
额度按装机匿名标识计量，换电脑是新的额度，互不影响。
