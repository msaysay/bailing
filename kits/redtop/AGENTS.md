# 给 AI 助手的说明 · 红顶双标题口播风

这个文件夹只做一件事：用户丢一条**竖屏口播原片**，你把它剪成一条成片。风格是固定的：顶上两行常驻大标题、胸口逐行累加的字幕、黑底圆框和手机壳截图穿插、一首很轻的配乐。

**先完整读一遍 `.claude/skills/redtop-talk/SKILL.md`，照它的六步做。**（你的工具不会自动加载技能也没关系，把那个文件当操作手册读。）

五条要点：

1. **环境你来装**：`python3 scripts/doctor.py --fix`。要 Python 3.10+、Node.js 20+、ffmpeg；它会自己装依赖和模型（第一次约下 250MB），没装上的照它打印的命令你接着装。不要让用户自己装东西；只有系统弹密码框、没有网时才找他。
2. **要用户定的事放在开剪之前，一次问完**：标题、字幕稿改错字、要剪的地方、开头金句、称呼和身份、结尾文字、配乐。做法是出一页「确认单」网页让他改完复制回来（`python3 scripts/redtop.py confirm …`）。开剪之后只在看关键帧、看成片两处停。
3. **不写画面代码**。整条片子由 `episodes/<期名>/plan.json` 决定，`python3 scripts/redtop.py plan` 自动生成，你只改里面的重点词、版式、截图标记。
4. **不编造**：字幕只改错字；标题不夸大；称呼、身份、结尾文字用户不给就不出。
5. **收尾出发布包**：成片点头后 `python3 scripts/redtop.py publish <期名>`，交三版封面、三个标题、简介、话题。

命令都在这个文件夹最外层运行。全部命令：`python3 scripts/redtop.py -h`。这种风格每个数字的出处：`docs/对标拆解-红顶双标题口播.md`。

和用户说话用大白话，每次停下来都告诉他下一步要给什么。你听不到声音、看不了动态，交片时把没法验证的地方如实说。
