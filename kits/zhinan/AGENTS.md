# 给 AI 助手的说明 · 网格取景框口播风

这个文件夹只做一件事：用户丢一条**竖屏口播原片**，你把它剪成一条成片。风格是固定的（对标直男财经）：人全屏两秒一换景别、网格底取景框面板放素材、胸口贴素材和表情、黄色大数字和词牌、身后大黄字，全部硬切。

**先完整读一遍 `.claude/skills/zhinan-talk/SKILL.md`，照它的七步做。**（你的工具不会自动加载技能也没关系，把那个文件当操作手册读。）用到别的技能时同样先读文件：`footage-guide`（找素材）。匹配表的规矩在 `docs/匹配规则.md`。

六条要点：

1. **环境你来装**：`python3 scripts/doctor.py --fix`。要 Python 3.10+、Node.js 20+、ffmpeg；它会自己装依赖和模型（第一次约下 250MB），没装上的照它打印的命令你接着装。不要让用户自己装东西；只有系统弹密码框、没有网时才找他。
2. **要用户定的事放在开剪之前，一次问完**：字幕稿改错字、要剪的地方、封面标题、账号名、配乐。做法是出一页「确认单」网页让他改完复制回来（`python3 scripts/zhinan.py confirm …`）。之后只在备素材、看关键帧、看成片三处停。
3. **不写画面代码**。整条片子由 `episodes/<期名>/plan.json` 决定，`python3 scripts/zhinan.py plan` 生成，你只改里面的内容。
4. **密度是命根子**：`plan` 会打印「画面平均几秒变一次」，目标 2.0 到 2.5 秒；超过 5 秒没动的地方要补东西。素材不够就用数字、词牌、表情、怼脸顶上，不要拿不相干的画面凑数。
5. **找素材先用没风险的**：用户自己的、明确授权的免费素材库；不够才引导接 TikHub（第三方、收费、和这套工具没关系）。下回来的每条都查水印、标来源（`python3 scripts/footage.py`，规则见 `docs/素材规则.md`）。对标片里的表情包、影视片段、名人照、品牌标志不照搬。
6. **收尾出发布包**：成片点头后 `python3 scripts/zhinan.py publish <期名>`，交三版封面、三个标题、简介、话题。

命令都在这个文件夹最外层运行。全部命令：`python3 scripts/zhinan.py -h`。每个数字的出处：`docs/对标拆解-直男财经.md`。

和用户说话用大白话，每次停下来都告诉他下一步要给什么。你听不到声音、看不了动态，交片时把没法验证的地方如实说。
