# 给 AI 助手的说明 · 小 Lin 风格口播工作流

这个文件夹只做一件事：用户给一条口播原片，你把它剪成**小 Lin 那种财经解读风**的竖屏成片（1080×1920）：人全屏和「素材 + 右上小圆头像」来回切，胸口压卡片，进度牌贯穿全片，白色标题体字幕；面板用关键词光球、对照表、走势图这些专属组件。

**先完整读一遍 `.claude/skills/xiaolin-talk/SKILL.md`，照它的步骤做。**（你的工具不会自动加载技能也没关系，把那个文件当操作手册读。）

七条要点：

1. **环境你来装**：`python3 scripts/doctor.py --line talk --fix`。要 Python 3.10+、Node.js 22+、ffmpeg；它会自己装依赖和模型（第一次约下 250MB），缺 ffmpeg / Node.js 也会用包管理器装；没装上的照它打印的命令你接着装。不要让用户自己装东西。
2. **开工的事一次问完**：让用户打开最外层的「开工单.html」点完复制回来（署名、要哪些处理、要不要网上的画面、怎么确认）。他贴来「这是我填好的开工单」就直接开工，不再问。
3. **横拍竖拍不用问、不用选**：程序自己看原片，自动以人脸为中心裁成竖屏。成片固定竖屏。
4. **去重录、去口吃、收紧停顿默认就做**（`talk_prep.py transcribe` 找，`cut --auto-drop` 剪），剪掉了哪几句要告诉用户。降噪、调光、配乐按开工单开。
5. **要用网上的画面就引导接 TikHub**：话术和命令在技能的「备素材」一节。用户不接就请他给链接或文件。搜来的画面没有授权，要告诉他。
6. **审美听小 Lin 骨架的**：排版式前先读 `docs/对标拆解-小Lin口播.md` 和 `docs/对标拆解-小Lin口播-第三批.md`，看 `reference/` 里的联系表；先定这一期的主面板和主题色；组件用 `studio/src/kit/talk2.tsx`、`talk3.tsx` 里的，别的组件用之前改成骨架的颜色和字体（`python3 scripts/skeleton.py show xiaolin`）。不混别的风格。
7. **收尾必出发布包**：成片点头后主动 `python3 scripts/publish_kit.py init / build <期名>`，交三版封面、三个标题、简介、话题。

其他：
- 署名三件套（角标、称呼加身份、简介）都不全程挂着：`python3 scripts/sign.py set / show / demo`，规矩在 `docs/署名规则.md`，模板里已经接好，填 `SIGN` 就行。
- 每一期的进度：`python3 scripts/episode.py status`。命令都在这个文件夹最外层运行，渲染在 `studio/` 里。
- 看全部专属组件的样子：`cd studio && npx remotion render src/index.tsx TALK3-DEMO out/talk3-demo.mp4`。`TALK02` 是版式演示，包里没带它的原片，只用来照抄写法。
- 不编造：数字、引语、截图以口播和真实材料为准；别人的画面写来源；走势图没有真实数据就不上。

和用户说话用大白话，每次停下来都告诉他下一步要给什么。你听不到声音、看不了动态，交片时把没法验证的地方如实说。
